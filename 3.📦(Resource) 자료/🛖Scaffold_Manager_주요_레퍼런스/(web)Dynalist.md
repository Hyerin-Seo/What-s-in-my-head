**Workflowy**와 **Dynalist**는 모두 들여쓰기(Bullet Point) 기반의 **‘아웃라이너(Outliner)’** 대표 앱입니다. 얼핏 보면 매우 비슷하지만, 구조, 서식 지원, 무료 정책, 개발 방향성 등에서 뚜렷한 차이가 있습니다.

두 서비스의 핵심 차이점을 비교해 정리해 드립니다.

---

### 1. 한눈에 보는 핵심 차이점 비교

| 구분 | **Workflowy** | **Dynalist** |
| :--- | :--- | :--- |
| **문서 구조** | **단일 무한 문서** (하나의 거대한 트리에서 줌인/아웃) | **폴더 & 파일 트리** (일반적인 노트 앱 구조) |
| **무료 버전 제한** | **블릿 수 제한** (월 100~250개, 추천 가입 시 추가) | **블릿 수 무제한** |
| **마크다운 지원** | 위지윅(WYSIWYG) 기반 + 자체 서식 | **표준 마크다운 문법 완벽 지원** |
| **고유 기능** | **칸반 보드 뷰**, **미러(Mirrors, 블록 동기화)** | **LaTeX 수식 지원**, 구글 캘린더 연동 (Pro) |
| **현재 개발 현황** | **활발한 업데이트 진행 중** (AI, 템플릿 등) | **유지보수 중심** (개발진이 Obsidian에 집중) |

---

### 2. 세부 차이점 분석

#### ① 구조 방식 (단일 페이지 vs 파일/폴더)
* **Workflowy:** 하나의 거대한 도화지 같은 구조입니다. 최상위 페이지 하나 안에서 무한히 하위 노드를 만들어가며 필요한 부분만 줌인(Zoom-in)해서 봅니다. 모든 생각과 정보가 유기적으로 연결된 것을 선호하는 분에게 최적입니다.
* **Dynalist:** 좌측에 폴더와 개별 파일(문서) 목록이 있습니다. 업무, 개인, 독서 등 주제별로 문서를 물리적으로 분리하여 관리하고 싶은 분에게 익숙합니다.

#### ② 텍스트 서식 및 표현 (마크다운 vs 직관성)
* **Dynalist:** 마크다운(Markdown)에 매우 친화적입니다. `# 제목`, `**굵게**`, 수식(`$$ LaTeX $$`) 입력이 자유롭고, 할 일 체크박스를 켜고 끄는 방식도 전통적입니다.
* **Workflowy:** 직관적인 텍스트 에디터(WYSIWYG) 방식입니다. 글자 색상, 형광펜, 레이아웃 변경 등을 메뉴나 간단한 단축키로 쉽게 적용할 수 있어 시각적인 정리가 깔끔합니다.

#### ③ 특화 기능 (칸반/미러 vs 수식/캘린더)
* **Workflowy의 강점:**
  * **칸반 보드(Kanban View):** 임의의 블릿 항목을 클릭 한 번으로 Trello 같은 칸반 보드로 전환할 수 있습니다.
  * **미러(Mirrors):** 하나의 블릿을 복사해 여러 곳에 배치할 수 있으며, 한 곳을 수정하면 모든 위치의 내용이 실시간으로 동기화됩니다 (매우 강력한 기능).
* **Dynalist의 강점:**
  * **수식(LaTeX):** 수학/공학 기호 입력이 필수인 학생·연구자에게 적합합니다.
  * **구글 캘린더 양방향 연동:** 날짜가 지정된 항목을 구글 캘린더와 연동하여 일정 관리용으로 쓰기 좋습니다 (Pro 기능).

#### ④ 무료 요금제 혜택
* **Dynalist (무료 사용자에게 유리):** 무료 버전에서도 **노트(블릿) 생성 개수 제한이 없습니다.** 돈을 쓰지 않고 방대한 양의 텍스트를 정리하고 싶다면 Dynalist가 훨씬 유리합니다.
* **Workflowy:** 무료 버전은 매월 생성할 수 있는 블릿 수가 제한되어 있어(월 100~250개 수준), 메인 생산성 도구로 깊게 쓰려면 유료 플랜(Workflowy Pro)을 결제해야 할 가능성이 높습니다.

#### ⑤ 개발 현황 및 미래 지속성
* **Dynalist:** Dynalist의 창업자(Erica & Shida)가 만든 차기작이 바로 유명한 **Obsidian(옵시디언)**입니다. 개발진의 역량이 옵시디언에 집중되어 있어 Dynalist는 현재 서비스 안정화/유지보수 중심으로 운영되고 있으며 큰 기능 추가는 드뭅니다.
* **Workflowy:** 여전히 팀 단위로 제품을 활발하게 개발하고 있으며, 정기적으로 새로운 기능(협업 기능, AI 통합 등)이 업데이트되고 있습니다.

### 3. 어떤 것을 선택해야 할까요?

* **Workflowy를 추천하는 경우:**
  * 모든 생각과 데이터를 하나의 거대한 체계 안에서 관리하고 싶을 때
  * 아웃라인을 **칸반 보드 형태**로도 바꿔보고 싶을 때
  * 여러 프로젝트에서 동일한 정보를 실시간으로 공유하는 **미러(동기화 블릿)** 기능이 필요할 때
  * 지속적인 새 기능 업데이트를 선호할 때

* **Dynalist를 추천하는 경우:**
  * **무료 버전**으로 블릿 수 제한 없이 방대한 노트를 작성하고 싶을 때
  * 전통적인 **폴더/파일 트리 구조**로 문서를 분류하는 것이 편할 때
  * **마크다운 문법**이나 **LaTeX 수식**을 자주 사용할 때
  * 구글 캘린더와 날짜 기반으로 연동하여 아웃라이너를 쓰고 싶을 때
