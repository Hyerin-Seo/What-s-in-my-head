앞서 말씀드린 **스크리브너(Scrivener)**는 전 세계의 소설가, 논문 작성자, 전문 서적 저자들이 가장 사랑하는 '장문 집필용 소프트웨어의 교과서'입니다. 

작성자님이 구상하시는 **"자료(Resource)를 모듈화하여 조립(Architecture)한다"**는 철학을 소프트웨어로 가장 완벽하게 구현해 낸 1세대 프로그램이기도 합니다.

스크리브너가 50페이지 이상의 장문 집필에 압도적으로 유리한 **6가지 핵심 기능**을 작성자님의 기획과 연결하여 설명해 드리겠습니다.

### 1. 🗂️ 바인더 (The Binder): 원고와 백데이터의 완벽한 통합 트리
스크리브너 화면 좌측에 있는 탐색기(Tree) 형태의 패널입니다. 일반적인 폴더 구조와 비슷해 보이지만 집필에 특화되어 있습니다.
*   **특징:** 바인더 안에는 '원고(Manuscript)' 폴더와 '리서치(Research)' 폴더가 명확히 나뉘어 있습니다. 원고 폴더에는 내가 쓸 책의 목차(1장, 2장...)를 만들고, 리서치 폴더에는 작성자님이 말씀하신 '5권의 책'에 해당하는 PDF, 이미지, 웹페이지 스크랩 등을 몽땅 집어넣을 수 있습니다.
*   **벤치마킹 포인트:** 내 글의 아웃라인과 참고할 백데이터가 하나의 프로젝트 파일(하나의 화면) 안에서 트리 구조로 관리된다는 점입니다.

### 2. 📌 코르크보드 (Corkboard): 시각적 에셋(포스트잇) 조립
작성자님의 '빨간 포스트잇' 아이디어와 100% 일치하는 기능입니다.
*   **특징:** 바인더에서 특정 폴더를 클릭하고 '코르크보드 뷰'로 전환하면, 하위 문서들이 마치 **코르크 게시판에 붙은 인덱스 카드(포스트잇)**처럼 펼쳐집니다. 각 카드에는 제목과 짧은 시놉시스(요약)가 적혀 있습니다.
*   **벤치마킹 포인트:** 글을 쓰기 전, 이 인덱스 카드들을 마우스로 드래그 앤 드롭하여 이리저리 옮기며 글의 순서와 논리 구조를 시각적으로 기획할 수 있습니다. 

### 3. 📖 스크리브닝스 모드 (Scrivenings Mode): 모듈의 선형적 결합
장문을 쓸 때 "글을 쪼개서 쓰면 전체 흐름이 끊기지 않을까?"라는 우려를 완벽하게 해결해 주는 마법 같은 기능입니다.
*   **특징:** 스크리브너에서는 글을 수십 개의 작은 텍스트 조각(모듈)으로 쪼개서 작성합니다. 하지만 최상위 폴더(예: '1부' 폴더)를 클릭하고 이 모드를 켜면, **잘게 쪼개진 수십 개의 텍스트가 마치 하나의 긴 문서처럼(끊김 없이) 스크롤 뷰로 합쳐져서** 보입니다.
*   **벤치마킹 포인트:** 작성할 때는 '블록(모듈)' 단위로 쪼개서 집중하고, 퇴고할 때는 '전체(선형)' 단위로 이어붙여서 흐름을 파악하는 UX입니다.

### 4. 🪟 화면 분할 (Split Screen): 듀얼 모니터가 필요 없는 환경
작성자님이 오른쪽(백데이터)과 왼쪽(아웃라인)을 나눈 스케치와 맥락이 같습니다.
*   **특징:** 편집 창을 좌/우 또는 상/하로 나눌 수 있습니다. 
*   **사용성:** 한쪽 창에는 리서치 폴더에 있는 '참고 도서(PDF나 발췌 텍스트)'를 띄워두고, 다른 쪽 창에서는 '내 원고'를 작성합니다. 수시로 자료를 참고해야 하는 장문 작업에서 창을 껐다 켰다(Alt+Tab) 할 필요를 없애줍니다.

### 5. 🔎 인스펙터 (The Inspector)와 스냅샷 (Snapshots)
화면 우측에 나타나는 속성 패널입니다. 각 텍스트 블록(모듈)에 대한 메타데이터를 관리합니다.
*   **특징:** 이 문서의 상태(초안, 수정 중, 완료), 라벨 색상(아이디어, 중요 자료 등), 메모 등을 우측에 기록해 둘 수 있습니다.
*   **스냅샷:** 특히 강력한 기능으로, 글을 대폭 수정하기 전에 '스냅샷(찰칵)'을 찍어두면 현재 상태의 텍스트가 백업됩니다. 나중에 수정본이 마음에 안 들면 언제든 클릭 한 번으로 이전 버전의 모듈로 롤백할 수 있습니다. (버전 관리 시스템)

### 6. 📤 컴파일 (Compile): 최종 빌드(Build)
스크리브너는 글을 '쓰는(Write)' 도구가 아니라 텍스트를 '컴파일(Compile)'하는 도구라고 불립니다.
*   **특징:** 바인더에 파편화되어 있는 수많은 텍스트 조각, 인덱스 카드, 메모들을 최종적으로 '하나의 완성된 책'으로 뽑아내는 기능입니다.
*   **사용성:** 컴파일 버튼을 누르면, 내가 설정한 규칙에 따라 쪼개진 모듈들이 하나의 워드(.docx), PDF, 혹은 전자책(.epub) 파일로 예쁘게 조립되어 출력됩니다.

### 💡 작성자님의 프로젝트(React)에 적용할 인사이트

스크리브너의 기능을 살펴보면, 작성자님의 기획 방향성이 얼마나 전문적인 저작 환경의 핵심을 잘 꿰뚫고 있는지 알 수 있습니다.

지금 개발하시는 서비스에 스크리브너의 장점을 접목한다면,
1.  **[코르크보드 + 아웃라이너의 결합]:** 스크리브너는 코르크보드(카드)와 아웃라이너(목차) 뷰를 '전환'해서 봐야 하지만, 작성자님의 서비스는 **우측(카드/백데이터)에서 좌측(아웃라인)으로 끌어다 놓는 '동시성'**을 가집니다. 이는 웹 기반 툴로서 훨씬 직관적이고 진보된 형태입니다.
2.  **[스크리브닝스 모드의 도입]:** React 에디터를 개발하실 때, 좌측 아웃라인에 있는 여러 개의 노드(블록)들을 하나로 쭉 이어서 볼 수 있는 **'전체 읽기 모드(Read Mode)'**를 반드시 추가해 보세요. 50페이지 글을 쪼개서 AI와 작업한 뒤, 전체 톤앤매너를 점검할 때 필수적입니다.
