## 1. Magic Plus Button (매직 플러스 버튼 — Insert Anywhere UX)

* **Things 3 원형 인터랙션**:  
  화면 우하단에 떠 있는 파란색 `+` 버튼을 클릭하면 기본 추가되지만, **버튼을 꾹 눌러 위로 드래그하면 목록의 항목들 사이에 파란 가이드 인디케이터가 표시**되며 원하는 위치에 정확히 놓아 그 자리에 항목을 인라인 삽입할 수 있습니다.
* **아웃라이너 적용점**:
  - 기존 아웃라이너는 특정 위치에 노드를 넣으려면 `Enter` 후 `Tab`을 치거나, 맨 밑에 만들고 위로 한참 끌어올려야 하는 번거로움 존재.
  - 마우스나 터치로 `+`를 드래그하여 **원하는 두 노드 사이, 또는 특정 노드의 자식 노드 슬롯으로 직관적으로 꽂아 넣는(Snap-in) 제스처** 구현.

## 2. 헤딩(Heading) 기반의 시각적 호흡 구분 (Visual Sectioning)

* **Things 3 원형 인터랙션**:  
  하나의 프로젝트 안에 무거운 하위 폴더나 별도 페이지를 파지 않고, **얇고 세련된 헤딩(Heading) 구분선**을 추가하여 프로젝트 내부를 시각적 섹션으로 분할.
* **아웃라이너 적용점**:
  - 아웃라이너가 무한 계층으로 깊어지면 시각적으로 어디서 끊어 읽어야 할지 인지 과부하(Cognitive Overload) 발생.
  - 단순 불릿 외에 챕터나 큰 전개 단위를 끊어주는 **'헤딩 디바이더 노드'**를 제공하여 문서의 호흡과 리듬을 시각적으로 부여.

## 3. 노드 속 체크리스트 (2단계 인지 계층 분리)

* **Things 3 원형 인터랙션**:  
  하나의 할일(Task) 카드 안에 가벼운 **체크리스트(Checklist)** 서브스텝을 포함시켜, 태스크 목록 자체가 지나치게 비대해지는 것을 방지.
* **아웃라이너 적용점**:
  - 문서의 뼈대를 이루는 '아웃라인 노드'와, 그 노드를 완성하기 위해 필요한 '작성 가이드 / 팩트 체크 항목'을 분리.
  - 노드를 클릭했을 때 열리는 미니 서랍에서 **'이 슬롯에서 채워야 할 필수 3가지 체크리스트'**를 제공하여 뼈대를 어지럽히지 않고 세부 요건 검증.

---

## 4. When(언제 할지) vs Deadline(마감)의 분리

* **Things 3 원형 인터랙션**:  
  할일을 처리할 시작 시점인 **'When (Today / Upcoming / Someday)'**과 절대적인 종료 시점인 **'Deadline'**을 엄격히 분리하여 사용자의 불필요한 마감 압박을 경감.
* **아웃라이너 / 볼트 적용점**:
  - 개똥이 머릿속 볼트의 `일정`과 `마감` 속성 철학과 100% 일치.
  - Scaffold Manager에서도 기획 문서 작성 시 "오늘 작성할 작업 범위(Today Focus)"와 "문서 최종 납기(Target Milestone)"를 분리하여 단계별 집중도 향상.

---

## 5. 쫀득한 마이크로 인터랙션과 키보드 조작감

* **Things 3 원형 인터랙션**:  
  - 항목을 체크(`Space`)할 때 0.1초 동안 살짝 튕기며 사라지는 경쾌한 체크 애니메이션.
  - 마우스에 손을 대지 않고 `방향키`, `Cmd+K` 퀵 점프로 모든 항목을 탐색하는 조작성.
* **아웃라이너 적용점**:
  - 노드를 작성하고 완료하거나 AI 슬롯을 승인할 때, 기계적인 텍스트 변경이 아니라 **'작업이 전진하고 있다'는 즉각적인 도파민 피드백**을 주는 미세 모션 구현.

## 🎯 Scaffold Manager 핵심 연결고리

* **론 프리드먼 3대 종족과의 조화**:  
  - 1종족(Workflowy)의 "극단적 자유로움"에 갇히면 구조가 난잡해지고, 2종족(PandaDoc)의 "엄격한 틀"에 갇히면 숨이 막힙니다.
  - Things 3는 **자유로운 아웃라인 위에 '우아한 헤딩'과 '매직 플러스 드롭', '노드별 체크리스트'를 얹어 두 종족의 장점을 결합하는 UI/UX 해법**을 제시합니다.
