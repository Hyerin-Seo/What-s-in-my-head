## 📌 개요 및 파이프라인 의의
파일 포맷 중 '스프레드시트 수식형'은 텍스트 문서와 달리 2차원 셀(Cell) 매트릭스 상에서 **데이터 연산, 함수 모델링, 조건부 서식, 자동 집계 로직**을 실행하는 데 특화된 양식입니다.

마이크로소프트 엑셀(`.xlsx`), 구글 스프레드시트(Google Sheets), 오픈포맷(`.ods`)을 포괄하며, 파이프라인 관점에서는 정적 텍스트를 넘어 **셀 간 참조 관계(DAG, 유향 비순환 그래프), 수식 무결성, 동적 데이터 바인딩**을 기계적으로 추출하고 보존하는 핵심 대상입니다.

## 2. 순수 신규 조사 대상 허브 (실측 조사 · 5곳)

### 6. Microsoft Create — Excel Templates
* **허브 링크**: https://create.microsoft.com/en-us/templates/excel
* **무엇이 있나**: 상단 Microsoft 365 글로벌 메뉴(Products, Features, Download, Support, Buy Microsoft 365) 및 Create 포털 진입점. "Create anywhere, anytime" 비주얼 및 엑셀(Excel XLSX) 표준 예산안, 일정표, 재무제표, 프로젝트 트래커 템플릿 카탈로그. 웹 엑셀(Excel for the web) 즉시 실행 및 로컬 `.xlsx` 다운로드 지원 인터페이스.
* **이용 조건**: 마이크로소프트 공식 무료 및 Microsoft 365 구독형(Freemium). 웹 기반 즉시 편집 무료, 고급 템플릿은 오피스 구독 연동.
* **파이프라인 관점**: 전 세계 스프레드시트의 원천인 Microsoft Excel의 공식 수식 구조, 피벗 테이블 스타일, 데이터 유효성 검사 규칙의 글로벌 표준 SSOT.

### 7. Sheetgo — Workflow & Spreadsheet Templates
* **허브 링크**: https://www.sheetgo.com/templates/
* **무엇이 있나**: 상단 로고 `Sheetgo`, 메뉴(Product, Solutions, Use cases, Pricing). 메인 헤드라인 "Discover ways to use Sheetgo — From cash flow monitoring to timesheet tracking, find a workflow template for every part of your business." 우측 워크플로우 템플릿 인터랙티브 일러스트레이션. 현금 흐름 모니터링, 타임시트 추적, 재고 관리 시트 템플릿 제공.
* **이용 조건**: 프리미엄(Freemium). 기본 스프레드시트 템플릿 무료 복제 지원 및 Sheetgo 데이터 파이프라인 자동화 도구 유료 연계.
* **파이프라인 관점**: 시트 간 데이터 연결(Sheet-to-Sheet ETL), 자동 병합, 스프레드시트 기반 업무 프로세스 자동화 양식의 훌륭한 레퍼런스.
