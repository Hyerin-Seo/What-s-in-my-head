# (에이전트) 도구 및 서식 선별 역량과 평가 지표 체계

AI 에이전트(LLM Agent) 연구 및 시스템 엔지니어링 실무에서, 사용자의 작업 맥락을 분석하여 방대한 라이브러리 중 가장 적합한 도구(Tool), 포맷, 서식 템플릿(Scaffold)을 찾아내고 장착하는 작업은 **단순한 텍스트 생성이나 단일 도구 실행과 구별되는 독립적인 고급 역량**으로 다루어집니다.

본 문서는 최신 AI 에이전트 분야에서 정립된 도구/서식 선별 역량의 정의, 글로벌 표준 벤치마크, 핵심 정량 평가 지표, 그리고 시스템 아키텍처 패턴을 정리합니다.

---

## 1. 특화 역량(Capabilities)의 정의

전통적인 LLM이 '질문에 답하는 것(Answering)'에 머물렀다면, 에이전트 시스템에서는 사용자의 목적 달성을 위해 환경과 상호작용하는 다음의 3대 핵심 역량이 요구됩니다:

### Tool Retrieval & Selection (도구/서식 검색 및 선별)
- 수백~수만 개의 API, 도구, 서식 템플릿 풀 속에서 사용자의 암묵적 의도와 맥락에 가장 부합하는 최적의 후보군을 골라내는 역량입니다.
- 도구를 단순히 호출(Execution)하는 것보다, 무관한 방해 후보(Distractors)들을 걸러내고 적합한 도구를 특정하는 **선별(Selection) 역량**이 모델의 실질적인 태스크 성공률을 결정짓는 핵심 병목으로 평가됩니다.

### Context-Aware Scaffolding & Proactive Assistance (상황 인지형 스캐폴딩 / 선제적 지원)
- 사용자가 "A 서식을 가져와"라고 직접 지시하지 않더라도, 대화 맥락, 현재 작업 단계, 환경적 제약(수기 작성 여부, 결재 거버넌스 등)을 감지하여 적합한 구조적 뼈대를 **적시(Just-in-Time)**에 능동적으로 공급하는 역량입니다.

### Context Localization & Schema Grounding (컨텍스트 국소화 및 스키마 안착)
- 방대한 저장소와 복합 문서 트리에서 문제 해결의 출발점이 되는 '정확한 서식 스키마와 규칙'을 오차 없이 타깃팅하여, 환각(Hallucination) 없이 작업 공간에 안착시키는 능력입니다.

## 2. 주요 글로벌 벤치마크 (Benchmarks)

에이전트의 도구/서식 선별 및 활용 역량을 측정하기 위해 정립된 대표적인 벤치마크는 다음과 같습니다:

### BFCL (Berkeley Function Calling Leaderboard)
- **주관**: UC Berkeley (Gorilla 프로젝트 팀, Patil et al.)
- **평가 초점**: 함수/도구 호출(Function Calling) 역량을 측정하는 업계 표준 리더보드. 수많은 함수 후보 중 단일/복수/병렬 도구를 정확히 선별하고, 올바른 인자(Arguments)를 구성하는지를 AST(추상 구문 트리) 및 실행(Executable) 레벨에서 정밀 평가합니다.

### ToolBench
- **주관**: Tsinghua 대학 & OpenBMB (Qin et al., 2023)
- **평가 초점**: 16,000개 이상의 실제 REST API 환경을 모사하여, 에이전트가 복잡한 다단계 지시사항을 해결하기 위해 도구를 검색(Retrieval), 선별(Selection), 연계 실행하는 전체 경로를 평가합니다. 도구 검색 전용 하위 셋(ToolRetriever)을 포함합니다.

### ContextAgentBench / ProAgentBench (2024 최신 연구)
- **평가 초점**: 기존 벤치마크들이 '명시적 명령에 대한 반응(Reactive)'만 측정하던 한계를 극복하기 위해 등장한 벤치마크입니다. 사용자의 연속적인 작업 흐름과 맥락을 모니터링하다가 '개입이 필요한 타이밍'을 예측하고 적절한 도구/서식을 지원하는 능동적 개입(Proactive Intervention) 성능을 측정합니다.

### GAIA (General AI Assistants)
- **주관**: Meta, HuggingFace, AutoGPT (Mialon et al., 2023)
- **평가 초점**: 현실 세계의 멀티모달 파일, 웹 탐색, 복합 문서 처리 작업에서 에이전트가 적절한 도구와 포맷을 스스로 선별해 문제를 완수하는 멀티모달 종합 역량을 평가합니다.

## 3. 정량 평가 지표 (Evaluation Metrics)

에이전트가 서식을 얼마나 적재적소에 올바르게 찾아주는지 평가하는 핵심 정량 지표는 다음과 같습니다:

| 평가 영역 | 지표명 | 측정 내용 및 의미 |
| --- | --- | --- |
| **선별 정확도** | Tool Selection Accuracy (Recall@k / Precision@k) | 수십~수백 개의 무관한 서식(Distractors)이 존재할 때, 정답 서식을 상위 k개 후보군 내에 정확히 추출해 냈는가 |
| **인자/스키마 정합성** | Action Exact Match (Act.EM) / AST Match Rate | 추출된 서식의 필수 입력 슬롯과 매개변수 구조를 에이전트가 문법 오류 없이 정확히 채워 넣었는가 |
| **적시성** | Intervention Timing Appropriateness (JIT Precision) | 서식을 사용자가 필요로 하는 바로 그 시점에 공급했는가 (너무 일러서 작업 흐름을 끊거나, 너무 늦어서 무용지물이 되지 않았는가) |
| **개입 마찰도** | Over-Intervention vs. Under-Intervention Rate | 불필요한 상황에 엉뚱한 양식을 들이밀어 사용자를 방해하는 비용(과잉 개입)과, 양식이 꼭 필요한데 백지로 방치하는 비용(과소 지원) 간의 균형 비율 |
| **스키마 준수율** | Schema Adherence Rate | 선별된 서식의 고유 제약 조건(예: 18줄 괘선 슬롯, 필수 메타 헤더 등)을 환각 없이 엄격히 준수하여 산출물을 작성했는가 |

## 4. 시스템 아키텍처 패턴: 2단계 분리 구조 (Retrieve-then-Act)

실무 에이전트 런타임에서는 수많은 서식 중에서 최적의 뼈대를 찾아 적용하기 위해 **2단계 분리(Two-Stage Architecture)** 패턴을 채택합니다:

```text
[사용자 비정형 요구/맥락]
        │
        ▼
┌───────────────────────────────────────────────┐
│ 1단계: Scaffold Retriever (Router Agent)      │
│  - 본문 작성 배제                             │
│  - 시맨틱 메타데이터(수기성, 거버넌스, 제약성) 대조 │
│  - 최적 서식 후보 1~3개 선별                  │
└───────────────────────────────────────────────┘
        │ (선별된 서식 스키마 및 제약 조건 전달)
        ▼
┌───────────────────────────────────────────────┐
│ 2단계: Scaffold-Guided Worker (Writer Agent)  │
│  - 서식 선별 고민 배제                        │
│  - 주입된 서식의 슬롯 및 제약 내에서 본문 완성 │
└───────────────────────────────────────────────┘
```

- **1단계 라우팅 에이전트**: 비즈니스 맥락과 입력 환경(수기/디지털, 결재선 유무 등)을 파악하여 서식 라이브러리에서 최적의 서식 ID를 특정합니다.
- **2단계 작성 에이전트**: 서식의 구조적 제약(Schema Constraints)을 시스템 프롬프트/가이드라인으로 주입받아, 그 뼈대를 벗어나지 않고 안전하게 내용을 채웁니다.

## 5. 서식 수집 파이프라인과의 연계 의의

현재 구축 중인 **예스폼 93종 회의록 수집 및 시맨틱 프로파일링(8대 분류 축 + 01번 7대 프로파일)**은 이 에이전트 아키텍처의 핵심 기반 데이터입니다:

1. **고밀도 메타데이터 색인 제공**: 표면 키워드("교회 회의록")가 아닌 '수기 완결형', '양자 대등 공증', '표현 억압형' 등의 속성을 부여함으로써, 1단계 라우팅 에이전트의 **Tool Selection Accuracy(선별 정확도)**를 극대화합니다.
2. **환각 없는 스캐폴딩 보장**: 7번 실전 작성 요령과 괘선 규격을 사전 정의함으로써, 2단계 작성 에이전트의 **Schema Adherence Rate(스키마 준수율)**를 보장합니다.
