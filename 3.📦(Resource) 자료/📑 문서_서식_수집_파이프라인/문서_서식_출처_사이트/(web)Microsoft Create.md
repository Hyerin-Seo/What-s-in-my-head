마이크로소프트 공식 통합 템플릿 포털.

## 1. 대표 포털 개요 및 메인 정보
* **공식 대표 사이트**: https://create.microsoft.com
* **보유 세부 서브 카탈로그 수**: 4개 허브

## 2. 세부 서브 카탈로그 카탈로그 및 이미지
### 2.1. Microsoft Create — 예산 및 재무 스프레드시트
![[재무·회계 허브 09 - Microsoft Create.png]]

* **서브 카탈로그 URL**: https://create.microsoft.com/ko-kr/templates/budgets
* **보유 서식 및 기능**: 헤드라인 "Create anywhere, anytime - Create and edit in an instant: Excel". 마이크로소프트 공식 템플릿 포털. 가계 및 비즈니스 예산안, 이슈 트래킹, 월간 지출 분석, 재무 계획 등 MS 오피스 공식 디자이너와 엔지니어가 제작한 엑셀 템플릿 갤러리 제공.
* **이용 조건 및 라이선스**: 무료 다운로드 및 Microsoft 365 웹 무료 계정을 통한 브라우저 내 즉시 편집 지원.
* **파이프라인 관점**: 마이크로소프트 공식 오피스 엑셀 엔진의 최신 표준 함수와 모던 UI 스타일 가이드를 준수하는 표준 템플릿 원천.
* **원천 카드 섹션**: [[05. (도메인) 재무·회계 서식 수급처 Top 10#9. Microsoft Create — 예산 및 재무 스프레드시트]]

### 2.2. Microsoft Create — Word Templates
![[문서 텍스트형 허브 06 - Microsoft Create Word.png]]

* **서브 카탈로그 URL**: https://create.microsoft.com/en-us/templates/word
* **보유 서식 및 기능**: 상단 Microsoft 365 헤더 및 네비게이션(Products, Features, Download, Support, Buy Microsoft 365). 메인 브랜딩 "Create anywhere, anytime. Turn your ideas into ready to edit images, templates, and designs with AI assistance, so you can move from blank page to first draft faster." 하단 워드(Word DOCX), 엑셀, 파워포인트 오피스 공식 템플릿 카탈로그 진입 및 AI 지원 템플릿 생성 인터페이스가 배치되어 있다.
* **이용 조건 및 라이선스**: 마이크로소프트 공식 무료 및 Microsoft 365 구독형(Freemium). 웹 브라우저 상에서 Word 템플릿 무료 편집 및 로컬 `.docx` 파일 다운로드 지원.
* **파이프라인 관점**: 전 세계 워드프로세서 문서의 사실상 표준(de facto standard)인 DOCX 서식 규약의 공식 원천. 단락 스타일, 목차(TOC) 필드, 표 테두리 레이아웃 추출에 최적이다.
* **원천 카드 섹션**: [[13. (포맷) 문서 텍스트형 서식 수급처 Top 10#6. Microsoft Create — Word Templates]]

### 2.3. Microsoft Create — Excel Templates
![[스프레드시트 수식형 허브 06 - Microsoft Create Excel.png]]

* **서브 카탈로그 URL**: https://create.microsoft.com/en-us/templates/excel
* **보유 서식 및 기능**: 상단 Microsoft 365 글로벌 메뉴(Products, Features, Download, Support, Buy Microsoft 365) 및 Create 포털 진입점. "Create anywhere, anytime" 비주얼 및 엑셀(Excel XLSX) 표준 예산안, 일정표, 재무제표, 프로젝트 트래커 템플릿 카탈로그. 웹 엑셀(Excel for the web) 즉시 실행 및 로컬 `.xlsx` 다운로드 지원 인터페이스.
* **이용 조건 및 라이선스**: 마이크로소프트 공식 무료 및 Microsoft 365 구독형(Freemium). 웹 기반 즉시 편집 무료, 고급 템플릿은 오피스 구독 연동.
* **파이프라인 관점**: 전 세계 스프레드시트의 원천인 Microsoft Excel의 공식 수식 구조, 피벗 테이블 스타일, 데이터 유효성 검사 규칙의 글로벌 표준 SSOT.
* **원천 카드 섹션**: [[14. (포맷) 스프레드시트 수식형 서식 수급처 Top 10#6. Microsoft Create — Excel Templates]]

### 2.4. Microsoft Create — PowerPoint Templates
![[슬라이드 시각형 허브 06 - Microsoft Create PowerPoint.png]]

* **서브 카탈로그 URL**: https://create.microsoft.com/en-us/templates/powerpoint
* **보유 서식 및 기능**: 상단 Microsoft 365 헤더 메뉴(Products, Features, Download, Support, Buy Microsoft 365) 및 Create 포털 안내. 메인 비주얼 "Create anywhere, anytime" 및 AI 어시스턴스 기반 프레젠테이션 디자인 제작 인터페이스. 공식 파워포인트(PowerPoint PPTX) 피치덱, 비즈니스 제안서, 교육용 슬라이드 템플릿 카탈로그가 제공된다.
* **이용 조건 및 라이선스**: 마이크로소프트 공식 무료 및 Microsoft 365 구독형(Freemium). 웹 파워포인트(PowerPoint for the web) 즉시 편집 및 로컬 `.pptx` 파일 무료 다운로드 지원.
* **파이프라인 관점**: 전 세계 프레젠테이션 슬라이드의 기술적 표준인 PPTX 서식 규약의 최고 원천. 슬라이드 마스터(Slide Master), 레이아웃 틀(Placeholder), 도형 벡터 속성 추출에 필수적이다.
* **원천 카드 섹션**: [[15. (포맷) 슬라이드 시각형 서식 수급처 Top 10#6. Microsoft Create — PowerPoint Templates]]
