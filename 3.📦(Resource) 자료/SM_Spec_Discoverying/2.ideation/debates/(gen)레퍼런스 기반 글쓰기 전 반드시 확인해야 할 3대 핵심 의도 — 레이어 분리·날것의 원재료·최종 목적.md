# 레퍼런스 기반 글쓰기 전 반드시 확인해야 할 3대 핵심 의도 — 레이어 분리·날것의 원재료·최종 목적

> **핵심 테제**:  
> 사용자가 레퍼런스 링크 하나만 던지며 "이걸 참고해서 기술 블로그를 쓰고 싶다"고 했을 때,  
> AI가 멋대로 가짜 소설을 쓰거나 뻔한 템플릿을 들이밀지 않으려면 **반드시 사전에 확인해야 하는 3가지 핵심 의도**가 있습니다.  
> 이 3가지를 체크하지 않고 바로 아웃라인을 뽑으면, "남의 프로젝트(테스트 자동화) 설정을 대충 내 기술 스택 이름으로만 갈아 끼운 가짜 토스 흉내내기 글"이 나올 수밖에 없습니다.

---

## 1. 레퍼런스에서 가져오려는 ‘레이어(차원)’의 분리

'레퍼런스로 삼겠다'는 말은 사람마다 의미가 완전히 다릅니다. 어떤 층위를 원하는지 특정하지 않으면 엉뚱한 결과물이 나옵니다.

* **서사 구조(Scaffold)만 빌리고 싶은가?**  
  → 토스의 `[극단적 고통] ➔ [사건형 헤딩] ➔ [뼈아픈 시행착오] ➔ [초압축 증거] ➔ [철학적 결론]`이라는 빌드업 공식만 내 프로젝트에 대입하려는 것인지
* **톤앤매너(Voice & Tone)를 빌리고 싶은가?**  
  → 토스 특유의 담백하고 친절한 구어체(~했어요, ~거든요)와 짧은 호흡의 문체 리듬을 입히고 싶은 것인지
* **도메인/기술적 주제(Topic)가 유사한 것인가?**  
  → 내 프로젝트도 실제로 'LLM 기반 자동화', 'QA/테스트 파이프라인', 'Self-healing' 같은 유사 기술을 다루고 있어 기술적 해결 방식을 참고하려는 것인지

---

## 2. 글의 심장이 될 ‘날것의 원재료(Raw Experience)’ 확인

토스 테크 글의 설득력은 기술 자랑이 아니라 **"실제로 현장에서 겪은 찌질한 고통"**과 **"망할 뻔했던 시행착오"**에서 나옵니다. 이 원재료가 없으면 AI는 무조건 가짜 실패담을 지어내게 됩니다.

* **해결하려던 진짜 고통이 무엇이었는가?**  
  (예: "매주 배포 때마다 3명이 손으로 1,000개 화면 누름"에 필적하는 사용자의 실제 작업 피로감)
* **진짜로 겪은 '결정적 삽질 1~2개'가 있는가?**  
  (예: "처음엔 전체를 통째로 넘겼더니 토큰/응답시간 폭탄 맞음", "조건을 느슨하게 줬더니 엉뚱한 결과가 줄줄이 통과됨")
* **보여줄 수 있는 최소한의 증거물(코드, 로그, 수치)이 있는가?**  
  (수동 작업 시간 80% 단축, 3줄짜리 시나리오 스니펫 등)

---

## 3. 글의 ‘최종 목적과 독자 타깃’ 확인

토스 글은 표면적으로는 기술 글이지만, 이면에는 강력한 **채용 브랜딩(Employer Branding)** 목적을 깔고 있습니다. 내 글의 목적에 따라 전개 방식이 달라져야 합니다.

* **취업/이직용 포트폴리오인가?**  
  → "내가 얼마나 주도적으로 문제를 발굴하고, 기술적 트레이드오프를 고민하며 끝까지 해결해 냈는가"를 보여주는 개인의 엔지니어링 깊이에 초점
* **팀/기업의 테크 브랜딩인가?**  
  → "우리 팀이 동료의 비효율을 어떻게 문화와 도구로 풀어냈는가"를 보여주는 조직 문화와 비전에 초점
* **실무 엔지니어를 위한 순수 지식/트러블슈팅 공유인가?**  
  → 서사보다는 문제 재현 조건, 아키텍처 다이어그램, 적용 방법 등 실용적 팁에 초점

## 💡 Scaffold Manager 엔진 관점에서의 체크리스트

```text
┌────────────────────────────────────────────────────────┐
│               사전 의도 디스커버리 3대 게이트             │
├────────────────────────────────────────────────────────┤
│ [Gate 1] 레이어 분리 : 구조(Scaffold) vs 톤 vs 주제    │
│ [Gate 2] 원재료 확보 : 진짜 고통 + 결정적 삽질 + 증거    │
│ [Gate 3] 목적 타깃   : 포트폴리오 vs 브랜딩 vs 지식공유 │
└────────────────────────────────────────────────────────┘
```

이 3대 게이트를 통과하지 않은 상태에서 성급하게 AI 문장 생성을 돌리는 것은, 내용 없는 껍데기 소설을 양산하는 지름길입니다.
