# 03. 해결방안

> **좌측 Explorer 카드 메타**:
> - **카드 이름**: `03. 해결방안`
> - **진행 상태**: ● 작성 완료 (필수 2개 채워짐)
> - **세부 구성**: 🔴 필수 2개 (동작 파이프라인, 결정적 돌파구) + ⚪ 선택 2개 (화면 캡처 증거, 3단계 대안 비교)

---

## 📝 중앙 에디터 본문

### 🔴 [필수] 3-1. 핵심 동작 파이프라인
코드를 잘 만들어도 실행 중에 예상 못한 화면이 끼어듭니다. 우리는 테스트가 요소를 찾지 못해 멈추려는 바로 그 순간, 도구가 화면을 직접 들여다보고 스스로 방해물을 치우는 **'스마트파인더(SmartFinder)'**를 구축했습니다. 쓰러진 그 자리에서 곧바로 심폐소생을 시도하는 파이프라인입니다.

### 🔴 [필수] 3-2. 결정적 돌파구 (장애물 우회)
타행 계좌로 송금할 때 외부 공유 툴팁이 계좌번호 입력칸을 가리고 있었습니다. 과거라면 테스트가 즉시 깨졌겠지만, 스마트파인더는 이를 '일시적 방해물'로 판단해 스스로 툴팁을 닫은 뒤, 가림이 사라진 것을 확인하고 원래 송금 입력을 무사히 이어갔습니다.

---

### ⚪ [선택] 3-3. 실제 작동 증거 화면 (캡처)
> **📸 [실제 스크린샷 캡처 삽입 위치]**  
> *(캡션: 송금 입력창을 가린 공유 툴팁을 스마트파인더가 감지하고 스스로 '닫기' 버튼을 눌러 치워내는 실제 실행 로그 화면)*

### ⚪ [선택] 3-4. 비용 절감을 위한 3단계 탐색 대안
1. **1단계 (가벼운 탐색)**: 화면 겉면에 드러난 요소 목록만 빠르게 훑기
2. **2단계 (심층 탐색)**: 못 찾으면 화면 전체 구조 데이터를 깊게 뒤지기
3. **3단계 (사람에게 질문)**: 그래도 막히면 그제야 사람에게 도움 요청
