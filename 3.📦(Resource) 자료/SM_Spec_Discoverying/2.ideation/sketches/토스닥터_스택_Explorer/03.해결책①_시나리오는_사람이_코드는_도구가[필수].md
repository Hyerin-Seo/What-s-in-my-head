# 03. 해결책① — 시나리오는 사람이, 코드는 도구가 [필수]

> **좌측 Explorer 카드 메타**:
> - **슬롯 역할**: 첫 번째 핵심 돌파구 (발상의 전환)
> - **정형 모드(Lock)**: 🔒 필수 칸 (해결책의 뼈대)
> - **비정형 모드(Unlock)**: 🔓 솔루션 블록 (필요시 상세 테크닉 블록과 묶거나 독립 분리 가능)
> - **작성 상태**: ● 작성 완료 (초록색 뱃지)

---

## 📝 중앙 에디터 본문 (일반 이용자가 읽는 글)

그래서 우리는 완전히 새로운 룰을 정했습니다.  
**"사람은 복잡한 컴퓨터 코드를 한 줄도 짜지 않는다."**

대신 사람은 우리가 매일 쓰는 자연스러운 말로 '어떤 흐름을 검사할지' 시나리오만 적기로 했습니다.

> *"송금 화면에 들어간다.  
> 받는 계좌와 보낼 금액 1만 원을 입력한다.  
> 송금 확인 화면이 제대로 뜨는지 확인한다."*

사람이 이렇게 직관적인 몇 줄의 글을 적어두면, 도구가 알아서 실제 스마트폰 화면을 눈으로 보면서 필요한 버튼을 찾고 코드를 스스로 완성합니다. 사람은 '의도'만 말하고, 번거로운 '구현'은 도구에게 온전히 넘긴 것입니다.

## 💡 우측 Recipe 쪽지 (글쓰기 비법 & 힌트)

- **이 블록의 목적**: 복잡한 기술 스택(Gherkin, Appium, MCP 등)을 앞세우지 않고, **"역할을 어떻게 나누었는가"**라는 명쾌한 규칙 하나로 무릎을 탁 치게 만듭니다.
- **선배의 글쓰기 팁**:
  - 독자가 즉시 이해할 수 있는 아주 친숙한 예시(송금 시나리오 3줄)를 본문에 배치하세요.
  - 전후 대비("예전엔 사람이 코드를 짰지만, 이제는 시나리오만 쓴다")를 굵은 글씨로 강조하면 전달력이 배가됩니다.
