# 토스닥터 사례로 검증하는 좌측 카드스택 Explorer 구조

> **핵심 테제**:  
> **"디렉토리와 파일의 트리 구조만 봐도, 좌측 Explorer 화면이 어떻게 생겼고 어떻게 작동하는지 단번에 보여야 한다."**  
> 이 폴더 안에 나열된 파일 목록 자체가 곧 **화면 좌측에 세로로 꽂히는 카드 목록(Card Stack)**입니다.

---

## 🧭 좌측 Explorer에서 이 폴더를 바라보는 두 가지 시선

사용자가 상단에서 **[정형 모드]**를 켜느냐, **[비정형 블로그 모드]**를 켜느냐에 따라 이 파일 목록은 화면에서 다음과 같이 다르게 렌더링됩니다.

```text
📁 토스닥터_글_작성하기 (중앙 에디터의 하나의 글)
│
├── 🔒 [정형 문서 모드 (Lock)] : 규격 준수 & 빈칸 채우기
│   ├── [필수] 01. 도입 — 매주 반복되는 피로와 문제의 시작  [● 완료]
│   ├── [필수] 02. 진단 — 화면이 조금만 바뀌어도 깨지는 도구  [● 완료]
│   ├── [필수] 03. 해결책① — 시나리오는 사람이, 코드는 도구가 [● 완료]
│   ├── [선택] 04. 해결책② — 화면이 바뀌어도 스스로 우회하는 눈 [○ 미작성]
│   ├── [선택] 05. 해결책③ — 스스로 원인을 분석하고 고치는 법 [○ 미작성]
│   └── [필수] 06. 결론 — 단순 자동화를 넘어 진짜 동료로     [● 완료]
│   └─▶ 규칙: 순서 변경 불가(드래그 잠김). 필수 칸이 다 채워져야 '제출/배포' 가능.
│
└── 🔓 [비정형 블로그 모드 (Unlock)] : 스토리텔링 & 블록 조립
    ├── ::: 01. 도입 — 매주 반복되는 피로와 문제의 시작     [드래그 핸들 노출]
    ├── ::: 02. 진단 — 화면이 조금만 바뀌어도 깨지는 도구
    ├── [+] (새로운 경험담 블록 끼워넣기)
    ├── ::: 03. 해결책① — 시나리오는 사람이, 코드는 도구가
    ├── ::: 04. 해결책② — 화면이 바뀌어도 스스로 우회하는 눈
    └── ::: 06. 결론 — 단순 자동화를 넘어 진짜 동료로 (05번 삭제 후 조립)
    └─▶ 규칙: 마우스로 위아래 순서를 바꾸고, 필요 없는 블록은 빼거나 새 블록을 추가.
```

---

## 🗂️ 개별 파일이 담당하는 3단 인터랙션

이 폴더의 파일 하나(`01.도입...md` 등)를 클릭하는 순간, 화면은 다음 세 영역이 동시에 유기적으로 반응합니다.

1. **[좌측 Explorer]**: 해당 카드에 파란색 포커스 하이라이트가 켜집니다.
2. **[중앙 에디터]**: 해당 카드의 본문(일반 사용자 언어로 쓰인 글)이 열려 바로 편집할 수 있습니다.
3. **[우측 Recipe 쪽지]**: "이 구간에서는 독자가 깊이 공감할 수 있도록 구체적인 고통을 적어주세요" 같은 선배의 글쓰기 팁이 실시간으로 전환됩니다.
