기획(Why & What)과 설계(How & Detail)는 모든 작업에 균일하게 바르는 요식행위가 아닙니다.  
작업의 4대 핵심 진단 차원이 가리키는 중력장 좌표에 따라, 최적의 작업 방식(How)을 산출해내는 **동적 레버(Dynamic Lever)이자 처방 시스템**입니다.

---

### 🏛️ 작업을 결정하는 4대 진단 차원과 1대 처방 레버

```text
┌─────────────────────────────────────────────────────────────┐
│ 🌍 1. 환경 (When & Context) : 시간, 자원(예산), 피드백, 생태계 │
│   └─► 밖에서 짓누르는 물리적·경제적 기압 (Input)            │
├─────────────────────────────────────────────────────────────┤
│ 👤 2. 주체 (Who & Governance) : 인지 진입점, 안전감, 권한 구조 │
│   └─► 작업을 수행하고 결단하는 뇌와 조직 (Input)             │
├─────────────────────────────────────────────────────────────┤
│ 🎯 3. 대상 (Whom & Audience) : 거리, 숙련도, 인간vs기계, 관여도│
│   └─► 결과물을 받아들일 종착지 (기획의 Why, Input)           │
├─────────────────────────────────────────────────────────────┤
│ 📦 4. 결과물 (What & Value) : 물성(점토/콘크리트), 가치 원천   │
│   └─► 빚어낼 물건의 물리적 성질 (Input)                     │
├═════════════════════════════════════════════════════════════┤
│ ⚙️ 5. 작업 방식 (How & Flow) : SM의 동적 처방 레버 (Output)  │
│   └─► 4대 중력장이 산출하는 작업 궤적 (스캐폴딩 vs 블루프린트)│
└─────────────────────────────────────────────────────────────┘
```

---

### 1. 결과물 (What & Value) : 물건의 성질 (진단)
* **핵심 준거**: 매체 물성(점토 vs 콘크리트), 가치 원천(감응/통찰 vs 무결성), 복제 의도(단발성 vs SOP), 환경 제약(규약 vs 물리법칙)
* 상세 분석 카드: [[(gen)03-1. (준거-결과물) 결과물의 형태를 가르는 4대 보편 준거]]

### 2. 주체와 거버넌스 (Who & Governance) : 뇌와 조직의 성질 (진단)
* **핵심 준거**: 인지 진입점(상향식 vs 하향식), 안전감 원천(우연 vs 통제), 동기 엔진(Why vs How), 완결성 기준(만족 vs 편집증), 의사결정 권한(1인 전결 vs 다자간 합의)
* 상세 분석 카드: [[(gen)03-2. (준거-주체) 기획·설계 주체의 성향을 가르는 4대 정성 준거]]

### 3. 외생적 환경 (When & Context) : 외기압의 성질 (진단)
* **핵심 준거**: 시간적 런웨이(시한폭탄 vs 넉넉한 버퍼), 자원·예산 한계(풍요 vs 극빈), 피드백 지연(즉각 vs 수개월), 생태계 변동성(안정 반석 vs 난기류 빙하)
* 상세 분석 카드: [[(gen)03-3. (준거-환경) 외생적 환경이 강제하는 4대 보편 준거]]

### 4. 이용 대상 (Whom & Audience) : 종착지의 성질 (진단)
* **핵심 준거**: 수용자 거리(나 자신 vs 타자), 수용자 숙련도(전문가 vs 초심자), 수용자 본성(기계 vs 인간 뇌), 수용자 관여도(캐주얼 vs 미션 크리티컬)
* 상세 분석 카드: [[(gen)03-4. (준거-대상) 이용 대상(수용자)을 판별하는 4대 보편 준거]]

### 5. 작업 방식과 프로세스 (How & Flow) : SM의 처방 레버 (처방)
* **핵심 준거**: 4대 차원의 상호작용 함수, 안전지대 임계선, 기반 종속성(말단 Leaf vs 발판 Foundation), 스펙트럼(탐색적 스캐폴딩 vs 엄격한 블루프린트 vs 하이브리드 완충)

### ⚖️ 5대 차원 종합 판정표

| 차원 (Dimension) | 핵심 진단 질문 | ⚡ 직관·즉시 실행 우세 (스캐폴딩) | 🛡️ 정밀 기획·설계 강제 (블루프린트) |
| :--- | :--- | :--- | :--- |
| **1. 결과물 (What)** | 실패 비용과 가치의 원천은? | 점토 / 감응·통찰 / 단발성 | 콘크리트 / 무결성 / 대량 SOP |
| **2. 주체 (Who)** | 수행 주체의 사고 편향과 권한은? | 상향식 / 우연 탐색 / 1인 전결 | 하향식 / 통제 무결성 / 다자간 승인 |
| **3. 대상 (Whom)** | 누가 어떤 인터페이스로 쓰는가? | 나 자신 / 전문가 / 기계 | 타자 / 초심자 / 인간의 주의력 |
| **4. 환경 (When)** | 밖에서 짓누르는 시공간 제약은? | 넉넉한 예산 / 즉각 피드백 | 시한폭탄 마감 / 극빈한 예산 / 지연 피드백 |
| **5. 프로세스 (How)** | 작업의 뼈대와 파괴 반경은? | 말단 작업(Leaf) / 독립적 수정 | 기반 작업(Foundation) / 연쇄 붕괴 위험 |
