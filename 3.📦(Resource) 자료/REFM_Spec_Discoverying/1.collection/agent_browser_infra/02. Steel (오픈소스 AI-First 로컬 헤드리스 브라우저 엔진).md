# 🛡️ Steel (오픈소스 AI-First 로컬 헤드리스 브라우저 엔진)

> [!abstract] 💡 핵심 명제
> **"외부 SaaS 클라우드에 종속되지 마라. Steel은 내 로컬 환경(Docker)에 직접 띄워 프라이빗하게 무제한 에이전트 브라우징과 UI 캡처를 돌릴 수 있는 오픈소스 AI 전용 브라우저다."**

---

### 1. 개요 및 탄생 배경
* **공식 웹사이트**: [steel.dev](https://steel.dev/)
* **오픈소스 저장소**: [GitHub - steel-dev/steel-browser](https://github.com/steel-dev/steel-browser)
* **등장 배경**:
  * Browserbase 같은 클라우드 서비스는 편리하지만 유료 크레딧 비용이 발생하고, 보안상 민감한 내부 문서나 프라이빗 사이트를 넘기기 어렵습니다.
  * Steel은 **내 PC나 사내 서버에 Docker 한 줄로 즉시 띄울 수 있는 완전 오픈소스(Self-hosted) AI 브라우저**로 탄생했습니다.

---

### 2. 핵심 아키텍처 및 킬러 기능

#### ① Puppeteer / Playwright 100% 호환 (CDP 브릿지)
* 기존 표준 라이브러리인 Playwright, Puppeteer, Selenium 코드를 단 한 줄의 변경 없이 그대로 물려 쓸 수 있습니다.
* Chrome DevTools Protocol(CDP)을 완벽 지원하므로, 에이전트가 브라우저의 DOM 계층과 렌더링 파이프라인을 기계 수준에서 정밀 제어합니다.

#### ② 핑거프린트 스푸핑 & 봇 회피 기본 탑재
* 로컬에서 일반 퍼피티어를 돌리면 Cloudflare나 구글 봇 감지에 1초 만에 튕겨 나갑니다.
* Steel은 브라우저 지문(Canvas, WebGL, 오디오 핑거프린트, 내비게이터 속성)을 실제 일반 사용자처럼 실시간 위장하여 **사이트 차단 없이 매끄럽게 레퍼런스를 순회**합니다.

#### ③ 세션 상태 및 디버거 뷰어 내장
* 로컬 도커로 실행되면서도 웹 대시보드를 제공하여, 현재 에이전트가 어떤 페이지를 탐색하고 있는지 **실시간 캔버스 화면으로 관측(Live View)**할 수 있습니다.

---

### 3. REFM (Reference Manager) 프로덕트 적용점

1. **무비용(Zero-Cost) 무제한 로컬 캡처 파이프라인**:
   - 클라우드 요금 걱정 없이, 내 로컬 환경에서 수백 개 타깃 사이트의 화면 캡처 및 레퍼런스 수집 작업을 백그라운드 데몬으로 상시 가동 가능.
2. **사내망 및 로컬 호스트(Localhost) 레퍼런스 접근**:
   - 외부 클라우드는 접근할 수 없는 로컬 개발 환경(`localhost:3000`)이나 사내 폐쇄망 인트라넷의 UI/UX 화면도 완벽하게 에이전트가 방문하여 캡처를 수집할 수 있음.
