# 🌐 Browserbase (클라우드 에이전트 브라우저 인프라 및 세션 인스펙터 타임라인)

> [!abstract] 💡 핵심 명제
> **"인간용 크롬을 로봇에게 쥐어주지 마라. Browserbase는 에이전트가 돌아다니며 조작한 모든 찰나의 순간을 스크린샷과 DOM 상태로 자동 기록하는 AI-Native 브라우저 인프라다."**

---

### 1. 개요 및 탄생 배경
* **공식 웹사이트**: [browserbase.com](https://browserbase.com/)
* **대표 오픈소스 프로젝트**: [Stagehand (GitHub)](https://github.com/browserbase/stagehand)
* **등장 배경**:
  * 기존 크롬이나 퍼피티어(Puppeteer)는 세션 유지가 불안정하고, 봇 탐지(Cloudflare)에 쉽게 차단되며, 에이전트가 조작한 중간 과정을 캡처로 남기기 어려웠습니다.
  * Browserbase는 **처음부터 AI 에이전트만을 위해 설계된 서버리스 클라우드 브라우저 플랫폼**입니다.

---

### 2. 핵심 아키텍처 및 킬러 기능

#### ① 세션 인스펙터 (Session Inspector) — [완전 자동 캡처 타임라인]
* **원리**: 에이전트가 웹페이지에 진입해 버튼을 누르고 스크롤하는 모든 과정을 브라우저 차원에서 **1초 단위 스크린샷과 비디오, DevTools 네트워크 로그로 자동 기록**합니다.
* **REFM 가치**:
  * 에이전트에게 굳이 *"지금 캡처 찍어!"*라고 지시하지 않아도, 탐색 세션이 끝나면 **대시보드와 API를 통해 중간 조작 화면 전체를 스크린샷 갤러리로 한 번에 내려받을 수 있습니다.**

#### ② Stagehand 엔진 내장 (3대 자연어 API)
* 브라우저베이시스는 자체 개발한 AI 웹 자동화 프레임워크인 **Stagehand**를 기본 제공합니다.
  * `page.act("버전 기록 메뉴를 클릭해")`: 화면을 보고 스스로 버튼을 찾아 클릭
  * `page.observe()`: 목적 달성을 위해 다음으로 취할 수 있는 후보 행동 관찰
  * `page.extract("버전 날짜와 수정자 목록만 뽑아줘")`: 원하는 데이터만 정밀 추출

#### ③ 스텔스 모드 (Stealth by Default)
* 고급 지문(Fingerprint) 위장, 주거용 프록시(Residential Proxy), CAPTCHA 자동 해결 기능을 내장하여, 타깃 서비스의 봇 탐지 알고리즘에 걸리지 않고 안정적으로 브라우징을 유지합니다.

---

### 3. REFM (Reference Manager) 프로덕트 적용점

1. **무인 UI 플로우 아카이빙**:
   - 구글 닥스나 깃북의 URL과 조사 목적을 던져주면, Browserbase 세션이 가동되어 팝업을 열고 탐색을 마친 뒤 **Session Inspector에 찍힌 깨끗한 고화질 스크린샷 셋을 볼트 `images/` 폴더로 직송**.
2. **네트워크 페이로드 동시 획득**:
   - 화면 캡처뿐만 아니라 해당 시점에 오간 통신(HAR 로그)까지 함께 보관되어, 기획 문서에 *"이 UI가 호출하는 내부 규격"*까지 한 번에 박제 가능.
