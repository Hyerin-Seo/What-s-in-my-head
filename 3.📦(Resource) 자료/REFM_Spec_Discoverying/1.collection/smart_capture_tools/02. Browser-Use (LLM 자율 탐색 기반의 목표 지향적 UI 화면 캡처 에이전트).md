# 🤖 Browser-Use (LLM 자율 탐색 기반의 목표 지향적 UI 화면 캡처 에이전트)

> [!abstract] 💡 핵심 명제
> **"단순 클릭 매크로가 아니다. Browser-Use는 인간처럼 화면을 눈으로 보고, 다음 행동을 스스로 추론하며, 목적지까지 길을 찾아가 원하는 스크린샷을 가져오는 자율 리서치 에이전트다."**

---

### 1. 개요 및 깃허브 트렌딩 반응
* **공식 웹사이트**: [browser-use.com](https://browser-use.com/)
* **오픈소스 저장소**: [GitHub - browser-use/browser-use](https://github.com/browser-use/browser-use)
* **시장 반응**:
  * 공개 직후 깃허브 글로벌 트렌딩 1위를 기록하며, **"가장 인간처럼 웹 서핑을 대신해 주는 AI 에이전트"**로 폭발적인 지지를 받았습니다.

---

### 2. 핵심 아키텍처: 자율 인지 루프 (Reasoning Loop)

Browser-Use는 고정된 코드가 아니라, 매 스텝마다 **[화면 관찰 ➔ 생각 ➔ 행동 ➔ 평가]**의 사고 루프를 돕니다.

```text
[자연어 목표 투입] ➔ "구글 닥스에서 이전 버전과 본문 Diff가 뜨는 화면을 캡처해 줘"
       │
       ▼
┌────────────────────────────────────────────────────────┐
│  [Step 1. Vision Perception] 현재 렌더링 화면 분석      │
│  [Step 2. Thought] "상단 파일 메뉴를 먼저 눌러야 함"   │
│  [Step 3. Action] 마우스 이동 & 클릭                    │
│  [Step 4. Verification] 서브메뉴가 떴는지 재확인       │
└──────────────────────────┬─────────────────────────────┘
                           │ (반복 탐색)
                           ▼
[목표 달성 확인] ➔ Diff 화면 감지 시 즉시 타깃 캡처 저장 후 종료
```

* **다단계 에러 자체 복구 (Self-Correction)**:
  - 클릭했는데 예기치 않은 팝업이 가로막고 있으면, 에이전트가 *"아, 팝업 닫기 버튼을 먼저 눌러야겠네"*라며 스스로 장애물을 치우고 본래 목적을 완수합니다.

---

### 3. REFM (Reference Manager) 프로덕트 적용점

1. **미지의 타깃 사이트 자율 탐색**:
   - 구조를 전혀 모르는 낯선 해외 신규 서비스라도, 목적(예: *"이 서비스의 가격 플랜 비교 표를 찾아 캡처해 줘"*)만 주면 스스로 사이트맵과 메뉴를 헤집고 들어가 타깃 화면을 따옴.
2. **조작 시퀀스 비디오/스텝별 캡처 자동 패키징**:
   - 최종 캡처뿐만 아니라, 그 화면에 도달하기까지 거친 **단계별 스크린샷 셋(Step-by-step screenshots)**을 타임라인 폴더로 일괄 생성.
