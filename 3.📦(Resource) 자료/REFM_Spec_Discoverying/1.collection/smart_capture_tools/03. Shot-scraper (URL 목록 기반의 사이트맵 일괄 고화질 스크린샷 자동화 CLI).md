# 📸 Shot-scraper (URL 목록 기반의 사이트맵 일괄 고화질 스크린샷 자동화 CLI)

> [!abstract] 💡 핵심 명제
> **"복잡한 AI 추론 없이, 정해진 페이지들의 전체 화면을 광속으로 찍어오고 싶을 때. Shot-scraper는 명령어 한 줄로 수십 개 사이트맵의 고해상도 스크린샷을 폴더에 꽂아 넣는 가장 가벼운 도구다."**

---

### 1. 개요 및 탄생 배경
* **공식 웹사이트**: [shot-scraper.datasette.io](https://shot-scraper.datasette.io/)
* **오픈소스 저장소**: [GitHub - simonw/shot-scraper](https://github.com/simonw/shot-scraper)
* **개발자**: 유명 파이썬 엔지니어 Simon Willison (Datasette 창시자)
* **등장 배경**:
  * 복잡한 에이전트 없이도, **"내가 찍고 싶은 10개 URL 목록을 메모장에 적어두고 명령어 한 번으로 스크린샷들을 한 번에 다운로드받고 싶다"**는 가장 단순하고 강력한 니즈를 해결하기 위해 탄생했습니다.

---

### 2. 핵심 사용법 및 작동 메커니즘

Playwright를 기반으로 동작하며, 파이썬 패키지(`pip install shot-scraper`)로 1초 만에 설치됩니다.

#### ① 단일 페이지 정밀 캡처
```bash
# 특정 웹사이트의 전체 스크롤 페이지 캡처
shot-scraper https://gitbook.com/ -o gitbook_full.png

# 특정 CSS 요소(예: 우측 패널)만 타이트하게 잘라서 캡처
shot-scraper https://example.com/ -s "#sidebar-panel" -o sidebar.png
```

#### ② 다중 URL 일괄 자동화 (YAML 설정)
메모장에 찍고 싶은 목록을 정의해 둡니다:
```yaml
# targets.yaml
- url: https://docs.google.com/...
  output: docs_home.png
  width: 1280
- url: https://gitbook.com/pricing
  output: gitbook_pricing.png
  wait: 2000 # 렌더링 완료 대기 (ms)
```
명령어 한 줄 실행:
```bash
shot-scraper multi targets.yaml
```
➔ 프로그램이 백그라운드에서 브라우저를 띄워 **목록의 모든 페이지를 방문해 지정된 파일명으로 PNG를 쏟아냅니다.**

---

### 3. REFM (Reference Manager) 프로덕트 적용점

1. **정적 사이트맵 초고속 일괄 아카이빙**:
   - 조사하려는 서비스의 핵심 서브페이지(가격표, 기능 소개, 릴리즈 노트 등) 목록을 뽑아둔 뒤, 10초 만에 스크린샷 셋을 일괄 다운로드하여 볼트 `images/`에 적재.
2. **토큰 소모 제로(Zero-Token)**:
   - LLM 추론 비용이 전혀 들지 않는 100% 무료 로컬 오픈소스 유틸리티로 상시 활용 가능.
