# 🎯 Stagehand (자연어 목적 기반의 지능형 브라우저 조작 및 정밀 캡처 프레임워크)

> [!abstract] 💡 핵심 명제
> **"깨지기 쉬운 CSS 셀렉터를 쓰지 마라. Stagehand는 인간의 언어로 된 '조사 목적'을 던지면, 스스로 버튼을 찾아 누르고 딱 그 순간의 화면만 정밀하게 낚아채는 AI 네이티브 브라우저 자동화 프레임워크다."**

---

### 1. 개요 및 탄생 배경
* **공식 웹사이트**: [stagehand.dev](https://stagehand.dev/)
* **오픈소스 저장소**: [GitHub - browserbase/stagehand](https://github.com/browserbase/stagehand)
* **등장 배경**:
  * 기존 Puppeteer/Playwright는 웹사이트의 클래스명이나 ID가 조금만 바뀌어도 스크립트가 깨져버리는 치명적 한계가 있었습니다.
  * Stagehand는 LLM(Claude, GPT 등)의 시각/텍스트 추론 능력을 브라우저 DOM과 직접 결합하여, **"자연어로 지시하면 알아서 화면을 보고 조작하는 차세대 에이전트 브라우징 API"**로 탄생했습니다.

---

### 2. 핵심 아키텍처: 3대 마법의 API

Stagehand는 수백 줄의 복잡한 스크립트 대신, 오직 **3개의 직관적인 자연어 메서드**로 동작합니다.

```typescript
// 1. 목적에 맞게 행동 유발 (Act)
await page.act("Click on the 'File' menu and select 'Version history'");

// 2. 현재 상태에서 가능한 다음 행동 관찰 (Observe)
const actions = await page.observe("Find the button to restore this version");

// 3. 목적에 부합하는 데이터만 정밀 추출 (Extract)
const data = await page.extract({
  instruction: "Extract the list of version names and their timestamps",
  schema: z.object({ versions: z.array(z.string()) })
});
```

1. **`page.act()` (자연어 행동 실행)**:
   - 셀렉터 없이 *"파일 메뉴를 누르고 버전 기록을 열어줘"*라고 적으면, 에이전트가 화면 렌더링 트리를 분석해 해당 버튼의 정확한 좌표를 스스로 찾아 클릭합니다.
2. **`page.observe()` (행동 후보 탐색)**:
   - 복잡한 대시보드에서 다음에 어디를 눌러야 목적을 달성할 수 있는지 스스로 탐색합니다.
3. **`page.extract()` (정밀 데이터 추출)**:
   - Zod 스키마와 결합하여, 화면에 표시된 텍스트와 메타데이터를 정형화된 JSON으로 뽑아냅니다.

### 3. REFM (Reference Manager) 프로덕트 적용점

1. **'조사 목적' 기반의 무인 캡처 파이프라인**:
   - 에이전트에게:
     > *"구글 닥스에서 `act('버전 이름 지정')`을 실행하고, 팝업창이 뜨면 그 바운딩 박스를 캡처해."*
   - 와 같이 지시하여, **인간이 개입하지 않아도 목적에 부합하는 4-Shot 캡처 셋을 100% 자동 생성**.
2. **UI 변경에 깨지지 않는 영구 수집기**:
   - 구글이나 깃북이 웹사이트를 리뉴얼해도 자연어로 지시하기 때문에 스크립트 수정 없이 영구적으로 동작.
