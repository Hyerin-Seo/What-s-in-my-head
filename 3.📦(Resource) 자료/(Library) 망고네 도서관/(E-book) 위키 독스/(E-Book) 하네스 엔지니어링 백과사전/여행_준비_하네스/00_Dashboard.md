## 📌 파이프라인 및 아키텍처 (Workflow)

```mermaid
flowchart TD
    In1["📌 [[family-trip-brief]]<br/>(v1: 제주도/4명/120만)"] --> A1["🤖 [[01_조건정리_Agent]]"]

    subgraph Pipeline ["🔄 중간 산출물 생성 파이프라인"]
        A1 -->|① 조건정리서| A2["🤖 [[02_숙소조사_Agent]]"]
        A2 -->|② 숙소/장소후보| A3["🤖 [[03_일정설계_Agent]]"]
        A3 -->|③ 일정초안| A4["🤖 [[04_예산확인_Agent]]"]
        A4 -->|④ 예산표| A5["🤖 [[05_준비물점검_Agent]]"]
        A5 -->|⑤ 준비물목록| A6["🤖 [[06_최종검토_Agent]]"]
        A6 -->|⑥ 최종검토안| A7["🤖 [[07_팩트체크_Agent]]"]
    end

    subgraph Verification ["🔍 검증 및 사람 승인 게이트"]
        A7 -->|⑦ 팩트체크/출처검증| Gate{"👤 사람 직접 승인<br/>(예약/결제/개인정보)"}
    end

    Gate -- "v1 승인" --> Out1["🎯 [[family-trip-report]]<br/>(제주도 가족 여행 보고서)"]
    Gate -- "v2 승인" --> Out2["🎯 [[family-trip-report-v2]]<br/>(오사카 가족 여행 보고서)"]
    Gate -- "v3 승인" --> Out3["🎯 [[family-trip-report-v3]]<br/>(제주 힙한 친구 보고서)"]
    Gate -- "수정 요청" --> S2["🛠️ [[개선반영_Skill]]"]
    S2 --> Log["📑 [[improvement-log]]"]
    S2 -.-> A3
```
