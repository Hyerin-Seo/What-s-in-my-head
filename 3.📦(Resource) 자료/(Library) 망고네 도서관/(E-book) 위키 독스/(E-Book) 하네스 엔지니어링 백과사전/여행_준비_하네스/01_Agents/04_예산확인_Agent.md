# 🤖 04. 예산확인 Agent

> **상위 대시보드**: [[00_Dashboard]]

---

## 📌 역할 및 목표
- 설계된 일정을 토대로 숙소비, 식비, 교통비, 입장료/체험비, 예비비 등을 카테고리별로 산출하고 총 예산 초과 여부를 검증합니다.

## 📥 입력 데이터
- [[03_일정설계_Agent]]의 일자별 상세 일정 초안

## 📤 중간 산출물 ④ (Output)
- **카테고리별 예산 분배표 및 검증 결과**:
  - 숙소비, 식비(끼니별 예상단가), 교통비(렌트/유류/통행료), 입장료/액티비티, 비상 예비비(10%)
  - 총 합계 금액 vs 입력된 목표 예산 비교 (초과 시 조정안 제시)

## 🔍 검증 기준 (Validation Criteria)
- [ ] 총합 예산이 목표 예산을 초과하지 않는가?
- [ ] 비상 예비비(최소 10%)가 확보되었는가?
- [ ] 누락된 필수 비용(예: 통행료, 렌트카 보험료 등)이 없는가?
