# (gen)Candidate 01 — '에이전트 온톨로지용 옵시디언' 사용 설명 페이지 빌딩 챌린지

> **챌린지 정의**: UI·UX 디자이너(Rin)가 망고독 Docs-Agent를 활용하여, 현재 팀에서 구축·운영 중인 **'에이전트 온톨로지용 옵시디언 볼트(개똥이 머릿속)'의 원천 시스템 규칙들을 빅테크(구글/MS) 기술 문서 스타일의 시각적 사용 설명서(How-to-Use Page)**로 1/10 시간 안에 스캐폴딩하고 슬롯(빈칸)을 채워 완성하는 첫 번째 실무 챌린지.

---

## 1. 챌린지 개요 및 선정 배경 (Why This Project)

1. **100% 실존하는 정본 백데이터의 힘**:
   * 가상의 모킹 데이터가 아닌, 실제로 디자이너와 PM이 매일 호흡하며 쓰고 있는 볼트 정본 규칙(`CLAUDE.md`, `AGENTS.md`, 속성 규격 등)을 백데이터로 사용합니다.
   * "지어낸 예시"가 주는 인지적 거부감을 완전히 제거하고 실무 몰입도를 극대화합니다.
2. **디자이너 본인의 실무 온보딩과 직결**:
   * 디자이너 본인(Rin)이 앞으로 옵시디언에 작업 노트를 작성할 때 지켜야 하는 온톨로지 규칙을 다루므로, 문서를 빌딩하는 과정 자체가 가장 자연스러운 볼트 온보딩 훈련이 됩니다.
3. **완벽한 '시각적 격자(Scaffold)' 구조**:
   * 온톨로지 시스템은 13종 속성 정의, 4대 폴더 접근 권한, 문법 규칙 등 대부분이 **표(Table), 매트릭스(Matrix), Do & Don't 카드**로 명확히 떨어집니다.
   * 서술형 줄글 작성 없이 **"빈칸 채우기(Slot-filling)"**만으로 문서 1장이 완성되는 망고독 스캐폴딩 엔진의 본질적 가치를 검증하기에 최적입니다.

---

## 2. 산출물 목표: 빅테크 스타일 'How-to-Use' 기술 문서 레이아웃

문서 작성자가 줄글로 길게 서술할 필요가 전혀 없도록, **문서의 80% 이상이 시각적 격자 틀(Visual Scaffold)**로 고정됩니다.

```text
┌────────────────────────────────────────────────────────┐
│ [헤더 카드] 볼트 온톨로지 개요 & 공존 주체 배지 (Rin · 민규 서 · AI)│
├────────────────────────────────────────────────────────┤
│ [1. PARA 온톨로지 구역 매트릭스] (4대 구역 역할/쓰기 권한 표) │
├────────────────────────────────────────────────────────┤
│ [2. 필수 13종 Frontmatter 속성 명세] (규격 테이블)      │
├────────────────────────────────────────────────────────┤
│ [3. Quickstart: 온톨로지 노트 작성 3-Step] (단계별 카드)  │
├────────────────────────────────────────────────────────┤
│ [4. 문법 및 무결성 수칙 Do & Don't] (2열 시각 대비 카드) │
├────────────────────────────────────────────────────────┤
│ [5. 트러블슈팅 & 린터 가이드] (파싱 크래시 방지 콜아웃)  │
└────────────────────────────────────────────────────────┘
```

## 3. 세부 구성요소별 슬롯 정의 (Slot-filling 목록)

### 1) 시스템 개요 & 공존 주체 배지 (Header Card)
* **슬롯 내용**: 볼트 명칭(`개똥이 머릿속`), 온톨로지 목적, 협업 참여자(`Rin(UI/UX)`, `민규 서(PM/Dev)`, `Agent(AI)`).

### 2) PARA 온톨로지 4대 구역 매트릭스 (Table Slot)
* 백데이터(`CLAUDE.md`)에서 4대 구역의 역할과 권한을 추출하여 표의 빈칸을 채웁니다.
  | 구역명 | 목적 및 취급 대상 | 쓰기/수정 주체 | 삭제 및 보존 규칙 |
  | :--- | :--- | :---: | :--- |
  | `1.🎯(Project) 프로젝트` | 데드라인과 목표가 있는 R&D 과제 | 사람 & 에이전트 | 완료 시 보관소 이관 |
  | `2.🌱(Area) 영역` | 지속 유지·관리되는 역할 및 책임 | 사람 중심 | 장기 보존 |
  | `3.📦(Resource) 자료` | R&D 레퍼런스, 프로토콜, 지식 자산 | 사람 & 에이전트 | 에이전트 무단 삭제 금지 |
  | `4.🗄️(Archive) 보관소` | 완료 또는 동결된 과거 산출물 | 사람 | 인간 전용 삭제 |

### 3) 필수 13종 Frontmatter 속성 명세표 (Spec Table Slot)
* 에이전트와 옵시디언이 읽는 13종 메타데이터 속성을 표의 각 행으로 1:1 맵핑하여 채웁니다.
  | 속성 키 (Key) | 타입 | 필수 | 허용 값/포맷 예시 | 설명 |
  | :--- | :--- | :---: | :--- | :--- |
  | `유형` | text | ✅ | `자료`, `프로젝트`, `영역`, `보관` | 문서의 최상위 성격 분류 |
  | `구역` | text | ✅ | `1.project`, `2.area`, `3.resource`, `4.archive` | PARA 물리 구역 매핑 |
  | `상태` | text | ✅ | `아이디어`, `진행 전`, `진행 중`, `검토 중`, `완료` | 업무 생명주기 상태 |
  | `링크` | list | ❌ | `["[[문서명]]"]` | 반드시 큰따옴표로 위키링크 래핑 |
  | `담당` / `작성자` | list | ✅ | `["[[민규 서]]"]`, `["[[Rin]]"]` | 책임자 및 에이전트 식별 |
  | *(나머지 속성군)* | ... | ... | ... | 주제, 요약, 작성일, 마감, 커버 등 |

### 4) Quickstart: 3단계 온톨로지 작성 워크플로우 (Step Cards)
* **Step 1 (템플릿 호출)**: Frontmatter 13종 자동 생성.
* **Step 2 (앵커링 & 본문 작성)**: 상위 과제 및 관련 문서를 `링크` 속성에 `"[[]]"` 형태로 연결.
* **Step 3 (린트 검증)**: 작성 완료 후 `obsidian_syntax_validator`로 파싱 크래시 여부 확인.

### 5) 문법 및 무결성 수칙 (Do & Don't Matrix)
* 디자이너와 에이전트가 가장 자주 실수하는 영역을 시각적으로 대비:
  * **DO ✅**: 위키링크 앞뒤에 큰따옴표 감싸기 (`"[[링크]]"`), 줄끝은 반드시 LF로 저장, 삭제는 사람이 직접 수행.
  * **DON'T ❌**: 따옴표 없는 생 위키링크 사용(YAML 파싱 에러 유발), CRLF 줄바꿈, 에이전트의 일괄 삭제 실행.

### 6) 트러블슈팅 & 파싱 크래시 가이드 (Callout Box)
* 옵시디언 Electron 앱에서 자주 터지는 '빨간 박스 크래시(속성창 무력화)'의 3대 원인과 즉각적인 복구 절차 표.

## 4. 디자이너에게 지급할 실제 백데이터 세트 (Raw Data Package)

가짜 데이터가 아닌, 볼트의 실제 소스 파일들을 그대로 레퍼런스로 제공합니다.

1. **`CLAUDE.md` 정본**: 볼트의 헌법, 13종 속성 목록, PARA 구역 정의 원문.
2. **`AGENTS.md` 정본**: 인간 2인과 에이전트의 협업 프로토콜 및 권한 원문.
3. **`실전 카드 샘플 2종`**: 이미 모범적으로 작성되어 린터를 통과한 `(gen)토론 카드 01` 및 `Risk 01` 원본 마크다운.

## 5. 실전 테스트 수행 절차 (망고독 조작 플로우)

* **[준비]**: 디자이너가 망고독 Reference 패널에 위 백데이터 파일들을 연결.
* **[1단계 — Scaffold 로드]**: `에이전트 온톨로지 How-to-Use 템플릿` 버튼 클릭 ➔ 표와 카드로 짜인 고정 틀이 화면에 로드됨.
* **[2단계 — 1:1 슬롯 앵커링]**:
  - `CLAUDE.md`에서 "속성 13종 표"를 드래그 ➔ 망고독 에디터의 '속성 명세표' 슬롯에 드롭 ➔ 표가 순식간에 정렬되어 채워짐.
  - "PARA 4대 구역" 텍스트를 드래그 ➔ '온톨로지 구역 매트릭스' 슬롯에 드롭 ➔ 권한 매트릭스 완성.
* **[3단계 — 조작 리뷰]**: 10분 만에 완벽한 사내 기술 문서 1장이 완성되는 1/10 시간 단축 실측.

## 6. 사용성 검증 지표 (Definition of Done)

- [ ] **실용적 몰입감**: 디자이너가 "이건 지금 당장 우리가 써야 하는 매뉴얼이네"라고 실전성을 느꼈는가?
- [ ] **빈칸 채우기 직관성**: 표와 매트릭스의 빈칸을 보고 백데이터에서 무엇을 끌어와야 할지 지체 없이 파악했는가?
- [ ] **소요 시간**: 수작업 작성(기준 약 45~60분) 대비 망고독 보조로 10분 내에 완성(1/5~1/10 단축)했는가?
- [ ] **규격 적합성**: 완성된 문서가 옵시디언 린터(`obsidian_syntax_validator`)를 에러 0건으로 통과하는가?
