# (gen)Candidate 03 — '이커머스 상품 상세설명서' 재조립 챌린지 (다채널 레퍼런스 기반 스펙·USP 스캐폴딩)

> **챌린지 정의**: UI·UX 디자이너(Rin)가 신규 론칭할 이커머스 상품을 대상으로, **기존 여러 플랫폼(스마트스토어, 쿠팡, 와디즈, 제조사 원문)에 흩어져 있는 서로 다른 버전의 상세설명서들을 백데이터로 수집하여, 우리 쇼핑몰의 고정 시각 틀(스펙 표, 핵심 USP 카드, 옵션 매트릭스)에 맞게 나만의 방식으로 재조립(Curate & Reassemble)**해보는 세 번째 실무 챌린지.

---

## 1. 챌린지 개요 및 선정 배경 (Why This Project)

1. **디자이너의 실무 직관과 100% 일치**:
   * 이커머스 상품 상세페이지와 스펙 시트는 UI·UX 디자이너에게 가장 친숙하고 일상적인 도메인입니다.
   * "헤더 카피 ➔ 특장점 카드 ➔ 상세 제원 표 ➔ 주의사항/FAQ"라는 문서 구조를 보는 즉시 직관적으로 이해할 수 있습니다.
2. **'창작'이 아닌 '다중 레퍼런스 재조립'의 현실성**:
   * 실무에서 상세설명서를 쓸 때 아무것도 없는 백지에서 글을 쓰지 않습니다.
   * 이미 존재하는 **[A채널의 감성 문구] + [B채널의 직관적 스펙 표] + [공식 제조사의 엄격한 기술 제원]**을 한데 모아놓고, 좋은 점만 쏙쏙 뽑아 우리 쇼핑몰 규격으로 재구성하는 것이 실제 업무 동선입니다.
3. **다중 컨텍스트 합성(Multi-source Synthesis)의 사용성 관측**:
   * 1개의 문서가 아니라 **'서로 포맷이 다른 3개의 레퍼런스'**를 대조하며 하나의 정형화된 틀로 모으는 작업이므로, 기존 채팅창 인터페이스가 얼마나 다중 문서 조합에 취약하고 피로한지 자연스럽게 경험해볼 수 있습니다.

## 2. 산출물 목표: 규격화된 상품 상세설명서 레이아웃 (Visual Scaffold)

문서의 80%가 **시각적 카드, 스펙 매트릭스 표, Q&A 콜아웃**으로 고정됩니다.

```text
┌────────────────────────────────────────────────────────┐
│ [헤더 USP 카드] 상품명, 카테고리, 3대 핵심 셀링포인트   │
├────────────────────────────────────────────────────────┤
│ [1. 상세 제원 및 스펙 명세 (Spec Table)] (규격 표)     │
│   → 소재, 치수, 무게, 소비전력, 인증번호, 제조국       │
├────────────────────────────────────────────────────────┤
│ [2. 옵션 및 구성품 매트릭스 (Option Grid)] (선택 표)    │
│   → 옵션명, 패키지 구성, 추가 구성품, 권장 사용자       │
├────────────────────────────────────────────────────────┤
│ [3. 실사용 체크포인트 Do & Don't] (2열 대비 카드)       │
│   → 호환 기기, 올바른 사용법 vs 고장 유발 주의사항      │
├────────────────────────────────────────────────────────┤
│ [4. 고객 빈출 Q&A (FAQ Block)] (아코디언/콜아웃)        │
└────────────────────────────────────────────────────────┘
```

## 3. 작업자에게 지급되는 3채널 백데이터 세트 (Raw Data Package)

동일한 특정 상품(예: 인체공학 무선 버티컬 마우스)에 대한 **3가지 서로 다른 채널의 원천 텍스트**:

1. **`ref_channel_A_wadiz.md` (펀딩/스토리형 레퍼런스)**:
   * 손목 터널증후군 고통 호소, 개발 비하인드 스토리, 감성적 후킹 카피, 임상 테스트 인용구 중심.
2. **`ref_channel_B_coupang.md` (커머스 직관형 레퍼런스)**:
   * 빠른 배송 강조, 핵심 기능 불릿 포인트(무소음 클릭, 3단계 DPI, C타입 충전), 실사용자 리뷰 요약 중심.
3. **`ref_channel_C_manufacturer_spec.txt` (제조사 공식 제원서)**:
   * 센서 모델명(PAW3212), 배터리 용량(500mAh), 블루투스 5.2/2.4G 듀얼 무선 주파수 대역, KC 인증 번호 등 딱딱하고 정밀한 수치 데이터.

## 4. 작업 진행 및 정지 가이드 (Stop-on-Fatigue Protocol)

작업자는 기존 ChatGPT/Claude 웹 채팅창에 위 3가지 레퍼런스를 제공하고, **"이 3개 자료를 조합해서 우리 쇼핑몰 규격의 상세설명서(헤더 USP + 스펙 표 + 옵션 매트릭스)를 만들어줘"**라고 요청해 봅니다.

이때 결과를 완벽하게 뽑으려고 애쓸 필요가 전혀 없습니다.

> **🛑 즉시 정지 기준 (Stop Threshold)**:  
> 3개 채널의 서로 다른 텍스트를 대조하고 합치는 과정에서 **"작업이 너무 복잡해져서 피로하다"**, 혹은 **"원하는 대로 표나 구성이 정렬되지 않아 너무 불편하다"**고 느껴지는 순간이 오면, **그 즉시 작업을 멈추십시오.**

* 10분을 시도했든, 3분을 시도했든 아무 상관 없습니다.
* 3개 채널 자료를 섞을 때 어디서 헷갈렸는지, AI가 표 서식을 마음대로 생략하거나 딴소리를 할 때 어느 지점에서 손을 놓고 싶어졌는지를 솔직하게 남기면 그것으로 충분합니다.
