# (gen)Step 01 — 프로젝트(Projects)로 영구 지식 베이스캠프 구축 (Knowledge Grounding)

> **Step 01 헌법**:  
> *"새 대화창을 열 때마다 사내 규칙을 복붙하는 사람은 하수다.  
> **클로드 프로젝트(Projects)에 사내 헌법과 핵심 백데이터를 단 한 번만 등록**해 두면, 그 프로젝트 안의 모든 에이전트는 우리 회사 10년 차 직원처럼 기억을 유지한다."*

---

## 1. 왜 '프로젝트(Projects)'가 첫 번째 하네스인가?

일반적인 챗봇 사용 방식은 매 대화방마다 "우리 회사는 이런 규칙이 있고, 이런 용어를 쓰며, 이 문서를 참고해줘..."라며 **수천 자의 프롬프트를 복붙하는 단순 노동**의 연속입니다.

클로드의 **'프로젝트(Projects)'**는 이 반복 노동을 영구히 종결짓는 하네스입니다:
* 특정 프로젝트 폴더를 하나 만들고, 그 안에 사내 문서들을 **'프로젝트 지식(Project Knowledge)'**으로 한 번만 업로드해 둡니다.
* 이후 그 프로젝트 안에서 생성되는 모든 채팅은 **업로드된 문서를 자동으로 뇌에 탑재한 상태**로 시작됩니다.

---

## 2. 프로젝트 지식에 반드시 넣어야 할 3대 핵심 파일

대기업이나 전문 에이전시가 프로젝트 지식에 세팅하는 3가지 필수 자산:

```text
┌────────────────────────────────────────────────────────┐
│ [파일 1] 브랜드/사내 헌법 가이드 (Brand & Tone Guide)   │
│   → 사내 공식 용어집, 금기 단어 목록, 공식 서식 수칙   │
├────────────────────────────────────────────────────────┤
│ [파일 2] 모범 산출물 샘플 (Gold Standard Samples)     │
│   → 과거 결재를 100% 통과한 최고 퀄리티의 보고서 2~3편 │
├────────────────────────────────────────────────────────┤
│ [파일 3] 프로덕트/서비스 백데이터 (Core Specifications) │
│   → 우리가 만드는 제품의 핵심 기능 명세 및 최신 수치   │
└────────────────────────────────────────────────────────┘
```

---

## 3. 실전 하네스: 프로젝트 커스텀 지침(Custom Instructions) 템플릿

프로젝트 우측의 **'Set custom instructions'**란에 영구 박아둘 시스템 프롬프트:

```text
[Step 01 프로젝트 커스텀 지침 템플릿]
"당신은 [우리 팀/프로젝트명] 전담 수석 테크니컬 라이터입니다.

[상시 준수 원칙]:
1. 프로젝트 지식(Project Knowledge)에 업로드된 사내 문서들을 모든 답변의 최우선 기준으로 삼으십시오.
2. 사내 공식 용어 사전에 등재된 단어만 사용하고, 일반 포털 사이트의 번역투 용어는 자동 교정하십시오.
3. 모든 출력물은 [파일 2. 모범 산출물]의 개조식 기호 위계(□ ➔ - ➔ · ➔ ※)를 100% 복제하십시오.
4. 사용자가 별도 지시를 내리지 않아도 기본 톤앤매너는 '신뢰감 있는 비즈니스 전문 어조'를 유지하십시오."
```

## 4. 효과 및 망고독(Scaffolding) 연결점

* **효과**: 대화방을 100개 새로 열어도 **복붙할 필요 없이 우리 팀의 룰과 지식을 100% 탑재한 에이전트와 즉시 협업 시작**.
* **망고독 연결**: 망고독의 **워크스페이스(Workspace) 및 지식 볼트 바인딩**이 바로 이 프로젝트 베이스캠프의 상위 호환 아키텍처입니다.
