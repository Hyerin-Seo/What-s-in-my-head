# (gen)Step 03 — 상황별 3대 보고서 템플릿 프롬프트 가동 (Executive · Standard · Deepdive)

> **Step 03 헌법**:  
> *"보고서 양식을 처음부터 고민하지 마라.  
> 실무에서 쓰이는 보고서는 **[1p 임원 요약형], [3p 표준 협의형], [딥다이브 심층 비교형]의 3대 템플릿**으로 90% 수렴된다. 상황에 맞는 템플릿을 골라 단 1회 지시로 완성하라."*

---

## 1. 실무를 지배하는 3대 보고서 템플릿의 성격

'퇴사한아빠' 영상에서 제공하는 100개 프롬프트 중, 회사 실무에서 가장 빈출되는 **3가지 핵심 템플릿 하네스**입니다.

```text
┌────────────────────────────────────────────────────────┐
│ [Template A] 1p Executive Summary (경영진 직보용)      │
│   → 30초 내 의사결정: 1줄 결론 + 핵심 수치 + 리스크 요약│
├────────────────────────────────────────────────────────┤
│ [Template B] 3p Standard Report (팀장/부서 간 협의용)   │
│   → 배경 ➔ 현황 분석 ➔ 3대 추진 과제 ➔ 일정 및 예산   │
├────────────────────────────────────────────────────────┤
│ [Template C] Deep-dive Comparative (기술/솔루션 비교형) │
│   → 제품 A vs B vs C 상세 매트릭스 표 + 장단점 심층 대조 │
└────────────────────────────────────────────────────────┘
```

---

## 2. 3대 템플릿 실전 하네스 프롬프트 팩 (복사하여 바로 사용)

### ① 템플릿 A: 1p Executive Summary (원 페이지 보고서)
```text
[템플릿 A 프롬프트]
"업로드된 소스를 기반으로 경영진(C-Level) 직보를 위한 [1-Page Executive Summary]를 작성하십시오:

1. [보고 제목]: 직관적인 결론형 문장 (수치 포함)
2. [핵심 요약 (Key Findings)]: 소스에서 가장 중요한 3대 팩트 (각 1줄 개조식)
3. [현황 및 시사점]: 문제의 근본 원인과 조직에 미치는 비즈니스 영향 (표 1개 포함)
4. [최종 권고안 및 제언]: 경영진이 즉시 승인해야 할 구체적 Action Item 2가지
* 제약: A4 1장(1,200자)을 절대 초과하지 말 것."
```

### ② 템플릿 B: 3p Standard Business Report (표준 비즈니스 보고서)
```text
[템플릿 B 프롬프트]
"업로드된 소스를 바탕으로 부서 간 협의 및 결재를 위한 [3-Page 표준 비즈니스 보고서]를 작성하십시오:

- 제1장. 추진 배경 및 대내외 환경 분석 (시장 데이터 및 내부 현황)
- 제2장. 핵심 쟁점 및 상세 문제 분석 (장애 요인 3선 분석 표)
- 제3장. 단계별 대응 전략 및 세부 실행 계획 (마일스톤 및 담당 R&R)
- 제4장. 소요 예산 및 기대효과 (정량적/정성적 ROI)
* 제약: 각 장(Chapter)마다 반드시 1개 이상의 데이터 비교 표를 포함할 것."
```

### ③ 템플릿 C: Deep-dive Comparative Analysis (다자간 비교 분석 보고서)
```text
[템플릿 C 프롬프트]
"업로드된 소스들에 등장하는 핵심 대상(예: 도구 A vs 도구 B vs 도구 C)을 심층 비교 분석하십시오:

1. [종합 비교 평가표]:
   | 평가 항목 | 대안 A | 대안 B | 대안 C | 핵심 차이점 |
   | 기능 완성도 | | | | |
   | 도입 비용/ROI | | | | |
   | 학습 곡선 및 리스크 | | | | |
2. [영역별 심층 분석]: 각 대안의 결정적 장점과 치명적 한계 기술
3. [최종 채택 권고안]: 우리 팀 상황에 가장 적합한 최종 1개 대안 선정 및 사유"
```

## 3. 효과 및 망고독(Scaffolding) 연결점

* **효과**: 프롬프트 핑퐁 없이, **단 1회의 명령으로 경영진 결재 라인에 즉시 올릴 수 있는 완성형 보고서 레이아웃이 쏟아져 나옴**.
* **망고독 연결**: 망고독의 **스캐폴딩 템플릿 보관함(Scaffold Presets)**에 이 3대 보고서 틀이 기본 내장되어 작업 시간을 1/10로 단축시킵니다.
