# (gen)Step 02 — 보고서 스타일 빌더 5대 파라미터 세팅 (Style Builder 5 Options)

> **Step 02 헌법**:  
> *"AI의 문체를 운에 맡기지 마라.  
> **[구조 + 톤앤매너 + 분량 + 서술방식 + 타겟독자]라는 5개의 하네스 다이얼**을 먼저 세팅할 때, 경영진부터 실무자까지 보고 대상에 딱 맞춘 맞춤형 장표가 완성된다."*

---

## 1. 왜 '스타일 빌더(Style Builder)'인가?

노트북LM에 소스를 넣고 "요약해줘"라고만 하면, AI는 위키백과 스타일의 건조한 줄글을 출력합니다.  
회사 실무에서는 **보고를 받는 사람의 직급과 보고 상황에 따라 완전히 다른 서식과 어조**가 요구됩니다:
* CEO에게는: **"1장짜리 핵심 결론 중심 개조식"**
* 팀장에게는: **"3장짜리 원인 분석 및 대안 비교표"**
* 고객사/투자자에게는: **"격식 있는 서술형 비즈니스 제안서"**

'퇴사한아빠' 영상의 핵심 무기는 바로 이 문체를 기계적으로 통제하는 **'스타일 빌더 5대 파라미터 하네스'**입니다.

---

## 2. 스타일 빌더 5대 통제 다이얼 매트릭스

| 파라미터 축 | 선택 가능한 하네스 옵션 | 실무 적용 시점 |
| :--- | :--- | :--- |
| **1. 구조 (Structure)** | ① 1p Executive 요약 / ② 3p 표준 보고서 / ③ 딥다이브 심층 분석 | 보고 시간(30초 vs 5분 vs 30분)에 따라 결정 |
| **2. 톤앤매너 (Tone)** | ① 격식 있는 공문서체 / ② 날카로운 전략 컨설팅체 / ③ 친절한 실무 설명체 | 사내 결재 vs 전략 회의 vs 온보딩 매뉴얼 |
| **3. 분량 (Length)** | ① A4 1장 엄수 / ② 1,500자 표준 / ③ 섹션별 무제한 상세 기술 | 장표 분량 제약 조건에 따라 선택 |
| **4. 서술 방식 (Narrative)** | ① 두괄식 개조식(-, ·, ※) / ② 완성형 줄글 문장 / ③ 표·매트릭스 중심 | 팩트 중심 보고 vs 기획 스토리텔링 |
| **5. 타겟 독자 (Audience)** | ① C-Level (CEO/임원) / ② 실무 팀장 (Lead) / ③ 외부 투자자/고객사 | 의사결정권자의 배경 지식 수준에 맞춤 |

---

## 3. 실전 하네스 프롬프트 템플릿 (스타일 빌더 일괄 세팅)

보고서 생성 프롬프트 상단에 아래 블록을 반드시 선언합니다.

```text
[Step 02 스타일 빌더 주입 프롬프트]
"업로드된 소스를 바탕으로 아래 [스타일 빌더 파라미터]를 엄격히 준수하여 보고서를 작성하십시오:

[스타일 빌더 설정값]:
1. 구조: [① 1p Executive 요약] (배경 ➔ 핵심 이슈 ➔ 해결책 ➔ 기대효과 4단 구성)
2. 톤앤매너: [② 날카로운 전략 컨설팅체] (사족을 배제하고 결론 중심의 단호한 문체)
3. 분량: [① A4 1장 분량 엄수] (공백 포함 1,200자 이내로 압축)
4. 서술 방식: [① 두괄식 개조식] (모든 항목은 '□ ➔ - ➔ ※' 기호 체계로 작성하고 명사형으로 종결)
5. 타겟 독자: [① C-Level 경영진] (전문 기술 용어는 최소화하고 비즈니스 임팩트와 비용 중심으로 서술)"
```

## 4. 효과 및 망고독(Scaffolding) 연결점

* **효과**: AI가 횡설수설하지 않고, **작업자가 다이얼로 설정한 사내 보고 규격에 100% 동기화된 완벽한 문체로 출력**.
* **망고독 연결**: 망고독의 **폼/인스펙터 패널(Inspector Options)**이 바로 이 5대 설정을 드롭다운 클릭으로 에이전트에 주입하는 물리적 인터페이스입니다.
