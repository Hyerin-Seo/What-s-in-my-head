> **레퍼런스 원천**: 유튜브 — *["99%가 모르는 AI 보고서 작성법(직장인 필수) \| 무료 도구 꿀조합으로 회사 보고서 형식 100% 복제하기"](https://www.youtube.com/watch?v=rOqZomcuaIc)*  
> **하네스 본질**: *"단 하나의 AI에게 '보고서 써줘'라고 몰아주면 100% 환각과 엉성한 줄글이 나온다. 기획(ChatGPT) ➔ 검색 및 팩트 검증(Perplexity) ➔ 양식 복제 초안(ChatGPT/Claude) ➔ 비즈니스 윤문(Claude)으로 **각 단계별 최적화된 도구를 파이프라인으로 연결하는 '분업 하네스(Multi-AI Pipeline)'**를 구축할 때 회사 양식이 100% 복제된다."*

## 1. 왜 이 영상이 '문서 작성 하네스'의 정석인가?

01번 영상(대기업 장표 AI PPT)이 **슬라이드의 시각적 셰이프와 블록 레이아웃**을 통제하는 하네스였다면,  
이번 02번 영상은 **"텍스트 기반의 정밀 기획 보고서(줄글 + 표 + 실제 팩트 출처)"를 빈틈없이 완성하는 도구별 분업 하네스**를 다룹니다.

* **올인원 환상 타파**: 한 챗봇 안에서 기획, 검색, 본문 작성, 윤문을 다 하려 들면 AI의 컨텍스트가 오염되고 헛소리가 섞임.
* **전문 도구의 기능적 하네스 분업**: 
  1. 기획/목차는 창의적 발상에 강한 도구(ChatGPT)
  2. 데이터/출처는 실시간 웹 인덱싱에 강한 도구(Perplexity/Liner)
  3. 사내 양식 복제는 모듈러 분절 프롬프트
  4. 최종 윤문은 문맥 파악과 자연스러운 비즈니스 개조식 문체에 강한 도구(Claude)

## 2. 사내 보고서 100% 복제 4단계 파이프라인 총람

```text
┌────────────────────────────────────────────────────────┐
│  [Step 01] 기획 및 목차 다변화 (ChatGPT)               │
│  → 10년 차 전략기획 전문가 페르소나 주입 + 3버전 목차 트리│
├────────────────────────────────────────────────────────┤
│  [Step 02] 팩트 수집 및 교차 검증 (Perplexity / Search) │
│  → 환각 원천 차단! 최신 통계, 공공 데이터, 출처 링크 확보 │
├────────────────────────────────────────────────────────┤
│  [Step 03] 사내 양식 복제 및 파트별 작성 (Modular)    │
│  → 기존 회사 모범 보고서를 주입(Few-shot)하고 파트별 분절│
├────────────────────────────────────────────────────────┤
│  [Step 04] 비즈니스 개조식 윤문 및 구조화 파일화(Claude)│
│  → 두괄식 개조식(-, ·, ※) 윤문 + Markdown/DOCX 내보내기│
└────────────────────────────────────────────────────────┘
```

| 단계 | 담당 도구 / 역할 | 통제 하네스 (Harness Mechanism) | 산출물 및 효과 |
| :--- | :--- | :--- | :--- |
| **[[Step 01]]** | ChatGPT (기획) | 전문가 페르소나 + 3가지 관점 목차 트리 생성 | 보고서의 전체 뼈대와 논리 전개 방향 확정 |
| **[[Step 02]]** | Perplexity (검색) | 실시간 검색 쿼리 + 출처 링크 교차 검증 | 환각 없는 100% 실측 통계 및 팩트 앵커 확보 |
| **[[Step 03]]** | 챗봇 (파트별 초안) | 과거 사내 모범 보고서 스타일 주입 (In-context) | 회사 특유의 보고서 서식/톤앤매너 100% 복제 |
| **[[Step 04]]** | Claude (윤문/내보내기) | 비즈니스 개조식(두괄식 요약) 윤문 규칙 | 경영진 보고용 최종 정형 문서(Markdown/DOCX) |

## 3. 온보딩 2단계 실행 요령 (Rin을 위한 가이드)

1. 작업자(Rin)는 **Step 01부터 Step 04까지의 카드를 순서대로 확인**하며, 각 단계에서 어떤 도구와 프롬프트 하네스를 쓰는지 파악합니다.
2. 1단계 Candidate 과제(예: 옵시디언 가이드, 나무위키 엔트리, 상세설명서 등)를 작성할 때, **"한 챗창에서 다 쓰려 하지 말고, [목차 ➔ 팩트 검색 ➔ 양식 복제 ➔ 윤문]으로 쪼개어 적용"**해 봅니다.
3. 단계별로 도구를 바꾸어가며 작업할 때 **"에이전트가 헛소리를 하지 않고 회사 양식에 딱 맞게 정렬되는 쾌감"**을 실측합니다.
