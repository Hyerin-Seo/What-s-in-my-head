## 1. 프로토타입 개요 및 검증 목표

* **유형**: Fake Door / Smoke Test (Live-Data Prototype 계열)
* **제작 도구**: 노션 웹(Notion Site), Framer, 또는 간이 랜딩페이지 빌더 (제작 소요 1일)
* **주관 R&R**: PM + Growth/Marketing 주도
* **핵심 검증 목표**:
  1. **정량적 수요 크기**: 대중 시장의 타깃 빌더들이 이 솔루션의 가치 제안에 실제로 반응하는가?
  2. **화폐 결속 클릭률 (CVR)**: 결제 금액이 명시된 CTA 버튼을 실제로 클릭할 만큼 지불 의향(WTP)이 실재하는가?

## 2. 1페이지 랜딩페이지 3대 핵심 구성 스펙

불필요한 회사 소개나 긴 텍스트를 배제하고 오직 3가지 핵심 요소만으로 1스크린 구성:

```text
┌────────────────────────────────────────────────────────────────────────┐
│  1. 강력한 헤드카피 (Problem-Solution Fit)                             │
│     "백데이터 100쪽을 30초 만에 인덱싱하여                              │
│      쪽수 앵커가 달린 30장 완제품 제안서를 직조하는 MangoDoc"            │
├────────────────────────────────────────────────────────────────────────┤
│  2. 30초 실작동 시뮬레이션 데모 영상                                  │
│     • Figma 프로토타입 조작 화면을 30초 분량으로 녹화/GIF 임베딩        │
│     • PDF 업로드 ➔ Composer 프롬프트 ➔ 팩트 앵커 제안서 직조 연출       │
├────────────────────────────────────────────────────────────────────────┤
│  3. 명확한 가격 정책 및 실제 결제 CTA 버튼                             │
│     [ 월 39,000원 결제하고 비공개 알파 시작하기 ➔ ]                     │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. 트래픽 배포 및 페이크 도어 인터랙션 시나리오

### Step 1: 타깃 커뮤니티 배포 (콜드 트래픽 유입)
* 사업계획서, 정부 지원사업, 연구보고서 작성이 잦은 커뮤니티에 링크 배포:
  * 디스콰이엇(Disquiet), 창업 단톡방, 대학원생/연구원 커뮤니티, 링크드인.
  * 광고 집행 시 10만 원 안팎의 소액 메타/구글 검색 광고 집행 가능.

### Step 2: 결제 버튼 클릭 시 인터랙션 (Fake Door)
* 사용자가 `[월 39,000원 결제하고 비공개 알파 시작하기]` 버튼을 클릭하는 순간, 실제 PG사 결제창 대신 아래 정중한 팝업을 띄움:

```text
┌────────────────────────────────────────────────────────────┐
│  🎉 성원에 감사드립니다!                                    │
│                                                            │
│  현재 MangoDoc 비공개 알파 30명 정원이 조기 마감되었습니다.   │
│  아래에 이메일을 남겨주시면, 1차 정식 오픈 시 1호 알림과     │
│  함께 [첫 달 무료 이용 쿠폰]을 발송해 드립니다.              │
│                                                            │
│  [ 이메일 주소 입력란              ]  [ 1호 알림 받기 ]     │
└────────────────────────────────────────────────────────────┘
```

### Step 3: 데이터 로깅
* `방문자 수 (Unique Visitors)`
* `결제 버튼 클릭 수 (Button Clicks)`
* `이메일 등록 수 (Lead Conversions)`

## 4. 정량 승패 판정 기준 (Quantitative Kill Criteria)

핵심 지표는 **방문자 대비 결제 버튼 클릭 전환율 (CVR = 결제 버튼 클릭 수 / 고유 방문자 수)**:

| 지표 구간 | 판정 결과 | 해석 및 후속 액션 |
| :--- | :--- | :--- |
| **CVR ≥ 5%** | **합격 (Pass)** | **시장 지불 의향 확실히 입증**. 본 제품 개발(엔지니어링) 착수 승인 |
| **1% ≤ CVR < 5%** | **경고 (Warning)** | 니즈는 있으나 가격 저항이 크거나 헤드카피가 모호함. 카피/가격 수정 후 1회 재실험 |
| **CVR < 1%** | **사망 (Fail / Pivot)** | 시장의 고통이 크지 않거나 솔루션 매력도 결여. **제품화 즉각 중단 및 피봇** |

---

## 5. 윤리적 운영 가이드라인
* 결제 버튼을 누른 고객에게 불쾌감을 주지 않도록 "조기 정원 마감" 프레이밍을 사용하며, 등록 고객에게는 반드시 [정식 오픈 시 1개월 무료 쿠폰]을 제공하여 보상한다.
* 고객에게 허위 결제를 완료시키거나 카드 번호를 탈취하지 않는다.
