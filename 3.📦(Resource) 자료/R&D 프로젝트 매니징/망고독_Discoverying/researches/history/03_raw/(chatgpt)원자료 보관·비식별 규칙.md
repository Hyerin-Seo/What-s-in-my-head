# 원자료 보관·비식별 규칙

`03_raw/P01/`처럼 참가자 ID별 폴더를 만들며, 원문 녹취·영상·원문 문서는 접근 권한이 있는 별도 보관소에 둔다. 이 볼트에는 비식별 관찰 메모와 접근 경로만 남긴다.

| 구분 | 허용 | 금지 |
| --- | --- | --- |
| 참가자 식별 | P01 같은 ID | 실명, 연락처, 회사 비밀, 고객명 |
| 문서 예시 | 허가받은 비식별 발췌·대체 자료 | 무단 원문 업로드·공유 |
| 발화 | 원문 위치·시각과 함께 인용 | 출처 없는 “사용자 증언” |
| 해석 | 관찰 다음에 별도 기록 | 관찰처럼 보이게 해석을 섞기 |

원자료가 삭제되거나 접근 불가해졌으면 해당 Evidence ID를 `확인 불가`로 바꾸고, 이전 결론의 근거로 사용하지 않는다.
