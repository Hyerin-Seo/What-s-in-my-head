# Problem Interview Guide

## 진행 순서 — 45~60분

1. 동의와 비식별 원칙을 설명한다. 사람을 평가하는 것이 아니라 작업 흐름을 이해한다고 알린다.
2. 제품 설명 없이 최근 실제 문서 한 건을 고르게 한다.
3. 시작부터 제출까지 시간선을 재구성한다.
4. 사용한 자료·도구·사람·수정·확인 행동을 구체화한다.
5. 이미 사용한 대안, 전환 비용, 실패한 우회를 확인한다.
6. 마지막에만 다음 실제 업무와 후속 관찰 가능성을 묻는다.

## 핵심 질문

- 마지막으로 그 문서를 작성한 때를 처음부터 보여 주실 수 있나요?
- 어떤 자료를 어떤 순서로 열었고, 무엇을 복사·검토·수정했나요?
- 시간이 가장 많이 들거나 멈춘 순간은 언제였나요?
- 그때 이미 해 본 해결책은 무엇이고, 왜 충분하지 않았나요?
- 결과가 틀리거나 형식이 어긋나면 실제로 어떤 일이 생기나요?
- 같은 작업이 다시 생기면 무엇을 똑같이 쓰고, 무엇을 바꾸겠나요?

## 금지와 기록

- `2D Canvas`, `레퍼런스 역공학`, `스캐폴딩`, 가격을 먼저 말하지 않는다.
- “필요하지 않나요?”, “더 좋지 않나요?”처럼 답을 유도하지 않는다.
- 발화와 관찰을 분리하고, 정확한 인용은 녹취 시각 또는 비식별 메모 위치를 남긴다.
- 가설과 반대되는 사례를 같은 비중으로 [[(chatgpt)Evidence Matrix]]에 기록한다.
