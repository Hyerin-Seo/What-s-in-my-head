# 참가자 Screener

## 확인 질문

1. 최근 60일 안에 여러 참고자료를 바탕으로 검토·승인용 문서를 작성하거나 최종 검토한 경험이 있습니까?
2. 그 문서는 어떤 목적이었고, 누가 어떤 기준으로 검토했습니까?
3. 과거 문서·조직 양식·명시적 형식 제약을 따라야 했습니까?
4. 참고자료는 몇 개였고 어떤 형식이었습니까?
5. 당시 실제 사용한 도구와 사람의 도움은 무엇이었습니까?
6. 비밀 정보를 제외한 작업 흐름을 화면 공유 또는 비식별 사례로 설명할 수 있습니까?
7. 향후 30일 안에 유사한 실제 작업이 예정돼 있습니까?

## 선별 규칙

- 최근 실제 사례가 없는 경우 제외한다.
- AI 도구를 쓰지 않은 사례도 적극 포함한다.
- 같은 회사·친한 지인·같은 커뮤니티에 편중된 경우는 모집 현황에 표시하고 다른 채널을 보충한다.
- 참가자에게 “AI 문서 Workspace”나 “2D Canvas”를 미리 설명하지 않는다.
