## 3. 판정과 실행 통제

- P01~P18은 `충족(1) / 부분 충족(0.5) / 미충족(0) / 판정 불가`로 기록한다.
- 치명 오류가 하나라도 있으면 합계와 무관하게 `제출 위험`으로 표기한다.
- 실행 기록에는 입력 해시, 모델/도구/플랜, 허용한 검색/도움, 완료/재확인 시간, 요구별 점수, 반출 파일의 형식 통제 결과를 남긴다.
- 입찰 서식에는 개인정보가 포함될 수 있으므로 실험에 실제 이름·주민등록번호·회사 등록번호·서명·가격을 넣지 않는다.
