# T-009 요구사항·양식 매핑 기준선

## 과업 정의와 앵커 규칙

- 입력: `01_공고문.pdf` 11쪽, `02_RFP.zip` (3개 세부 RFP PDF), `03_연구개발계획서_양식.hwpx` (9,907자), `04_기타양식.hwpx` (7,200자).
- 산출: `원문 앵커 → 요구사항 → HWPX 양식 위치 → 통과 규칙` 구조화 매핑.
- 2차(T-002)와 동일한 사업의 4차 공고로, 양식 서식은 동일하지만 **지정 공모 주제 3종**(심우주탐사, AAM 버티포트, 비행시험센터)의 예산과 기술 요구가 완전히 다르다.
- **기관부담연구개발비 면제 조항** 및 **위탁정산수수료 별도 계상 의무**가 정확히 반영되었는지를 엄격히 검수한다.
