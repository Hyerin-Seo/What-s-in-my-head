# 현황 조사 01 — 기존 문서 편집·협업 AI 6종

> **범위**: 2026-09-28에 수집한 공식 1차 출처 18건. 이 문서는 기능·제약 현황이며, 사용자 문제·시장 수요·제품 우위를 증명하지 않는다.

## 확인된 현황

| 서비스 | 공식 문서에서 확인한 기능 | 문서 작업에 중요한 제약·조건 |
| --- | --- | --- |
| Word + M365 Copilot | Word 안에서 초안 작성, 다듬기, 문서 이해·요약 | 기능은 구독·라이선스·테넌트 설정의 영향을 받음 |
| Google Docs + Gemini | Docs 안의 생성·개선·요약, Workspace 데이터 처리 안내 | 적격 Workspace 또는 Google AI 플랜 필요 |
| Notion + Notion AI | 문서 작성·편집, workspace/연결 앱/웹 검색, 파일 읽기 | 기능·모델·보안 설정·내보내기 방식이 플랜별로 다름 |
| Coda Docs AI | 문서 안에서 표 구성, 초안·편집, 댓글 처리 | 베타 상태이며 역할·AI 크레딧·문서 한도가 적용됨 |
| Confluence + Rovo | 연결 자료를 활용한 검색·초안·에이전트, Confluence 내보내기 | Cloud 플랜·크레딧·연결 데이터의 권한과 색인 범위를 확인해야 함 |
| ClickUp Docs + Brain | 접근 권한 내에서의 Brain 사용, Docs 협업·내보내기 | 역할·플랜·AI 크레딧에 따라 접근이 다르며, 임베드와 대량 Docs 내보내기에 제약이 있음 |

각 행의 원문 3건은 [[(chatgpt)필수 서비스 Source Register]]에 연결했다.

## 기존 가설에 미치는 영향

1. **“기존 문서 도구는 AI 문서 작업을 지원하지 않는다”는 주장은 기각한다.** 여섯 서비스 모두 문서 작성 또는 문서 맥락 활용 기능을 공식적으로 제공한다.
2. 따라서 망고독이 검증해야 할 것은 “AI 기능이 있는가”가 아니라, **특정 규격 문서 Job에서 기존 도구 대비 형식 준수·근거 확인·검토 리드타임을 실제로 개선하는가**다.
3. 보안·권한·내보내기는 부수적 요구가 아니다. 특히 조직 문서에서는 플랜, 사용자 권한, 연결 범위, 데이터 보존, Word/PDF/Markdown 내보내기 손실이 전환 결정을 바꿀 수 있다.

## 아직 모르는 것

- 실제 사용자가 이 기능들로 어떤 문서를 어디까지 끝내는가
- 다중 근거를 이용한 규격 문서에서 어느 대안이 더 빠르고 정확한가
- 문장 단위 근거 추적이나 과거 문서의 구조 재사용이 실제 전환 이유가 되는가
- 2D Workspace가 기존 편집기·분할 화면보다 더 낫거나 더 나쁜가

그러므로 다음 실험은 공식 기능표의 빈칸을 상상으로 채우는 것이 아니라, 공개 문서 과업 팩과 실제 사용자의 최근 업무로 대안을 비교하는 것이다.
