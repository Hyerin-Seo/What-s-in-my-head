# (gen) 가치 카드 05 — [시뮬레이터] 스토리라인 기반 팩트 꿰기와 슬롯 배선 (Fact Weaving)

> **핵심 명제**:  
> **"설득력은 문장의 화려함이 아니라, 스토리라인을 뒷받침하는 '팩트(Fact)의 정밀한 결속'에서 나온다."**  
> 드론 줄기에는 비행 로그와 시장 통계를, PCB 줄기에는 회로도와 원가 내역을 꽂아야 한다. 리소스 매니저의 원본 데이터를 스토리라인에 맞춰 각 슬롯에 배선(Wiring)하는 것이 시뮬레이터의 핵심 행위다.

---

## 1. 작업자의 인지 의도 (Cognitive Intent)

* **머릿속 생각**:  
  *"스토리라인을 '임베디드 PCB'로 잡았다면, 이번 연구실에서 실측한 초저전력 벤치마크 그래프와 외산 대비 40% 절감된 부품 BOM 원가표가 추진 전략 칸에 증빙으로 들어가야 논리가 단단해진다. 어디에 어떤 데이터를 꽂아야 심사위원이 반론을 못 펼칠까?"*
* **해결하고 싶은 갈증**:  
  자료 폴더를 뒤적거리며 수치를 복사해 표에 채워 넣는 타이핑 노가다를 없애고, **내 원본 데이터들을 스토리라인에 맞춰 각 슬롯에 직관적으로 연결(배선)**하고 싶음.

---

## 2. 기존 도구에서의 고통 (Pain Point)

* **워드/엑셀 작업의 늪**:  
  * PDF 논문, 시험 성적서, 견적서 파일 20개를 띄워두고 수치를 손으로 옮겨 적다 오타가 발생함.
  * 스토리라인을 바꾸면 수치와 증빙 표를 일일이 다시 찾아 갈아 끼우느라 반나절이 날아감.
* **챗봇의 환각(Hallucination)**:  
  * AI에게 맡기면 존재하지도 않는 허위 통계나 가짜 특허 번호를 지어내어, 신뢰성을 한순간에 무너뜨림.

---

## 3. 시뮬레이터에서의 작업 행위 (The Simulator Action)

```text
[스토리라인: PCB 척추]
          │
          ▼
[리소스 바구니 (Fact)] ──(슬롯 배선: Wiring)──▶ [와이어프레임 슬롯 (Slot)]
 • 전력 실측 로그                              • [배경 슬롯]: 전력 소모 한계 수치
 • 외산 대비 BOM 원가표                        • [차별성 슬롯]: 40% 단가 절감 증빙
 • 회로 레이아웃 도면                          • [수행 체계 슬롯]: 2층 보드 설계도
```

* **스토리라인별 팩트 큐레이션**:  
  * 스토리라인 가설에 따라 리소스 매니저의 방대한 자료 중 **"이 논리를 입증할 유효 팩트"**만 선별 정렬.
* **Slot Wiring (배선 행위)**:  
  * 글을 쓰지 않고, 슬롯과 데이터 소스 간의 **연결 포인터(Anchor)만 꽂아주는 작업**.
  * 텍스트 렌더링 시 원본 페이지/줄 번호가 100% 결속되어 환각 없는 무결점 증빙이 완성됨.

---

## 4. 실전 사례 (Use Case)

* **공인 시험성적서와 특허 배선**:  
  * '초저전력 슬롯'에 지난달 발급받은 공인시험성적서 PDF의 4페이지 표를 드래그하여 연결.
  * '지식재산권 확보 슬롯'에 등록 특허 공보를 바인딩.
  * 스토리라인이 변경되면 바인딩 포인터만 교체하여 즉시 새로운 팩트 사슬로 재배선함.
