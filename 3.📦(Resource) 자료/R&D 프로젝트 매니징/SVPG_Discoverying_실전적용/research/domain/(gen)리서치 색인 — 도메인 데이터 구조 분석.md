# 리서치 색인 — 도메인 데이터 구조 분석 (Domain Research)

본 영역은 시맨틱 서치의 환각을 방지하고 에이전트가 100% 참/거짓을 판정할 수 있도록 하는 **버티컬 도메인별 제약 조건 및 데이터 스키마 리서치**를 체계적으로 아카이빙하는 공간입니다.

## 📂 주요 보관 주제
* **보험/금융 도메인**: 보험 약관의 특약 구조, 질병코드 매핑, 면책 조항 Boolean 인과 모델
* **오프라인 상권/공간 도메인**: 매장 유휴 좌석률, 시간대별 혼잡도, 공간 쾌적도(콘센트, 눈치 지수) 팩트 스키마
* **외주/기술/학술 도메인**: 전문 역량 매칭 및 논문 연구 결론(Positive/Negative) 명제 구조
