# 📌 새 레퍼런스 등록하는 법

> [!tip] 3줄 요약
> `[레퍼런스] 제목.md` 를 **복사** → `UI + 디자인 + 기술 레퍼런스` 폴더에 붙여넣고 파일명을 `[레퍼런스] 사이트이름` 으로 변경.
> `자료 분류 기준` 은 이미 채워져 있으니 **건드리지 마세요.** 그게 보드에 올려주는 열쇠입니다.
> 이미지는 노트가 있는 폴더의 `이미지/` 하위 폴더에 넣습니다 — `3.📦(Resource) 자료/UI + 디자인 + 기술 레퍼런스/이미지/`

---

## 이 양식은 언제 쓰나요

노션 **`🛸 4. UI 레퍼런스 분석`** DB에서 넘어온 자료, 그리고 앞으로 찾은 **사이트·툴·서비스 레퍼런스**를 기록할 때 씁니다.

같은 폴더의 다른 양식과 이렇게 나뉩니다.

| | `!(Template) 새 자료 등록 양식` | **`!(Template) 새 레퍼런스 등록 양식`** (이 양식) |
| --- | --- | --- |
| 무엇을 적나 | 조사·관찰·불편함 기록 | 써볼 만한 사이트·툴 레퍼런스 |
| 고유 속성 | 분야 | 레퍼런스 종류 / 참고 중요도 / 평가 / 사이트 주소 |
| 출처 노션 DB | current research DB | UI 레퍼런스 분석 DB |

둘 다 `자료 분류 기준` 과 `자료 특이사항` 을 갖고 있어서 **같은 보드에 같은 모양으로 올라옵니다.**

## 1. 복사하기

1. `[레퍼런스] 제목.md` 를 복사 → `UI + 디자인 + 기술 레퍼런스` 폴더에 붙여넣기
2. 파일명을 **`[레퍼런스] 사이트이름`** 으로 변경 — 예: `[레퍼런스] GM-Meme.md`, `[레퍼런스] Dribbble.md`
3. 속성 `제목` 에도 파일명과 똑같이 적기 — `"[레퍼런스] GM-Meme"` (대괄호로 시작하니 **큰따옴표 필수**)

> [!warning] 속성은 지우지도, 순서를 바꾸지도 마세요
> 이 폴더의 노트는 **17개 속성을 같은 순서**로 갖도록 맞춰뒀습니다. 값이 비어도 속성 줄은 남겨두세요.
>
> `자료 분류 기준` 은 특히 지우면 안 됩니다
> 이 값이 `UI + 디자인 + 기술 레퍼런스` 여야 보드에 뜹니다. 양식에 미리 채워뒀습니다.
> 파일명에 `\ / : * ? " < > |` 는 못 씁니다.

## 2. 속성 채우기

| 속성 | 쓰는 법 | 어디에 쓰이나 |
| --- | --- | --- |
| 제목 | `[레퍼런스] 사이트이름`. **큰따옴표 필수** | **카드 제목** |
| 아이콘 | `🍴` 그대로 (노션 DB 아이콘) | |
| **레퍼런스 종류** | 아래 6개 중 하나 | **🎨 종류별 그룹** |
| **참고 중요도** | `상` `중` `하` | **🔥 중요도순 그룹** |
| 평가 | ⭐️ 를 개수만큼 (예: `⭐️⭐️⭐️⭐️⭐️`) | 카드에 표시 · 정렬 |
| **자료 특이사항** | 한 줄로 "이게 뭐 하는 놈인지" | **카드 부제** |
| 참고 포인트 | 우리 서비스에 가져올 만한 지점 | 📊 전체 표 |
| 사이트 주소 | 주소가 여럿이면 줄바꿈해서 나열 | 📊 전체 표 |
| 시도 여부 | `true` / `false` | ✅ 써본 것 |
| 자료 작성자 | 기본값 `민규 서` | 📊 전체 표 |
| 자료 이미지 | `"[[3.📦(Resource) 자료/UI + 디자인 + 기술 레퍼런스/이미지/파일명.png]]"` | **카드 커버** |
| 자료 분류 기준 | `UI + 디자인 + 기술 레퍼런스` — **고정** | **보드 필터** |
| 생성 일시 / 최종 편집 일시 | `2026-08-28T15:30:00` 형식 (KST) | 정렬 |
| 돌아가기 / notion_url / notion_db | 노션에서 옮겨온 것만. 새로 쓰는 건 비워두기 | |

**레퍼런스 종류 6가지** — `Second Brain` · `메모` · `글쓰기` · `협업&프로젝트 관리` · `문서&콘텐츠 작성 어시스턴트` · `디자인`

> [!info] 노션의 `핵심 기능` 은 `자료 특이사항` 으로 들어옵니다
> 카드 부제로 나오는 속성이 `자료 특이사항` 이라, 노션에서 옮겨올 때 `핵심 기능` 내용을 여기로 넣습니다.
> 조사 노트와 레퍼런스 노트가 카드에서 같은 자리에 같은 정보를 보여주게 하기 위함입니다.

> [!warning] 옵시디언에는 드롭다운(선택) 속성이 없습니다
> 옵시디언이 지원하는 속성 타입은 텍스트 · 목록 · 숫자 · 체크박스 · 날짜 · 날짜와 시간뿐입니다.
> 노션의 `선택` 처럼 미리 정해둔 목록에서 고르는 기능은 아직 없습니다. (망고네 책장의 `평점` 도 실은 ⭐️ 문자가 든 텍스트 속성입니다.)
> 대신 **속성값 칸을 클릭하면 볼트에서 이미 쓴 값들이 후보로 떠서** 골라 넣을 수 있습니다.
> 자료가 쌓일수록 후보가 완성되니, 위 표의 값을 그대로 써주세요.

## 3. 이미지 넣기

1. 왼쪽 파일 탐색기에서 `UI + 디자인 + 기술 레퍼런스` > `이미지` 폴더로 이미지를 **드래그**해 넣기
2. `자료 이미지` 속성에 `"[[3.📦(Resource) 자료/UI + 디자인 + 기술 레퍼런스/이미지/파일명.png]]"` 형태로 **전체 경로**를 적기
3. 본문에도 보이게 하려면 프론트매터(`---`) 바로 아래 줄에 `![[전체경로]]` 를 넣기

> [!warning] 이름만 쓰지 말고 전체 경로로 쓰세요
> `![[파일명.png]]` 처럼 이름만 쓰면 옵시디언이 못 찾는 경우가 있었습니다. 폴더 경로까지 적어주세요.

## 4. 본문 쓰기

콜아웃 2개는 노션 DB의 기본 템플릿을 그대로 옮긴 것입니다.

| 콜아웃 | 용도 |
| --- | --- |
| `> [!abstract] 🔥` 사이트 소개 | 이 사이트가 뭐 하는 곳인지, 왜 눈에 띄었는지 |
| `> [!tip] 🍽️` 적용하고 싶은 부분 | 우리 서비스에 가져올 만한 지점 |

- **본문에 `# 제목` (H1) 을 넣지 마세요.** 제목은 파일명과 `제목` 속성이 대신합니다.
- 유튜브·영상 링크는 그냥 주소를 붙여넣으면 됩니다.
- 노션에서 옮겨온 옛 자료는 두 번째 콜아웃이 `완성된 요리` 로 되어 있을 수 있습니다. (노션 DB가 요리 템플릿을 개조해 쓴 흔적입니다.) 눈에 거슬리면 `적용하고 싶은 부분` 으로 바꿔도 됩니다.

## 5. 보드에 반영되는 방식

`🪄 UI + 디자인 + 기술 레퍼런스.base` 에 저장 즉시 올라옵니다.

| 뷰 | 보이는 것 |
| --- | --- |
| 🪄 보드 | 커버 + 제목 + 자료 특이사항 + 평가 (중요도 상 → 하 순) |
| 🎨 종류별 | 레퍼런스 종류로 묶기 |
| 🔥 중요도순 | 참고 중요도 상 → 중 → 하 |
| 📊 전체 표 | 속성 전체 |
| 🕳️ 정리 필요 | 종류·중요도·자료 특이사항이 빈 것 |

> [!info] 기존 조사 노트 4개도 같은 보드에 있습니다
> `[레퍼런스] 소설 전용…` 같은 노트들은 출처 DB가 달라서 레퍼런스 속성이 비어 있습니다.
> 「🕳️ 정리 필요」 탭에 잡히니, 채우고 싶으면 거기서 모아 보세요.
