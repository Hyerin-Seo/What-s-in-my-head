# 📌 새 자료 등록하는 법

> [!tip] 3줄 요약
> `[조사 목적] 제목.md` 를 **복사** → 그룹 폴더에 붙여넣고 파일명 변경 → 속성 `자료 분류 기준` 에 그룹명 적기.
> 이미지는 **그 그룹 폴더 안의 `이미지/`** 에 넣습니다. 노트를 옮기면 이미지도 같이 따라갑니다.
> 저장하는 순간 그 그룹의 **🪄 베이스**에 자동으로 올라옵니다.

---

## 1. 복사하기

1. 이 폴더의 `[조사 목적] 제목.md` 를 복사 → 넣고 싶은 그룹 폴더에 붙여넣기
2. 파일명을 **자료 제목**으로 변경 — 예: `[레퍼런스] 소설 전용 프로그램 및 플러그인.md`
3. 속성 `제목` 에도 같은 제목을 큰따옴표로 감싸서 적기
4. 속성 `자료 분류 기준` 에 **폴더명과 똑같이** 적기 (이게 빠지면 보드에 안 뜹니다)

> [!warning] 파일명 규칙
> - 제목이 `[` 로 시작하므로 `제목:` 속성은 **반드시 큰따옴표**로 감싸야 합니다. 안 그러면 목록으로 잘못 읽힙니다.
> - 파일명에 `\ / : * ? " < > |` 는 못 씁니다. 제목에 `/` 가 있으면 파일명에서는 **공백**으로 바꾸고, `제목:` 속성에는 원래 제목을 그대로 적으세요.
>   예) 제목 `[추천 명작] 작품명/추천도/플랫폼 등등` → 파일명 `[추천 명작] 작품명 추천도 플랫폼 등등.md`

## 2. 이미지 넣기

**이미지는 그 노트가 속한 그룹 폴더의 `이미지/` 하위 폴더에 모읍니다.** 커버든 본문 삽입이든 구분 없습니다.

예) `2.🌱(Area) 관리 영역/AI가 보여준 신세계/이미지/` · `4.🗄️(Archive) 보관/웹소설 어시스턴트/이미지/`

이렇게 두면 **그룹 폴더를 통째로 옮겨도 이미지가 따라갑니다.** PARA 재배치에 안전합니다.

1. 왼쪽 파일 탐색기에서 **그 노트가 있는 그룹 폴더** > `이미지` 폴더로 이미지 파일을 **드래그**해 넣기
   (파일명은 알아보기 쉽게 — 기존 자료는 `res_자료제목_번호.jpg` 형식을 씁니다)
2. 속성 `자료 이미지` 에 `"[[파일명.jpg]]"` 형태로 적기 → **카드 커버**가 됩니다
3. 본문에도 보이게 하려면 프론트매터(`---`) 바로 아래 줄에 `![[파일명.jpg]]` 를 넣기

> [!info] 노트에 바로 붙여넣기(Ctrl+V)를 했다면
> 옵시디언 기본 설정상 이미지가 **볼트 최상위**에 떨어집니다.
> 파일 탐색기에서 그 파일을 `이미지` 폴더로 드래그해 옮기면 링크는 자동으로 따라옵니다.
> 그다음 파일명을 복사해 `자료 이미지` 속성에 `"[[...]]"` 로 넣어주세요.

**커버 없이 둬도 됩니다.** 카드에 이미지 자리만 비어 보일 뿐 나머지는 그대로 동작합니다.

## 3. 속성 채우기

| 속성 | 쓰는 법 | 어디에 쓰이나 |
| --- | --- | --- |
| 제목 | 정식 제목. **큰따옴표 필수** | **카드 제목** (굵게) |
| 아이콘 | `💡` 그대로 | |
| 분야 | `AI 활용 방안 연구` / `📜 [PL-NOP] 노션 최적화` / `✏️ [PL-NA] NovelAI 요구사항 명세서 작성하기` | **🔬 분야별 그룹** |
| **자료 분류 기준** | **폴더명과 동일하게.** 빠지면 보드에 안 뜹니다 | **보드 필터** |
| 자료 작성자 | `민규 서` / `Rin` 등 | 📊 전체 표 |
| 자료 특이사항 | 여러 줄이면 `\|-` 를 쓰고 다음 줄부터 2칸 들여쓰기 | **카드 부제** |
| 자료 이미지 | `"[[파일명.jpg]]"` | **카드 커버** |
| 생성 일시 / 최종 편집 일시 | `2026-08-27T15:30:00` 형식 (KST) | 정렬 |
| 돌아가기 | 노션 원본 DB 주소. 그대로 두기 | |
| notion_url / notion_db | 노션에서 옮겨온 자료만 해당. 새로 쓰는 건 비워두기 | |

**여러 줄 특이사항 예시**

```yaml
자료 특이사항: |-
  - 증강 지능 (Augmented Intelligence)
  - AI 오케스트레이션 (AI Orchestration)
```

> [!info] 빈칸은 그냥 두셔도 됩니다
> `자료 분류 기준` 만 필수입니다. 나머지는 비면 해당 필터에서 조용히 빠질 뿐이고,
> 나중에 채우고 싶으면 각 그룹 베이스의 **`🕳️ 정리 필요`** 탭에서 빠진 것만 모아 볼 수 있습니다.

## 4. 본문 쓰기

콜아웃 4개는 노션 DB의 기본 템플릿을 그대로 옮긴 것입니다. 안 쓰는 건 지워도 됩니다.

| 콜아웃 | 용도 |
| --- | --- |
| `> [!abstract] 📌` 한 줄 요약 | 대상 / 용도 / 결과 |
| `> [!note] 🔎` 조사 방향 | 조사하게 된 계기 |
| `> [!tip] 💻` 주요 내용 | 조사한 내용 본체 |
| `> [!important] 🎯` 조사 결과 | 어디에 쓸지 / 추가 조사 필요한지 |

- **본문에 `# 제목` (H1) 을 넣지 마세요.** 제목은 파일명과 `제목` 속성이 대신합니다.
- 콜아웃 **안에** 이미지나 목록을 넣으려면 줄 앞에 `>` 를 붙입니다.
- 기존 자료 중 `Before / After / 효능과 효엄` 구성을 쓰는 것들도 있습니다. 편한 쪽으로 바꿔 쓰세요.

## 5. 보드에 반영되는 방식

| | 자동인가 | 설명 |
| --- | --- | --- |
| 그룹별 **🪄 베이스** | ✅ **자동** | 저장하는 순간 4개 탭 전부에 즉시 반영 |
| 카드 커버 | ✅ **자동** | `자료 이미지` 속성만 채우면 됨 |

**새 그룹을 만들고 싶다면** — `3.📦(Resource) 자료` 아래에 그룹 이름으로 폴더를 만들고, 기존 그룹의 `.base` 파일을 복사해 넣은 뒤 파일 안의 그룹명 두 곳(`file.inFolder(...)` 와 `note["자료 분류 기준"] == ...`)을 새 이름으로 바꾸면 됩니다.

> [!danger] 베이스 파일은 건드리지 마세요
> 각 그룹 폴더의 `🪄 그룹명.base` 는 카드 비율·정렬이 맞춰져 있습니다.
> 뷰 설정을 바꾸고 싶으면 옵시디언에서 베이스를 연 뒤 우측 상단 메뉴로 조절하세요.
