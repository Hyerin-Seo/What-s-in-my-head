# 📌 새 책 등록하는 법

> [!tip] 3줄 요약
> 이 폴더를 **통째로 복사** → 폴더명·파일명을 책 제목으로 변경 → 표지를 `이미지/표지.jpg`로 저장.
> 저장하는 순간 **[[📚 망고네 책장]]** 에 자동으로 올라옵니다. (캔버스만 수동)

---

## 1. 복사하기

1. `!(Template) 새 책 등록 양식` 폴더를 통째로 복사 → 도서관 폴더 안에 붙여넣기
2. 폴더명을 **책 제목**으로 변경 (이모티콘 없이) — 예: `달러구트 꿈 백화점`
3. 안의 `📖 (책 제목).md` 파일명을 **`📖 책 제목`** 으로 변경 — 예: `📖 달러구트 꿈 백화점.md`
4. 이 `📌 사용법.md` 파일은 **삭제**

> [!warning] 파일명 규칙 두 가지
> - **`📖 ` 로 시작해야 합니다.** 책장이 이 글자로 책을 찾습니다. 빠지면 목록에 안 뜹니다.
> - 폴더명에 `: \ / * ? " < > |` 는 못 씁니다. 제목에 `:` 가 있으면 ` - ` 로 바꾸고, 프론트매터 `책 제목:` 에는 원래 제목을 큰따옴표로 감싸 그대로 적으세요.

## 2. 표지 넣기

1. 알라딘에서 책 검색 → 표지 이미지 우클릭 → 이미지 저장
2. 복사한 폴더의 `이미지/` 안에 **`표지.jpg`** 라는 이름으로 저장
3. 끝. (이름을 바꾸면 본문 `![책 표지](이미지/표지.jpg)` 와 속성 `책 표지:` 두 군데를 같이 고쳐야 합니다)

**고화질 팁** — 알라딘 이미지 주소의 `cover200` 을 `cover500` 으로 바꾸면 더 큰 이미지가 나옵니다.
PNG 표지라면 `표지.png` 로 저장하고 속성·본문도 `.png` 로 맞추세요.

## 3. 속성 채우기

| 속성 | 쓰는 법 | 어디에 쓰이나 |
| --- | --- | --- |
| 책 제목 | 정식 제목. `:` `,` 있으면 `"큰따옴표"` | |
| 저자 | 여러 명이면 쉼표로 나열 | 카드에 표시 |
| 출판사 | | |
| 장르 | `웹소설` `기획` `스타트업` `AI` `자기계발` | **📚 장르별 그룹** |
| 평점 | ⭐️ 를 개수만큼 (예: `⭐️⭐️⭐️⭐️`) | 카드에 표시 |
| **별점** | **위 ⭐️ 와 같은 개수를 숫자로 (예: `4`)** | **⭐ 인생책 필터 · 정렬** |
| 전체 페이지 수 | 숫자만 | |
| 진행도 | `구매예정` `구매완료` `독서중` `감상평 작성` `책장보관` | **🔥 읽는 중 · 🛒 위시리스트** |
| 독서시작 / 독서종료 | `2026-08-27` 형식 | |
| 완독 | `true` / `false` | ✅ 완독 |
| 웹소설 작가 필독 백과사전 여부 | `true` / `false` | 📕 작가 백과사전 |
| 구매링크 | 서점 주소. 빌린 책이면 `"[아람누리] 아람종합자료실"` 처럼 위치를 적어도 됨 | |
| 책 표지 | `"이미지/표지.jpg"` — 그대로 | **카드 커버 이미지** |
| 이동버튼 / notion_url / notion_db | 노션에서 옮겨온 책만 해당. 비워둬도 됨 | |

> [!info] 빈칸은 그냥 두셔도 됩니다
> 필수값이 아닙니다. 값이 없으면 해당 필터에서 조용히 빠질 뿐이고, 나중에 채우고 싶어지면
> 책장의 **`🕳️ 정리 필요`** 탭에서 빠진 항목만 모아 볼 수 있습니다.
> 다만 **`별점`** 은 비면 `⭐ 인생책` 에서 빠지니, 점수를 매겼다면 ⭐️ 와 숫자를 같이 적어주세요.

## 4. 본문 쓰기

- 맨 위 인용구(`> **"..."**`) 에 **책에서 가장 인상 깊었던 문장**
- `💭 나의 감상평` 콜아웃 안에 감상
- `🏷️ 기억에 남는 글귀` 콜아웃 안에 발췌
- `💬 댓글` 은 노션에서 주고받은 코멘트를 옮길 때만. 없으면 지워도 됨

**본문에 사진·도표를 넣을 때**
1. `이미지/` 폴더에 넣기 (파일명은 알아보기 쉽게 — 예: `달러구트_01.jpg`)
2. 본문에 `![](이미지/달러구트_01.jpg)` 로 삽입
3. 콜아웃 **안에** 넣으려면 줄 앞에 `>` 를 붙이기

> [!danger] 건드리면 안 되는 두 가지
> 카드 높이를 맞추기 위한 규칙입니다.
> 1. **본문에 `# 제목` (H1) 을 넣지 말 것** — 제목은 파일명이 대신합니다.
> 2. **프론트매터 `---` 바로 다음 줄에 표지 이미지를 둘 것** — 사이에 빈 줄을 넣으면 여백이 벌어집니다.

## 5. 책장에 반영되는 방식

| | 자동인가 | 설명 |
| --- | --- | --- |
| **[[📚 망고네 책장]]** (Bases) | ✅ **자동** | 파일을 저장하는 순간 8개 탭 전부에 즉시 반영됩니다. 할 일 없음 |
| **[[🏠 도서관 홈]]** | ✅ **자동** | 위 책장을 그대로 끼워 넣은 것이라 같이 갱신됩니다 |
| **책장 캔버스** | ❌ **수동** | 좌표가 고정된 그림이라 새 책이 저절로 들어가지 않습니다 |

**캔버스에도 넣고 싶다면** 둘 중 하나입니다.

- 간단히: 캔버스를 열고 왼쪽 파일 목록에서 노트를 캔버스 위로 **드래그**
- 통째로 다시 뽑기: 터미널에서 아래 실행 (장르 그룹이 새로 계산됩니다)

```bash
python ".obsidian/scripts/rebuild-canvas.py"
```

> 재생성은 캔버스를 통째로 덮어씁니다. 직접 옮겨둔 배치가 있으면 사라지니,
> 실행 전 자동으로 남기는 `.canvas.bak` 백업을 확인하세요.
