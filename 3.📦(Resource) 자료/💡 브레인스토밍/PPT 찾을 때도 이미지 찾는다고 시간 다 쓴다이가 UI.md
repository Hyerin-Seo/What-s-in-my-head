본문을 먼저 작성하고 나면 → 1. 이미지 검색어 키워드 추출 → 2. PPT 전체 슬라이드 입력 → 3. AI 알아서 분석 → 4. 적절한 알잘딱한 삽입해야하는 이미지를 ‘구글 이미지’나 ‘핀터레스트’ 처럼 옆에 보드, 카드 형으로 뿌려주고 → 5. 사용자가 끌어다 첨부하면 이미지를 바로 꽂아주는걸로 → 6. 부가로 ‘이미지 생성하기, 그래프나 도식 생성하기’도 보드, 카드 섹션에 잘 뿌려놓기

## 어떤 이유로 중요하다고 생각하시나요?

- PPT 찾을 때도 이미지 찾는다고 시간 다 쓴다, 적절한 이미지를 찾는 것은 시간이 매우 오래 걸리는 작업
- 내 ‘프로젝트’, ‘결과물’을 모니터링 하며 적재적소의 상황에 미리 세팅해놓는 것이 생산성 향상에 중요한 도움 포인트
