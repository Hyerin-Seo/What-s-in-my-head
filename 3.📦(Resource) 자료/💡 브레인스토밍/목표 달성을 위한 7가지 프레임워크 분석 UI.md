- Goal을 입력하면 ‘막연한 목표’에서 보다 구체적이고 명확한 단위로 분해해서 ‘직관적’으로 보여주고 ai의 초안과 제안을 받아볼 수 있는 UI
- **S.M.A.R.T (구체적인 목표 잡기)**, **The Golden Circle (작품의 핵심 잡기)**, **Goals Pyramid (실행 단계 나누기), Locke and Latham’s 5 Principles (멘탈 관리), B.H.A.G. (Role model 유형 적용), H.A.R.D (동기 부여), W.O.O.P. (장애물 대비 - 가장 중요!) 측면에서 구체화 가능**

## 어떤 이유로 중요하다고 생각하시나요?

- Goal은 너무 막연할 때가 많고, Goal 자체를 명확하게 잡아가는 것 자체가 중요한 시작점이고 시행착오를 겪어야하는 부분 → 빠른 시뮬레이션과 구체화를 통해 [Goal] 수정을 빠르게 가져갈 수 있음
- 목표와 관련해 고려해야할 요소들을 미리 빠짐없이 체크해볼 수 있음 → 아직 구체화가 안된 부분은 어디인가 등
- 도식화, 직관적으로 보여주는 것이 좋음
