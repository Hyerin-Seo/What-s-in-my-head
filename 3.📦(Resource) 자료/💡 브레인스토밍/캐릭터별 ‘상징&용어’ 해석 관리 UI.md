[기본 구성]

- 용어, 등장인물, 단어의 의미+캐릭터별 의미, 캐릭터에게 그런 의미가 생기게된 계기
- 단어와 용어 중심으로 표나 갤러리 형태로 보여주고, 용어 상세보기를 했을 때 어떤 인물들이 해당 단어에 대해 의미를 가지고 있는지 제시
- 예시) ‘장미’ → 엘리스 - 기쁨(선물 받았던 좋은 추억), 케빈 - 슬픔(이별한 사람이 가장 좋아했던 것), 등등

[기능]

- Grammarly가 작가의 Workspace에서 단어들을 채집함
- 작품에 나온 내용은 알아서 반영함
- 작품에 나오지 않고, 구상 단계에서 나온 것은 챗팅 혹은 구상 프로세스 중 알아서 단어집에 추가 or 간단한 추가 UI

## 어떤 이유로 중요하다고 생각하시나요?

- 진후 작가 다이렉트 요청
- 소재, 연출 장치가 각 인물들에게 어떤 식으로 받아들여지는지 추적 관리가 필요함
- 다음 스토리 구상에 도움이 됨 - ‘장미’ 관련해서 해당 장면을 한 번 작성해볼까? 하고
- ‘상징화’ 작업 - 주요 소재 선택 과정에서 AI의 도움을 받기 좋음 → ex) ‘초콜릿’이 각 인물들에게 어떻게 사용될지 한 번 제안해봐
