1. 작업 Flow를 시각적 그래프 형태로 표기 - 메인 줄기와 서브 줄기의 관계로
2. Flow의 각 포인트는 챗팅과 1대 1 관계를 가짐
3. 한 채팅창 내에서 사용된 작업은 따로 수집하여 유저의 프롬프트 입력창에 ‘템플릿’ 형태로 제공 → 유저가 작업 템플릿 선택 시 주요 용어를 제외한 나머지 지침 그대로 자동 생성해줌
4. Flow의 각 포인트는 첨부한 이미지와 같은 기능을 내장함

## 어떤 이유로 중요하다고 생각하시나요?

- 유저의 LLM과의 작업 흐름 관리를 직관적, 시각적으로 만들어 집중력을 유지하도록 도와줌
- 긴 LLM 작업을 ‘맵’ 형식으로 요약, 압축하여 보여줌으로 LLM 챗의 작업 형태를 한 눈에 파악 가능
- 같은 작업 지시를 타이핑으로 반복하고 있으면 빡침 ⇒ 작업 지시 간편화와 자동화에 기여
