## 아이디어 콘티

- Inbox → PARA로 조사 섹터별로 Chat 페이지 전체를 이동
- 만약 P에서 T라는 주제에 대해서 탐색을 진행하다가 조사 결과 중 A에 해당하는 내용 발생 → 브런치를 A로 이동 + A섹테 조사 주제&주요 키워드 자동 생성
- 조사 주제별 Hierachy + 연관 주제를 지정가능 → 마인드맵 혹은 전체 조망 형태로 보면 어떤 방향으로 조사가 진행되고 있는지 한 눈에 파악 가능
- 조사 목표 하나당 PARA 보관함&디렉토리 생성 → PARA는 조사에 특화해서 다시 정의함
- 추후 AI 비서 결합 가능

## 어떤 이유로 중요하다고 생각하시나요?

- 조사는 기본적으로 발산형이고, 어떤 내용이 나오는지에 따라 조사 방향이 달라지게됨. PARA는 탐색해나가는 자료 정리에 있어서 매우 궁합이 잘 맞다고 생각함
- 특히 자료가 무한정 쏟아지는 ‘AI 채팅’식 조사는 이런 분류가 빡세게 잡혀있지 않으면 다 ‘휘발성 자료’가 되어버림. 조사의 방향을 읽기도 쉬움
- 추가적으로 이 조사 자료 자체가 ‘잘 정리될 수만 있다면’ 그냥 게임 끝
