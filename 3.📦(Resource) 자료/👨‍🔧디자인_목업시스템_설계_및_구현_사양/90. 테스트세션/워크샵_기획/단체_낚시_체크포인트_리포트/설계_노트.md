## 3. 답을 가르는 조건
* **변수**:
  1. **낚시 유형 · 이동 거리**: 오창 1시간권 내륙 민물(수상좌대 · 송어터 · 실내 하우스) vs 1시간 40분~2시간 30분권 서해 바다(선상 체험낚시 · 해상좌대)
  2. **참여 범위**: 아웃라인 메모 기반 **부분·옵션 참여형(좋아하는 사람만 낚시 + 나머지 인원 숙소/관광/카페)** vs **전원 참여형(팀 전체 단체 낚시)**
  3. **시기(11~12월 동절기)**: 11월 하순~12월 초는 붕어 비수기·얼음낚시 미결빙(안전 두께 10cm 미달 위험) 구간 → **실내 하우스·송어장·난방 완비 좌대·바다 우럭/열기**로 선택지가 급격히 좁혀짐
  4. **초보 비율**: 초보 다수(장비 올인원 대여·손맛 보장형 필수) vs 경력자 중심(개인 장비 지참)
  5. **규모·예산(300~1,000만 원 / 1박 2일)**: 소규모 옵션(5~10명 → 일반 좌대 1~2동 또는 체험선 합승) vs 중대규모 전원(20~40명 → 독배 1~2척 또는 대형 투룸 좌대 연달아 배정)
* **묶음별 갈림과 보여 줄 방식**:
  * 묶음 1·2·3 → 맨 앞 **조건 분기표(거리 × 참여방식 × 시기)**로 4가지 시나리오 중 탈락/유력 경로를 먼저 가름
  * 묶음 4·5·6 → **바다(선상/해상좌대) vs 민물(수상좌대/송어/하우스)** 2열 비교표로 다른 규정(신분증·멀미약 vs 난방 환기·장비 지참 여부)을 분리 제시
  * 묶음 7 → **1박 2일 타임테이블(옵션 분반형 기준)** + 현장 체크리스트
* **독자 상황을 알면 앞에 둘 경로**: 현재 아웃라인 기준 **"오창 1시간권 + 11~12월 + 부분·옵션 참여"** 경로를 기본 전면에 두고, 바다 선상/좌대를 원할 때 감수해야 할 추가 변수(거리·새벽 출항·기상 취소)를 대조한다.
