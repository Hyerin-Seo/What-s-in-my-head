# 좋은 레퍼런스 판단 기준

> 레퍼런스는 "내용이 좋은 글"이 아니라 **"결정이 배울 만한 글"** 이다. 아래 기준으로 후보를 보고, 숫자와 화면을 함께 판단한다.
> 숫자는 참고선이다 — 넘는다고 좋은 글이 되고, 못 넘는다고 탈락하는 것이 아니다.

---

## 1. 반드시 (하나라도 아니면 떨어뜨린다)

| 기준 | 묻는 것 | 확인 방법 |
|---|---|---|
| **같은 결정** | 이 글의 독자도 우리 독자와 비슷한 결정을 내리려고 읽는가? | 소제목 목록(`summary.md`)을 내 질문 지도 묶음과 맞대 본다. 절반 가까이 겹치거나, 결정의 모양(고르기 · 준비 · 비교)이 같으면 통과 |
| **직접 겪은 글** | 쓴 사람이 직접 하고 · 가고 · 써 본 글인가? | 1인칭 · 경험 신호, 같은 장소 · 사람 · 물건이 여러 사진에 반복되는가(타일), 날짜 · 동선 같은 구체성. 업체 소개 나열 · 스톡 사진 · 업체 제공 사진뿐이면 탈락 |
| **광고 문서가 아님** | 정보 전달보다 판매 · 상담 유도가 목적인가? | 광고 신호(`협찬 · 원고료 · 체험단`)와 연락처 · 상담 유도 신호가 높고, 제목 낱말이 1000자당 과하게 반복되면(SEO 글) 의심. 협찬이어도 직접 겪은 내용이 충실하면 통과 — 단 카드에 "협찬"을 적는다 |

## 2. 결정의 질 (고를 때 비교하는 축)

| 기준 | 좋은 신호 | 측정 지표 (참고선) |
|---|---|---|
| **반복 단위가 있다** (B1) | 섹션마다 같은 모양으로 끊겨 따라 하기 쉽다 | `signature_share` 0.5↑, `photo_first_ratio` 높음 (소제목 → 바로 사진) |
| **사진이 이야기를 끈다** (B2) | 글보다 사진이 먼저 보이고, 묶음 · 캡션을 의도적으로 쓴다 | `photos_per_section` 1.5↑, `photo_text_ratio` 0.5↑, 갤러리 · 캡션 사용 |
| **훑어 읽힌다** (B3) | 문단이 짧고, 강조가 드물게 정확하다 | `avg_para_chars` 100↓, `max_para_chars` 300↓, 강조(`bold · highlight per para`)가 1 미만 — 모든 문단이 굵으면 강조가 아니다 |
| **소제목이 질문에 답한다** (B4) | 소제목만 읽어도 흐름이 잡힌다 | 질문형 · 요약형 소제목, 내 질문 지도와 겹침 |
| **다음 행동으로 넘긴다** (B5) | 요약 상자 · 체크리스트 · 링크 카드로 독자를 움직인다 | `boxes`, `link_cards_per_section` |
| **말투가 독자와 맞다** (B6) | 우리 독자(요청자)가 어색해하지 않는다 | 종결 어미 · 이모지 · 감탄 — 실무 리포트면 감탄 · 이모지가 과한 글은 `참고` 로 |

## 3. 덤 (있으면 가점)

* **독자 반응**: 공감 · 댓글 · 스크랩이 보이고, 댓글에 "도움 됐다 / 이대로 했다"가 있다.
* **최신**: 플랫폼 편집기 모양이 지금과 같다 (배치 레퍼런스라 내용 최신성은 덜 중요).
* **우리 '봐야 아는 것'과 같은 종류의 사진**을 쓴다 (예: 우리는 좌대 내부를 보여 줘야 하는데, 이 글은 숙소 내부를 구석구석 보여 준다).

---

## 4. 2~3개를 고르는 법

1. 반드시 기준을 통과한 후보만 남긴다.
2. 결정의 질 축에서 **서로 다른 강점**을 가진 조합을 고른다. 같은 장점의 글 두 개보다, 리듬이 좋은 글 하나 + 요약 · 동선이 좋은 글 하나가 낫다.
3. 카드에 "왜 이 글인가"를 한 줄로 쓴다: "B1 · B2 따름 — 소제목 다음 사진 0.89, 섹션당 2.6장".

## 5. 실측 예 (2026-11-19, 네이버 블로그 두 편)

| | 여행 가이드형 (하코다테) | 추천 랭킹형 (세계여행) |
|---|---|---|
| 섹션 반복 모양 | 소제목 → 사진 → 캡션 → 문단들 → 사진 → 문단들 → 링크 | 소제목 → 사진 묶음 → 문단들 → 링크 |
| 섹션당 사진 · 소제목 다음 사진 | 2.6 · 0.89 | 2.2 · 0.93 |
| 평균 · 최대 문단 | 19자 · 99자 | 78자 · 270자 |
| 강조 | 형광펜 0.19/문단, 가운데 정렬 | 형광펜 0.63/문단, 질문형 소제목 0.86 |
| 배울 점 | 짧은 문단 · 캡션으로 사진을 설명하는 리듬 | 질문형 소제목 · 사진 묶음 · 섹션 끝 링크 |
