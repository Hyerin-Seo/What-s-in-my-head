# 🧠 개똥이 머릿속 (What's in my head)

> 민규 서의 옵시디언(Obsidian) 지식관리 볼트입니다.  
> **GTD (Getting Things Done)** 프로세스와 **PARA (Projects, Areas, Resources, Archive)** 가치 체계로 운영됩니다.

---

## 📌 핵심 원칙

1. **폴더 대신 프론트매터 속성으로 검색**
   - 노트의 위치(폴더)에 의존하지 않고, 모든 노트에 동일하게 부여된 **16가지 공통 프론트매터 속성**을 활용합니다.
2. **검색 탐색 순서**
   ```
   1. 유형으로 범위 좁히기  (예: 아이디어, 할일, 책, 레퍼런스 등)
   2. 구역으로 범위 좁히기  (예: 1.project, 2.area, 3.resource 등)
   3. 분류 / 주제로 세부 검색
   ```

---

## 🗺️ 볼트 구조 (PARA 체계)

| 구역 (Zone) | 설명 | 주요 역할 |
| --- | --- | --- |
| `0.inbox` | 아직 분류되지 않은 수집함 | 주 1회 가공 및 이동 |
| `1.project` | 목표와 마감 기한이 명확한 현재 주력 과제 | GTD 수집 및 실행의 중심 |
| `2.area` | 마감은 없지만 장기적으로 지속 유지·관리하는 영역 | 원칙, 추구미, 지속 관찰 기록 등 |
| `3.resource` | 향후 프로젝트나 영역으로 승격 가능한 참고 자료 | 아이디어, 책, 메모, 레퍼런스 등 |
| `4.archive` | 완료되었거나 보관 중인 항목 | 과거 프로젝트 및 이력 |

## 📋 16가지 공통 프론트매터 속성

모든 마크다운 노트에 공통 적용되는 속성 구조입니다:

| 속성명 | 설명 | 비고 |
| --- | --- | --- |
| `제목` | 노트 이름 | 파일명과 동일 |
| `유형` | 노트 분류 (가장 중요) | 아이디어, 할일, 책, 레퍼런스 등 |
| `구역` | PARA 구조 위치 | `0.inbox`, `1.project`, `2.area`, `3.resource`, `4.archive` |
| `분류` | 구역 내 세부 그룹 | 리스트 구조 |
| `주제` | 태그성 키워드 | 리스트 구조 |
| `상태` | 진행 상태 | 유형별 전용 상태값 존재 |
| `중요도` | 중요도 (1~5) | 숫자가 클수록 높은 중요도 |
| `요약` | 한 줄 요약 |  |
| `작성일` | 최초 생성일 | YYYY-MM-DD |
| `수정일` | 최종 수정일 | YYYY-MM-DD |
| `마감` | 목표 / 완료 기한 | YYYY-MM-DD |
| `커버` | 대표 이미지 링크 | 위키링크 형식 |
| `상위` | 부모 노트 링크 | 위키링크 형식 |
| `링크` | 외부 원본 URL |  |
| `담당` | 실무/책임 담당자 | 위키링크 형식 (`"[[이름]]"`) |
| `작성자` | 노트 작성 주체 | 위키링크 형식 (`"[[민규 서]]"`, `"[[Gemini]]"` 등) |

---

## 🤖 에이전트(AI) 가이드

- **작성자 표기:** 에이전트가 새 노트를 생성하거나 본문을 작성한 경우 `작성자` 속성에 반드시 위키링크 형태(`- "[[Gemini]]"` 등)로 표기합니다.
- **검색 방법:** 단순 폴더 경로가 아닌 `유형`, `구역`, `주제` 프론트매터 키워드를 기준으로 검색 및 정렬합니다.
