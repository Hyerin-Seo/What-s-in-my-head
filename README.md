## 서랍은 다섯 개뿐입니다

| 폴더 | 여기 넣는 것 | 노트 |
| --- | --- | --: |
| `0.📥 인박스` | 아직 안 정한 것. 일단 던지는 자리 | 5 |
| `1.🎯(Project) 프로젝트` | 끝이 있는 일. 마감이 있다 | 42 |
| `2.🌱(Area) 관리 영역` | 끝은 없는데 계속 챙기는 것 | 52 |
| `3.📦(Resource) 자료` | 언젠가 쓸 것 | 56 |

넣을 곳이 헷갈리면 위에서부터 물어봅니다 — 마감이 있나 → 계속 중요한가 → 언젠가 쓸 것인가 → 아니면 보관.

## 이름표(속성) 열세 개

모든 노트가 같은 칸을 갖습니다. 빈 칸으로 둬도 됩니다.

`유형` `구역` `분류` `주제` `상태` `요약` `작성일` `마감` `커버` `상위` `링크` `담당` `작성자`
(할 일에는 `일정` 이 하나 더 붙습니다 — *하기로 한 날*, `마감` 과 다릅니다)

- **`유형`** 이 검색의 시작점입니다: 아이디어 77 · 책 45 · 메모 42 · 할일 42 · 레퍼런스 35 · 자료 33 …
- **`구역`** 은 폴더와 항상 같습니다. 한쪽을 고치면 다른 쪽이 따라옵니다.
- **`담당`**(책임지는 사람)과 **`작성자`**(쓴 주체)는 다른 값입니다. AI가 **본문을 쓴** 글은 작성자에 그 이름이 남습니다 — `요약` 한 줄만 자동으로 채운 것은 쓴 게 아니라서 비워 둡니다.

찾을 때는 이렇게 씁니다.

```bash
grep -rl '^유형: 할일' --include='*.md' .
grep -rl '^  - 세컨드 브레인' --include='*.md' .
```

## 자동으로 되는 것들

볼트 안에 직접 만든 옵시디언 플러그인 하나(`.obsidian/plugins/gaeddong-claude`)가 돌고 있습니다.

| 기능 | 무엇을 하나 |
| --- | --- |
| **PARA 구역 정리** | `구역` 과 폴더를 양쪽으로 맞춤. 어느 폴더에서 새 노트를 만들어도 이름표를 붙여 줌. 프로젝트 폴더를 만들면 **폴더 이름을 딴 보드**를 한 장 만들고, 캔버스 옆에는 노트를 세워 줌 (캔버스는 속성을 가질 수 없어서 그냥 두면 어느 보드에도 안 뜹니다). 폴더를 다른 구역으로 옮기면 **보드 속 경로가 따라감**. 책장에서 책을 추가하면 **책 폴더째로** 세움. `분류` 도 폴더를 따라감 — 폴더 이름을 바꾸거나 다른 폴더로 끌어 옮겨도 맞춰지고, 분류를 고치면 그 폴더로 옮김. 인박스에서 **여러 장을 한 번에** PARA로 보냄 (핀보드 `☑ 일괄 보내기` · 탐색기 다중 선택 우클릭) |
| **인박스 자동 감싸기** | 인박스에 던진 파일·폴더를 노트로 감쌈 (PDF·hwp·zip 도 링크로 열림). 첨부와 던진 문서(.md)의 `요약`·`주제` 를 agy(Antigravity CLI)로 채움 — **지금은 한 건에 몇 분씩 걸립니다 (알려진 문제, 아직 안 고침)** |
| **커버 자동 채우기** | 본문 첫 이미지를 `커버` 로 |
| **캔버스 우측에서 열기** | 캔버스 카드를 옆 화면에서 |
| **상태 칩** | 표에서 `상태`·`마감`·`일정` 을 색 칩으로 (날짜는 남은 날에 따라 색이 바뀜) |
| **홈 버튼** | 탭 제목줄 오른쪽 🏠 — 누르면 그 탭이 홈으로 (Ctrl+클릭은 새 탭) |

버그가 나오면 `1.🎯(Project) 프로젝트/🐛 버그 리포트/` 에 적습니다. 보드의 `+` 를 누르면
**무슨 일이 났나 / 이렇게 하면 다시 난다 / 이래야 맞다 / 알아낸 것** 네 칸이 깔립니다.
새 유형도 새 속성도 아니고 그냥 할일이라, 칸반·담당자 탭·마감 칩이 전부 그대로 붙습니다.

보드(`.base`) 27개가 이름표로 노트를 모읍니다. 칸반은 **하나**이고, 프로젝트와 담당자는 뷰로 고릅니다.

## 폴더 한눈에

```
개똥이 머릿속/
├── !🏠 홈/              대시보드 · 달력 · 오늘 · 볼트 지도
├── 0.📥 인박스/          던져 넣는 곳 (칸: 🥭 망고 · 🐶 개린)
├── 1.🎯(Project) 프로젝트/
├── 2.🌱(Area) 관리 영역/   원칙 · 관찰 기록 · 회의록
├── 3.📦(Resource) 자료/
├── 4.🗄️(Archive) 보관/
├── docs/                에이전트용 자세한 규칙 (주제별 · 무엇을 읽을지는 CLAUDE.md 가 알려 줌)
├── skills/              에이전트 스킬 (회의록 정리·배포 · 기획 노트를 할 일로 쪼개기)
├── AGENTS.md            에이전트 입구
├── CLAUDE.md            에이전트용 규칙의 입구
└── .obsidian/           설정 · 직접 만든 플러그인 · 스니펫
```

## AI에게 시킬 때

폴더 이름 대신 이름표로 부탁하면 정확합니다.

- "유형이 레퍼런스인 것 중에 상태가 picked 인 것"
- "담당이 Rin 인 할일 모아줘"
- "구역이 3.resource 인 자료 중에 커버 없는 것"

- "이 회의록 정리해줘" → "배포해줘" — `skills/meeting-notes` 를 따라 할 일 후보를 뽑고, 사람이 ✅ 한 것만 할일로 만듭니다

양식(`!(Template)…`)과 `skills/` 는 옵시디언 **제외된 파일**이라 보드·검색에 안 뜹니다 — 탐색기에서 여세요.

**삭제는 사람이 합니다.** 에이전트는 버릴 것을 `4.archive` 로 옮기고 알려만 줍니다.
