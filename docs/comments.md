# 코멘트 · @언급 · 슬랙 알림

> 입구는 볼트 맨 위 `CLAUDE.md` 입니다. 노트에 코멘트를 달거나, 언급 알림(슬랙)을 손볼 때 읽습니다.
> 2026-09-22 에 만들었습니다 (`plugins/claude` 의 **💬 코멘트 · @언급**).

노션 댓글처럼 씁니다. 옵시디언에는 이 기능이 없어서 우리 플러그인에 넣었습니다.

## 쓰는 법

| 하려는 것 | 어떻게 |
| --- | --- |
| 코멘트 달기 | 글을 고르고 우클릭 → `💬 코멘트 달기` (안 고르면 그 줄 전체). 패널의 `＋ 댓글 달기`, 명령 팔레트 `코멘트 달기` 도 같음 |
| **보기 · 답글 · 해결** | **오른쪽 `💬 토론` 패널** — 노션의 "토론" 처럼 지금 보는 노트의 댓글이 카드로 모이고, 카드마다 답글 칸 · `@` 단추 · `✅ 해결`. 해결된 건 아래 `▸ ✅ 해결됨 N` 에 접힘 |
| 패널 여는 곳 | 왼쪽 리본 💬 · 아래 상태바 `🔔` · 본문의 `💬` 누르기 (그 스레드가 강조됨) · 명령 `토론 패널 열기`. 기기마다 처음 켤 때 한 번 저절로 열림 |
| 본문 그 자리로 | 패널 카드 맨 위 인용(보라 줄)을 누름 |
| 부르기 | `@Rin` `@민규 서` 단추. 직접 `@민규서` 라고 써도 됩니다 (띄어쓰기 상관없음) |
| 나를 부른 것 | 패널 맨 위 `🔔 나를 부른 것` (볼트 전체) — 누르면 그 노트로 가서 그 스레드를 강조. 상태바 `🔔 N` 도 같은 수 |

패널은 **지금 보는 노트를 따라갑니다.** 답글을 쓰는 동안엔 노트가 바뀌어도 패널을 다시 그리지 않고 (커서·쓰던 글 보존),
칸을 벗어나면 그때 새로 그립니다. 패널은 노트 안의 `## 💬 코멘트` 를 보여 주고 고치는 창일 뿐, 저장 방식은 그대로입니다.
(2026-09-22 — 슬랙 · 노트 맨 아래 · 팝업 세 군데를 오가서 낯설고 불편하다는 말이 나와 만들었습니다)

`🔔` 는 **나를 불렀는데 내가 그 뒤로 답을 안 한 스레드**입니다. 내가 나를 부른 "나중에 볼 것" 도 셉니다.
부르지 않고 답하거나 해결하면 빠집니다.
다른 사람이 남긴 건 🔀 동기화로 받은 뒤에 뜹니다.

## 어디에 저장되나 — 노트 안

```
- [WHAT] 요구사항 추출 작업 흐름 [[#^c-muc1i1sa|💬]]        ← 본문의 그 자리

## 💬 코멘트                                                ← 노트 맨 아래

> [!comment]- ✅ [WHAT] 요구사항 추출 작업 흐름
> **Rin** · 2026-09-22 11:13
> @민규서 납득이 안 가는 부분은 댓글에 남겨주세요.
>
> **민규 서** · 2026-09-22 11:20
> 1차 작업물이 뭔지부터 정하자 @Rin

^c-muc1i1sa
```

- 따로 파일(JSON)을 두지 않은 이유: 동기화 충돌이 나면 사람이 못 풉니다. 노트 안이면 줄 단위로 합쳐지고,
  에이전트도 그대로 읽습니다.
- 해결한 스레드는 `> [!comment]- ✅ …` (접힘). 지우지 않습니다 — 지우는 건 사람 몫입니다.
- **손으로 고쳐도 됩니다.** 머리줄 `> **이름** · YYYY-MM-DD HH:mm` 모양과 맨 끝 `^c-…` 줄만 지키면 플러그인이 읽습니다.
  `^c-…` 를 지우면 그 스레드는 코멘트로 안 읽힙니다.
- 에이전트가 코멘트에 답할 때도 같은 모양으로 스레드 안(`^c-…` 위, 마지막 `>` 줄 뒤)에 덧붙입니다.
  에이전트가 쓴 건 슬랙 알림이 안 갑니다 (알림은 플러그인 창에서 남길 때만).

## 슬랙 알림

코멘트를 **남기는 순간**, 부른 사람에게 NovelAI 슬랙으로 알림이 갑니다. 내용까지 같이 가서 동기화 전에도 슬랙에서 읽힙니다.
**자기 자신을 불러도 보냅니다** — `📌 이름 의 나중에 볼 것` 으로 슬랙에 남겨 두는 용도입니다 (2026-09-22 Rin 요청).
아무도 안 부른 코멘트만 안 보내고, 그때는 "부른 사람 없음" 알림이 뜹니다.

| | |
| --- | --- |
| 보내는 길 | NovelAI 워크스페이스의 **Incoming Webhook** 주소로 POST. 그 채널에 `<@멤버ID>` 로 불러서 그 사람에게 알림이 뜹니다 |
| 웹훅 주소 | **비밀입니다.** 설정 → Claude → 💬 코멘트 · @언급 → `슬랙 웹훅 주소`. 기기마다 넣고 git 에 안 올라갑니다 (`app.saveLocalStorage`) |
| 멤버 ID | 같은 설정의 `슬랙 사용자 ID` (`Rin = U09LDCUNWAF` · `민규 서 = U09LPA180CC`). 비밀이 아니라 `data.json` 으로 같이 씁니다 |
| 주소가 없는 기기 | 슬랙은 건너뛰고 "옵시디언 안(🔔)에서만 보입니다" 알림만 뜹니다 |
| 보내다 실패하면 | 그 기기에 쌓아 두고 다음에 옵시디언을 켤 때 다시 보냅니다 |
| 메시지 모양 | **댓글 내용이 주인공** — 큰 글씨(한 줄 150자 안이면 header, 길면 굵은 문단)로, `@이름` 은 빼고 할 말만. 나머지는 작고 흐리게: 위에 `💬 보낸 사람 → @받는 사람` (멘션·알림은 이 줄로), 아래에 코멘트 단 자리의 제목·윗줄·그 줄·아랫줄, 맨 아래 `📄 노트 · 폴더   옵시디언에서 열기 →`. 슬랙 Block Kit |
| 바로 가기 링크 | 설정의 `바로 가기 주소 틀`. 기본값은 우리 중계 페이지 `https://hyerin-seo.github.io/obsidian-comment-repository/#file={file}&{vaults}` (저장소 `Hyerin-Seo/obsidian-comment-repository`, 페이지 한 장). **비워 두면 이 기본값**, `끔` 이면 링크 없음 |

**바로 가기 링크가 https 중계를 거치는 이유**: 슬랙은 `obsidian://` 링크를 눌리게 해 주지 않습니다. 그래서
https 페이지를 한 번 거쳐 `obsidian://open?vault=…&file=…` 로 넘깁니다. 열리는 건 **누른 사람 컴퓨터의 옵시디언**입니다.
볼트 이름·노트 경로는 주소의 `#` 뒤에만 실려서 GitHub 서버로 안 가고 브라우저 안에서만 읽힙니다.
처음 한 번은 브라우저가 "Obsidian 을 열까요?" 하고 묻습니다 — 항상 허용을 켜 두면 다음부터 바로 열립니다.
기기마다 볼트 폴더 이름이 달라서 (Rin `개똥이 머릿속` · 민규 서 `What-s-in-my-head`) 링크에 **볼트 이름 후보를 다 담고**,
중계 페이지가 처음 한 번 "내 볼트는 어느 것인가요?" 를 물어 그 브라우저에 기억합니다. 다음부터는 바로 그 볼트로 엽니다.
페이지 아래의 볼트 단추로 언제든 바꿀 수 있습니다.
(예전엔 받는 사람 볼트 이름 하나만 넣어서, 채널의 다른 사람이 누르면 "Vault not found" 가 떴습니다 — 2026-09-22 고침)
두 사람의 볼트 이름은 코드 기본값에 들어 있습니다. 볼트 폴더 이름을 바꾸면 그 기기가 켤 때
`data.json` 의 `comment.vaults` 에 새 이름을 덧적습니다 — 기본값과 같으면 파일을 안 건드립니다 (두 기기가 같은 줄을 고쳐 동기화 충돌이 나지 않게).
사람이 늘면 `DEFAULTS.comment.vaults` 에 한 줄 더합니다.

**웹훅 만들기** (한 번, 워크스페이스에 앱을 설치할 수 있는 사람이):

1. https://api.slack.com/apps → `Create New App` → **`Blank app`** (예전 이름 `From scratch`) → 이름 `Obsidian Alert` (앱 이름엔 한글이 안 됩니다), 워크스페이스 NovelAI
2. 왼쪽 `Incoming Webhooks` → 스위치 On → `Add New Webhook` → 알림 받을 채널 고르기 → 허용
3. 나온 주소를 복사해 옵시디언 설정의 `슬랙 웹훅 주소` 에 붙여 넣고 `시험 보내기`
4. 다른 사람 컴퓨터에도 같은 주소를 넣습니다 — 주소는 슬랙 DM 으로 건네고 **볼트에는 적지 마세요**

부른 사람이 그 채널에 들어가 있어야 알림이 갑니다.
지금 쓰는 채널은 **`#obsidian-comment`** (앱 `Obsidian Alert`, 2026-09-22 Rin 이 만듦 · 혜린·서민규 둘 다 들어가 있음).

## 이 컴퓨터를 쓰는 사람

코멘트에 적히는 이름이고, `🔔` 는 이 이름을 부른 것을 셉니다.
처음엔 git 의 `user.name` 을 gaeddong-sync 이름표로 바꿔 짐작합니다 (`Hyerin-Seo → Rin`, `knee2420 → 민규 서`).
모르면 처음 코멘트를 달 때 한 번 묻습니다. 바꾸려면 설정의 `이 컴퓨터를 쓰는 사람`.

부를 수 있는 사람은 **칸반 담당자 명단**(설정 → PARA 구역 정리 → 칸반에 늘 두는 담당자)과 같습니다.
사람이 늘면 거기에 더하고, 슬랙 멤버 ID 도 한 줄 더합니다.

## 알려진 한계

- `💬` 에 마우스를 올렸을 때 옵시디언 기본 미리보기가 뜨는지는 확인 못 했습니다. **누르면 토론 패널에서 강조되는 것**은 확인했습니다.
- 슬랙에서 답하면 옵시디언으로 안 들어옵니다 (한 방향). 답은 옵시디언 패널에서.
- 슬랙 알림은 채널에 올라가는 방식입니다. 사람마다 DM 으로 받으려면 봇 토큰(`chat:write`)을 쓰는 방식으로 바꿔야 합니다.
- 바로 가기 링크는 노트까지만 엽니다. 그 스레드 자리로 스크롤하지는 않습니다 (`💬` 를 눌러 여세요).
