# 할일 · 프로젝트 보드

> 입구는 볼트 맨 위 `CLAUDE.md` 입니다. 할일 카드·칸반·담당자 뷰·캔버스·버그 리포트를 다룰 때 읽습니다. 할일의 `상태`·`일정`·`마감` 값과 `🔥 지금 할 것` 뷰의 규칙은 `docs/properties.md` 에 있습니다.
> 2026-09-21 에 `CLAUDE.md` 에서 떼어 왔습니다. 규칙은 그대로이고 자리만 옮겼습니다.

## 프로젝트 보드 — 칸반 하나, 프로젝트·담당자는 뷰로 고른다

**칸반은 하나입니다.** 프로젝트가 100개든 노트가 1000개든 한 판에 다 들어옵니다.
프로젝트도 담당자도 스윔레인이 아니라 **뷰**로 고릅니다 — 무엇이 늘어도 판이 안 쪼개집니다.

| | |
| --- | --- |
| 보드 | `1.🎯(Project) 프로젝트/📋 프로젝트 보드.base` **하나뿐** |
| 무엇이 뜨나 | `유형: 할일` 이고 `구역: 1.project` 인 것 (양식 제외) |
| 칸 | `to do` · `진행중` · `확인 필요` · `완료` · `퍼즈` · `히스토리` |
| 스윔레인 | **없습니다.** `swimlaneByProperty` 를 안 넣으면 한 판이 됩니다 |
| 프로젝트 | `1.🎯(Project) 프로젝트` **바로 아래 폴더**. 뷰 이름이 곧 폴더 이름입니다 |
| 담당자 | **고정 명단**입니다 — `👤 Rin` · `👤 민규 서` · `👤 미할당` 이 모든 보드에 늘 있습니다 |
| 프로젝트 뷰의 필터 | `file.inFolder("1.🎯(Project) 프로젝트/<폴더>")` — **하위의 하위까지 다 걸립니다** (`inFolder` 는 `path.startsWith(폴더 + "/")`, obsidian.asar 확인) |
| 담당자 뷰의 필터 | `note["담당"].contains("[[이름]]")` — **대괄호까지** 넣어야 합니다 (아래) |

**폴더를 만들면 뷰가 저절로 붙습니다.** `1.🎯(Project) 프로젝트` 바로 아래에 폴더를
만들면 3초 뒤 그 프로젝트만 거르는 칸반 뷰가 보드에 추가되고, 그 폴더 안에 그
프로젝트만 거르는 보드 파일도 한 장 생깁니다.

**그 보드 이름은 폴더 이름 그대로입니다.** 앞머리 이모지만 뗍니다 — 보드가 자기
🗂️ 를 달기 때문입니다.

| 폴더 | 보드 |
| --- | --- |
| `new project for test` | `🗂️ new project for test 보드.base` |
| `😁MangoDoc_엔진설계` | `🗂️ MangoDoc_엔진설계 보드.base` |

한때는 어느 프로젝트든 `🗂️ 프로젝트 보드.base` 한 이름으로 만들었습니다. 셋이 다
`프로젝트 보드` 라 **파일 탐색기에서도 탭에서도 어느 프로젝트 것인지 알 수 없었습니다.**
옛 이름으로 만들어 둔 것은 옵시디언을 켤 때 폴더 이름표로 바뀝니다 —
**플러그인이 지은 그 이름일 때만** 건드리고, 사람이 붙인 이름(`🗂️ PARA 구축 보드`)은
그대로 둡니다. 폴더 이름을 바꾸면 보드 이름도 따라갑니다.

**담당자 뷰는 일이 있든 없든 있습니다.** 명단이 고정이라서요. 명단에 없는 이름이
`담당` 에 적혀 있으면 그 사람 뷰도 따로 붙습니다 (옵시디언을 켤 때 훑습니다) —
명단은 줄이는 것이 아니라 늘리기만 하는 기준입니다.

- **덧붙이기만 합니다 — 보드를 다시 쓰지 않습니다.** 칸반 플러그인이 카드를 끌 때마다
  `cardOrders`·`columnColors` 를 그 파일에 적어 두기 때문에, 통째로 다시 쓰면 사람이
  맞춰 둔 순서가 날아갑니다. 새 뷰는 **마지막 칸반 뷰 뒤**에 끼워 넣습니다.
- 이름에 `이미지` `image` `attachment` `첨부` 가 든 폴더는 프로젝트가 아닙니다
  (그림·첨부 보관소). `.` `!` 로 시작하는 폴더도 뺍니다.
- 밀린 것은 명령 팔레트 `프로젝트 보드에 빠진 뷰 붙이기 (프로젝트 · 담당자)`.
- 끄려면 설정 → Claude → PARA 구역 정리 → `프로젝트·담당자가 늘면 보드에 뷰를 붙인다`.
- 칸 목록은 `KIND_STATES["할일"]` 하나에서 나옵니다. **칸을 바꾸려면 거기만 고치세요** —
  보드에 붙는 새 뷰도 그걸 읽습니다.

### 담당자로 나누지 말고 담당자로 거르세요

예전에는 프로젝트별 보드가 칸반을 `swimlaneByProperty: note.담당` 으로 갈랐습니다.
사람이 늘 때마다 판이 세로로 쪼개지고, 빈 줄(`Uncategorized`)이 늘 맨 위를 차지하고,
같은 사람이 `민규 서` 와 `[[민규 서]]` 두 줄로 나뉘어 있었습니다. 프로젝트와 같은
이유로 **뷰**로 바꿨습니다. 스윔레인은 볼트 어디에도 없습니다.

**필터는 대괄호까지 넣어야 합니다.**

```yaml
- note["담당"].contains("[[민규 서]]")   # 맞음
- note["담당"].contains("민규 서")       # 조용히 0건
```

`담당` 은 목록이고 값이 **링크**입니다. 목록의 `contains` 는 `looseEquals` 로 견주는데,
링크와 글자를 견줄 때 글자를 위키링크로 파싱해서 맞춰 봅니다 (obsidian.asar 확인).
대괄호가 없으면 파싱이 안 되고, 틀렸다는 말도 없이 빈 칸반이 나옵니다.

**명단은 고정입니다 — 일이 없어도 탭은 있습니다.**

| | |
| --- | --- |
| 지금 명단 | `Rin` · `민규 서` (+ 늘 맨 뒤에 `👤 미할당`) |
| 어디서 고치나 | 설정 → Claude → PARA 구역 정리 → **칸반에 늘 두는 담당자** (한 줄에 한 사람) |
| 명단에 없는 이름이 `담당` 에 적히면 | 그 사람 뷰도 붙습니다 — 안 보이는 일이 없게 |

일이 있는 사람만 탭을 만들면, 일이 하나 생겼다 끝날 때마다 탭이 나타났다 사라집니다.
그러면 **"나한테 온 게 없다" 를 확인할 자리가 없어집니다.** 빈 칸반이 답입니다.

### 프로젝트별 보드 — 같은 명단, 폴더만 하나 더 걸립니다

프로젝트 폴더 **안에** 있으면서 그 폴더를 거르는 `.base` 는 그 프로젝트의 보드로 봅니다
(`🗂️ 문서 어시스턴트 보드.base` · `🗂️ PARA 구축 보드.base` — 이 둘은 사람이 이름을 지은
것이고, 이제 새로 생기는 것은 폴더 이름을 그대로 땁니다). 여기에도 **같은 고정 명단**이
붙고, 필터에 그 폴더 조건이 하나 더 들어갑니다.

```yaml
- file.inFolder("1.🎯(Project) 프로젝트/🚚 PARA 구축 — 자료 이식")
- note["담당"].contains("[[Rin]]")
```

이 둘은 이제 전체 보드의 프로젝트 뷰와 하는 일이 같습니다. **지워도 됩니다** —
지우는 것은 사람 몫입니다 (에이전트는 안 지웁니다).

### 캔버스는 **속성을 가질 수 없습니다** — 옆에 노트를 세웁니다

`.canvas` 를 프로젝트 폴더에 만들어 두면 보드에 안 뜹니다. 속성을 안 채워서가 아니라
**채울 수가 없어서**입니다.

| | |
| --- | --- |
| 프론트매터를 읽어 주는 파일 | **마크다운 하나뿐**입니다 (obsidian.asar 확인 — metadataCache 의 `isSupportedFile` 이 `"md" === e.extension` 한 줄) |
| 베이스가 훑는 파일 | **볼트의 모든 파일**입니다 (`vault.getFiles()`, obsidian.asar 확인). 그래서 보드 필터에 `file.ext == "md"` 가 있습니다 |
| 그래서 캔버스는 | 후보에는 들어가지만 `유형`·`상태` 가 없어 **어느 칸에도 못 들어갑니다** |

인박스가 첨부에 하는 것과 똑같이 **옆에 같은 이름의 노트를 세웁니다.** 보드에 뜨는
카드는 그 노트고, 카드를 누르면 본문 링크로 캔버스가 열립니다.

| 무엇이 | 어떻게 |
| --- | --- |
| PARA 폴더에 캔버스를 만든다 | 1.5초 뒤 옆에 `캔버스이름.md` 가 생깁니다 |
| 그 노트의 속성 | **속성 붙이기와 같은 기준** — 자리가 말해주는 것만. `1.project` 면 `유형: 할일` · `상태: to do` |
| 캔버스 파일 | **제자리에 그대로.** 첨부가 아니라 문서입니다 (인박스도 캔버스만 `이미지/` 로 안 옮깁니다) |
| 본문 | `🖼 캔버스 열기 → [[…]]` 한 줄 + 임베드 |
| `요약` | **비워 둡니다.** 그림을 보고 무슨 내용인지 짐작하지 않습니다 |

- 링크에는 **확장자가 꼭 있어야 합니다** (`[[캔버스 테스트.canvas]]`). 노트와 캔버스가
  이름이 같아서, 확장자를 빼면 링크가 이 노트로 되돌아옵니다.
- 고를 여지가 있는 구역(`2.area` · `3.resource` · `4.archive`)이면 유형을 비워 두고
  이웃이 쓰는 값을 누를 수 있는 알림으로 권합니다 — 노트를 새로 만들 때와 같습니다.
- **그 노트를 지우면 캔버스가 보드에서 다시 사라집니다.** 캔버스가 지워지는 게 아니라
  카드가 없어지는 것입니다.
- 밀린 것은 명령 팔레트 `볼트 전체 — 혼자 있는 캔버스를 노트로 세우기`,
  한 장만은 `이 캔버스를 노트로 세우기` (캔버스 우클릭에도 있습니다).
- 끄려면 설정 → Claude → PARA 구역 정리 → `캔버스 옆에 노트를 세운다`.
- 엑스칼리드로우는 해당 없습니다 — `.excalidraw.md` 라서 처음부터 마크다운입니다.

### 🐛 버그 리포트 — 볼트를 고치면서 나오는 것을 여기 적습니다

`1.🎯(Project) 프로젝트/🔬 볼트 실험실/🐛 버그 리포트/` 는 **그냥 프로젝트 폴더 하나**입니다.
새 유형도, 새 속성도, 새 보드 종류도 안 만들었습니다 — 이미 있는 것으로 다 됩니다.

| 쓰는 것 | 무엇이 되나 |
| --- | --- |
| `유형: 할일` | 프로젝트 보드·`🔥 오늘`·홈 달력에 그대로 뜹니다 |
| `상태` | `to do → 진행중 → 확인 필요 → 완료` (치우려면 `히스토리`). 칸반 칸이 그대로 |
| `담당` | `👤 Rin` · `👤 민규 서` · `👤 미할당` 탭. 비우면 미할당에 모입니다 |
| `마감` | 급한 것. 지나면 빨강 · 오늘이면 주황으로 카드에 뜹니다 |
| `분류: 🐛 버그 리포트` | 폴더 이름과 같아서 PARA 보내기도 여기로 떨어집니다 |

- 보드는 `🗂️ 버그 리포트 보드.base`. `+` 를 누르면 **이 프로젝트 전용 양식**
  (`!(Template) 버그 리포트.md`)으로 만들어집니다 — `newItemTemplate` 이 그것만 다릅니다.
- 본문은 넷입니다. **무슨 일이 났나 · 이렇게 하면 다시 난다 · 이래야 맞다 · 알아낸 것.**
  위 둘만 채워도 리포트입니다. 화면이면 이미지를 붙이세요 — 첫 이미지가 `커버` 가 됩니다.
- **심각도 속성은 일부러 안 만들었습니다.** 급한 건 `마감` 이, 지금 붙잡은 건 `상태` 가
  말합니다. 속성을 늘리면 채울 칸만 늘고 볼 자리는 안 늘어납니다
  (없앤 `중요도` 와 같은 이유입니다).
- **카드에 `🐛 bug` 칩이 붙습니다.** 양식이 `작성자` 에 `"[[bug]]"` 를 기본으로 넣고,
  `author-chips.css` 가 빨간 칩으로 그립니다. 프로젝트 보드 한 판에 여러 프로젝트가
  섞여 있어서, 폴더를 안 보고도 버그인 걸 알게 하려는 것입니다.
  사람 이름을 같이 적어도 **칸반 카드에는 `bug` 만** 보입니다 — 카드의 작성자 줄은
  종류 표시만 남기고 사람·AI 칩을 숨깁니다 (2026-09-21). 속성·표에는 그대로 있습니다.
  속성을 새로 만들지 않으려고 제일 눈에 띄는 칩 자리를 빌렸습니다 — 그 대신
  `작성자` 가 "누가 썼나" 만 뜻하지는 않게 됐습니다. 이 폴더에서만 그렇습니다.
- 처음 세 장은 2026-09-16 에 실제로 잡은 것들입니다 (`상태: 완료`). 형식 보기로
  두었으니 `히스토리` 로 치우거나 지워도 됩니다.
- **`🧺 챙길 일` 도 같은 방법입니다** (2026-09-21). 회사 행정 · 가족 일 · 개인 잡무를 받는 폴더라,
  그 폴더 양식이 `작성자` 에 `"[[챙길 일]]"` 을 넣고 노란 `🧺 챙길 일` 칩으로 그립니다.

### 칸반 빠른 추가(+)가 빈 폴더를 흘리던 것 — 플러그인을 고쳤습니다

칸 머리의 `+` 로 카드를 만들면 `1.🎯(Project) 프로젝트/🧪 …/1.🎯(Project) 프로젝트/🧪 …`
같은 **빈 폴더 두 겹**이 남았습니다. 카드 자체는 제자리에 생기니 눈에 안 띄는데,
그 빈 폴더가 `분류` 와 이름이 같아서 **PARA 보내기의 도착 자리를 망가뜨렸습니다.**

경로를 두 번 붙여서 그렇습니다.

| 누가 | 무엇을 |
| --- | --- |
| `kanban-bases-view` | `createFileForView("<quickAddFolder>/<제목>")` — **전체 경로**를 넘김 |
| 옵시디언 (core) | 그 앞에 폴더를 **또** 붙임 — `newItemFolder` → 템플릿이 사는 폴더 → 필터의 `inFolder` 순 (obsidian.asar 의 `newItemMenu.open` 확인) |
| 결과 | `<폴더>/<폴더>/<제목>.md` 로 만들어짐 |
| 칸반이 수습 | 만든 파일을 `quickAddFolder` 로 **옮깁니다** (`ensureCreatedCardInFolder`). 파일은 제자리로 가고 **빈 폴더만 남습니다** |

`.base` 쪽으로는 막을 수 없습니다 — `newItemFolder` 를 지워도 템플릿 폴더가, 그것도
없으면 필터의 `inFolder` 가 대신 붙습니다. 그래서 **플러그인 한 줄을 고쳤습니다.**

```
.obsidian/plugins/kanban-bases-view/main.js
  createFileForView(fileNameToCreate, …)  →  createFileForView(baseFileName, …)
```

- 옮기는 안전장치(`ensureCreatedCardInFolder`)는 그대로 둡니다 — 그건 잘못이 아닙니다.
- **플러그인을 업데이트하면 이 줄이 되돌아갑니다.** 코드에 `[개똥이 머릿속 수정]` 주석을
  달아 뒀으니 그걸로 찾으세요. 되돌아가도 아래 치우개가 뒤를 받칩니다.
