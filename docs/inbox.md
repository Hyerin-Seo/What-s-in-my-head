# 인박스

> 입구는 볼트 맨 위 `CLAUDE.md` 입니다. 인박스를 처리하거나, 첨부·폴더를 넣거나, PARA로 보낼 때 읽습니다.
> 2026-09-21 에 `CLAUDE.md` 에서 떼어 왔습니다. 규칙은 그대로이고 자리만 옮겼습니다.

## 인박스 — 던져 넣으면 노트가 된다

보드·대시보드는 **마크다운만** 봅니다. PDF·xls·hwp 를 그냥 두면 어디에도 안 뜹니다.
그래서 인박스에 들어온 첨부를 노트로 감쌉니다.

| 무엇이 | 어떻게 |
| --- | --- |
| 파일을 인박스에 던진다 | **인박스 자동 감싸기** 가 1.5초 뒤 노트로 감쌉니다 |
| 첨부 원본 | 그 폴더의 `이미지/` 로 옮깁니다 (캔버스는 제자리 — 문서니까) |
| 새 노트 속성 | `유형: 자료` · `구역: 0.inbox` · `상태: 미처리` · `작성일` |
| `요약`·`주제` | 감싼 뒤 **`agy`(Antigravity CLI) 를 플러그인이 직접** 부릅니다. 파이썬도 클로드도 안 끼웁니다 |
| `커버` | **커버 자동 채우기** 가 알아서 (이미지일 때만) |

- 노트 이름은 `파일명.md`. 같은 이름이 이미 있으면 `파일명 (pdf).md` 로 구분합니다.
- **본문 순서: 내 판단이 위, 첨부가 아래.** `이게 뭐였더라` → `다음 행동` → `---` → 원본.
  첨부는 근거일 뿐이고 3주 뒤에 보는 건 내가 적어둔 한 줄입니다.
- **원본에는 반드시 누를 수 있는 링크를 답니다** (`📎 원본 열기 → [[파일]]`).
  임베드(미리보기)만 있으면 원본 파일 자체를 열거나 폴더에서 찾을 방법이 없습니다.
  옵시디언이 못 여는 형식(hwp·xls·zip…)은 링크로 들어가서
  우클릭 → `기본 앱으로 열기` / `폴더에서 보기` 로 갑니다.
  그 메뉴는 코어 플러그인 `open-with-default-app` 이 켜져 있어야 나옵니다 — 켜 뒀습니다.
- 안내 문구는 `%%` 로 감싸 둡니다 — 읽기 모드에서 안 보이니 채우면 그대로 노트가 됩니다.
  **파이썬 `%` 포매팅에 `%%` 를 섞지 마세요.** `%` 하나로 줄어듭니다 (이 파일에서 두 번 걸렸습니다).
- 손으로 적을 때는 핀보드의 **`✏️ 새 인박스`** 를 누릅니다 (명령 팔레트 `새 인박스 노트 쓰기`,
  왼쪽 리본 ✏️ 도 같은 것). `!(Template) 새 인박스 노트.md` 를 그대로 복사하고
  **작성일만 오늘로, `주제` 는 비웁니다** — 양식의 `주제: 양식` 이 딸려 오면 새 노트가
  전부 `#양식` 이 됩니다 (실제로 그랬습니다). 유형·구역·상태(메모 · 0.inbox · 미처리)는
  양식 그대로 둡니다. 묻는 것은 제목 · 폴더 · 한 줄뿐입니다.
  그 양식의 `%` 블록에 유형·구역·마감·상태를 어떻게 정하는지 표로 적어뒀습니다.
- **`.canvas` 는 Dataview 가 색인하지 않습니다.** 캔버스만 있으면 대시보드에 안 뜨므로
  래퍼 노트를 만듭니다. 캔버스 파일은 옮기지 않습니다.
- 손으로 돌리려면 `python .obsidian/scripts/inbox.py --wrap --ai --write`.
- **`작성자` 는 안 건드립니다 — 비워 둡니다.** `요약`·`주제` 한 줄을 채운 것과
  그 노트를 *쓴* 것은 다릅니다. (게다가 요약을 쓰는 건 agy = Antigravity 라
  한때 박혀 있던 `Claude` 는 사실도 아니었습니다.) 적고 싶으면 설정 → Claude →
  인박스 자동 감싸기 → `작성자에 적을 이름` 에 넣으세요. 비어 있으면 안 적습니다.
  `inbox.py` 의 `AI_AUTHOR` 이 같은 뜻입니다 — **한쪽만 고치지 마세요.**
- **agy 는 빈 칸만 채웁니다.** 요약·주제 중 하나만 비어도 부르지만, 사람이 적어 둔 칸은 안 씁니다.
  예전엔 둘 다 덮어써서 옮겨 온 회의록의 주제가 사라졌습니다 (2026-09-22 버그 리포트). 플러그인 `askAgy` 와
  `inbox.py` 가 같은 규칙입니다 — **한쪽만 고치지 마세요.**
- **`agy` 는 연달아 부르면 막힙니다.** 한 번에 하나씩, 사이에 간격(기본 4초)을 두고,
  실패하면 6·12초 백오프로 세 번까지 재시도합니다. 그래도 실패하면 요약을 비워 둡니다.
- 쿼터가 떨어지면 `Individual quota reached … Resets in NNh` 가 옵니다. 코드 문제가
  아니니 기다려야 합니다. 그동안 감싸기는 정상 동작하고 요약만 빈 채로 남습니다.
- 몰아서 돌릴 때는 `python .obsidian/scripts/inbox.py --ai --write` 도 그대로 씁니다.
- **문서(.md)를 던져도 채웁니다.** 예전엔 첨부·폴더를 감쌀 때만 agy 를 불러서, 다른 데서 쓴 문서를 인박스에
  던지면 속성만 붙고 요약·주제가 영영 비었습니다 (2026-09-17 버그 리포트). 이제 **사람이 쓴 글자가 80자**
  (속성·`%%`·제목줄·빈 글머리·임베드·공백을 뺀 것, `meaningfulText`) 넘는 .md 가 인박스에 생기거나 옮겨 오면
  대기줄에 넣습니다. `✏️ 새 인박스` 로 막 만든 노트는 양식 뼈대뿐이라 안 넣습니다 — 그건 여전히 지어내기입니다.
- **agy 실행 파일은 플러그인이 직접 찾습니다.** 옵시디언은 켜질 때의 PATH 를 물려받아서, agy 를 깐 뒤 다시 안
  켰으면 `spawn agy ENOENT` 로 요약이 조용히 빕니다. 설정이 `agy` 면 `%LOCALAPPDATA%\agy\bin\agy.exe` → PATH 순으로
  찾고(`resolveAgy`), 못 찾으면 세 번 기다리지 않고 바로 알립니다.
  **`shell: true` 는 켜지 마세요** — 줄바꿈 든 프롬프트가 깨지고, 켜지 않아도 node 가 `.exe` 를 붙여 찾습니다.
- **한 번에 5분 30초**(`agyTimeoutMs`) 넘으면 끝내고 다음으로 갑니다. 없을 땐 agy 가 멈추면 대기줄 전체가 멈췄습니다.
- **실패는 `.obsidian/plugins/claude/agy.log` 에 남습니다** (git 제외 — 기기마다 다릅니다). 알림은 사라지고
  콘솔은 옵시디언을 끄면 지워져서, 다른 컴퓨터에서 왜 안 되는지 쫓을 길이 없었습니다.
- 연결이 의심되면 명령 팔레트 `agy 연결 확인 (실행 파일 · 버전)`, 또는 설정 → Claude → 인박스 자동 감싸기 →
  `agy 실행 파일` 옆 `연결 확인`.

### 폴더를 던졌을 때 — 통째로 하나의 자료

파일과 똑같이 노트로 감쌉니다. 다만 **폴더는 옮기지도, 안을 건드리지도 않습니다.**
안에 든 파일 30개를 따로따로 감싸면 던진 사람이 원한 묶음이 부서집니다.

| 무엇이 | 어떻게 |
| --- | --- |
| 칸 안에 폴더를 던진다 | 2.5초 뒤 **옆에** 노트를 만듭니다 (`폴더이름.md`). 폴더는 제자리 |
| 노트 본문 | `📁 원본 폴더 열기 → 폴더::경로` · 파일 수 · 용량 · 안엣것 12개까지 목록 |
| 그 링크를 누르면 | **폴더 창이 열립니다** (`app.openWithDefaultApp`). 볼트 상대경로라 볼트를 옮겨도 안 깨집니다 |
| 폴더 안의 파일들 | **아무것도 안 합니다.** 감싸지도, `이미지/` 로 옮기지도 않습니다 |

**층으로 가릅니다.** 인박스 바로 아래는 *자리*, 그 안이 *자료*입니다.

```
0.📥 인박스/🐶 개린 인박스/            ← 칸 (핀보드 탭). 폴더를 만들어도 안 감쌉니다
0.📥 인박스/🐶 개린 인박스/자료.pdf     ← 던진 것 → 노트 + 이미지/ 로 이동
0.📥 인박스/🐶 개린 인박스/받은 폴더/   ← 던진 것 → 노트 (폴더는 제자리)
0.📥 인박스/🐶 개린 인박스/받은 폴더/a.pdf  ← 안 건드립니다
```

- 인박스 **바로 아래**에 폴더를 만들면 새 칸으로 봅니다. 자료가 아니라 자리라서요.
  (인박스 **밖**에 생긴 폴더에는 이 알림을 안 띄웁니다 — 예전엔 확인이 없어서 3.resource 에
  유령 폴더가 생겼을 때도 "인박스의 새 칸으로 봅니다" 가 떴습니다.)
  그때는 감싸는 대신 알림만 뜹니다 — 아무 반응이 없으면 고장으로 보이니까요.
- 안에서 한 개만 따로 다루고 싶으면 **그 파일을 칸으로 꺼내세요.** 그러면 감싸집니다.
- `📤 PARA로 보내기` 는 **노트만** 옮깁니다. 폴더는 파일 탐색기에서 같이 옮기세요.
  (노트 안의 `폴더::` 경로도 같이 고쳐야 합니다 — 위키링크가 아니라 글자입니다)
- 옵시디언은 폴더 드롭을 실제로 받습니다 (obsidian.asar 확인: dataTransfer 항목이
  디렉터리면 `importDirectory` 로 통째로 복사해 넣습니다). 그렇게 들어온 폴더도
  `vault.on("create")` 로 똑같이 잡힙니다. 파일 탐색기에서 복사해 넣어도 같습니다.
- `폴더::` 를 칩으로 그리는 것은 마크다운 후처리기입니다. 읽기 모드·라이브 프리뷰 다 됩니다.
  꾸밈은 `plugins/claude/styles.css` 에 있습니다 (스니펫이 아니라 플러그인 것이라서요).

### 인박스에서 나가는 길 — `📤 PARA로 보내기`

**인박스에 "처리완료" 는 없습니다.** 처리했다는 것은 **P·A·R·A 어딘가로 갔다**는 뜻이고,
버린 것은 `4.archive` 로 간 것입니다. 나가면 `구역` 이 바뀌므로 핀보드·`🔥 오늘`·
`🧠 주간 리뷰` 에서 저절로 사라집니다. 상태로 완료 표시를 하면 처리한 것이 인박스에
영영 쌓이기만 합니다 — 그래서 옛 `처리완료로`·`미처리로` 버튼과 그 칸을 없앴습니다.

| 어디서 | 무엇 |
| --- | --- |
| 핀보드 카드의 `📤 PARA로 보내기` | 구역 넷 중 하나를 고르면 창이 뜹니다 |
| 명령 팔레트 `이 노트를 PARA로 보내기` | 지금 열어둔 노트 |
| 파일 우클릭 `PARA로 보내기…` | 탐색기에서 |
| 핀보드 `☑ 일괄 보내기` | 카드를 여러 장 골라 한 창으로 (아래) |
| 탐색기에서 Ctrl·Shift 로 여러 개 고르고 우클릭 `PARA로 일괄 보내기…` | 인박스 밖 노트도 한 번에 |

**여러 장을 한 번에 보낼 때** (`BatchSendModal`, 2026-09-17 개발 요청) — 한 장짜리 창과 같은 `sendTo` 를
차례로 부르니 규칙은 똑같고, 무엇을 모두에 줄지만 다릅니다.

| 칸 | 여러 장일 때 |
| --- | --- |
| `구역` | 모두에 한 번 |
| `유형` | **각자 지금 값 그대로.** 고른 구역에 없는 유형인 노트만 창에서 한 번에 고릅니다 — pdf 자료와 생각 메모를 한 유형으로 덮으면 한쪽이 틀립니다 |
| `상태` | 노트마다 그 유형이 쓰는 값으로 (`stateFor` — 미처리는 사라짐) |
| `분류` · `마감` | 적으면 모두에, **비우면 각자 지금 값 그대로** |

- 대문·대시보드·양식과 제외 폴더의 노트는 빼고, 남은 게 한 장이면 원래 보내기 창을 엽니다.
- 보내는 동안은 옮길 때마다 뜨는 "속성 맞추기" 창을 띄우지 않고, 끝나고 안 맞는 게 있으면 한 번만 알립니다.
- 핀보드는 `☑ 일괄 보내기` 를 누르면 고르기 모드가 됩니다 — 카드를 누르면 열리는 대신 체크되고,
  위 줄의 `📤 PARA로 보내기 ▾` 로 구역을 고릅니다. 보낸 카드는 판에서 바로 빠집니다.

창이 한 번에 묻는 것은 다섯입니다 — **구역 · 유형 · 상태 · 분류 · 마감.**
**PARA 구역 정리** 의 `sendTo()` 가 속성을 먼저 쓰고, 캐시가 그걸 읽기를 기다렸다가 파일을 옮깁니다.

| 칸 | 어떻게 채워지나 |
| --- | --- |
| `구역` | 카드에서 고른 것. 네 구역의 판단 기준이 그대로 붙어 나옵니다 |
| `유형` | **사람이 고릅니다.** 그 구역에 있을 수 있는 유형만 (`ZONE_KINDS`). 지금 값이 그 구역에 없으면 `(지금 값 · 이 구역엔 없는 유형)` 으로 남겨 둡니다 |
| `상태` | 지금 값이 그 유형에서도 쓰이면 그대로, 아니면 그 유형의 첫 값. `미처리` 는 인박스 전용이라 여기서 사라집니다. 보관으로 가는 `할일` 은 `히스토리` |
| `분류` | **그 구역이 실제로 쓰는 값**을 많이 쓰는 순서로 권합니다 (지어내지 않습니다). 폴더 이름과 같으면 그 폴더로 들어갑니다 |
| `마감` | 프로젝트면 사실상 필수 — 홈 달력과 마감 보드가 이걸 봅니다 |

- **유형을 같이 묻는 이유**: 보드는 폴더가 아니라 `유형` 으로 거릅니다. 구역만 바꾸면
  파일만 옮겨지고 옛 보드에 그대로 뜹니다. 어차피 옮긴 직후에 `FixModal` 이 떠서 물어볼
  것이라면 보내기 전에 한 번에 묻는 편이 손이 덜 갑니다.
- 창 아래에 **떨어질 자리가 미리 보입니다** (`→ 1.🎯(Project) 프로젝트/🧪 …/파일.md`).
- 구역 표(`ZONES`)는 플러그인이 `this.zones` 로 내놓고 핀보드가 그걸 씁니다.
  **같은 표를 두 군데 적지 마세요.**

### 옵시디언이 모르는 확장자 — 이걸 먼저 켜야 합니다

옵시디언이 아는 확장자는 **이미지·오디오·영상·pdf·md·canvas·base 뿐**입니다.
`hwp` `cell` `show` `hwdt` `xls` `zip` `csv` 는 목록에 없고, 기본 설정
`showUnsupportedFiles: false` 에서는 **옵시디언이 그 파일의 존재 자체를 모릅니다.**
링크도 안 걸리고 파일 탐색기에도 안 뜹니다.

```
설정 → 파일과 링크 → 모든 파일 확장자 감지  (app.json 의 showUnsupportedFiles: true)
```

이미 켜 뒀습니다. **끄면 첨부 링크가 전부 깨진 링크가 됩니다.**

### 대시보드에서 조심할 것 — Dataview 의 링크는 객체입니다

`0.📥 인박스/📥 인박스 대시보드` 는 `dataviewjs` 한 블록입니다.
프론트매터의 위키링크는 Dataview 가 **`Link` 객체**로 줍니다.

```js
String(p.커버)   →  "망고.jpg|망고.jpg"   (경로|표시이름)
p.커버.path      →  "망고.jpg"            ← 이걸 써야 합니다
```

문자열로 다루면 파이프가 남아 경로 해석이 **항상** 실패합니다. 예전에 이미지가 안 뜨고
클립 아이콘만 나오던 것, 작성자가 `Gemini|Gemini` 로 보이던 것이 다 이 때문이었습니다.
대시보드 안의 `linkPath()` · `textList()` 를 쓰세요.

**Dataview 의 `file` 에는 `basename` 이 없습니다.** 확장자 뺀 이름은 `p.file.name` 입니다.
없는 값은 오류 없이 빈 글자로 그려져서, 9/15 부터 핀보드 카드 제목이 전부 비어 있었습니다 (2026-09-22 고침).
