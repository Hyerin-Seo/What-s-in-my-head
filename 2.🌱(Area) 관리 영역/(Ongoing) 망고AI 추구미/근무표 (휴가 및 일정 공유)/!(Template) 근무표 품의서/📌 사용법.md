# 📌 근무표 품의서 쓰는 법

> [!tip] 3줄 요약
> `[품의서] 제목.md` 를 **복사** → `근무표 (휴가 및 일정 공유)` 폴더에 붙여넣기 → 파일명을 신청 내용으로 변경.
> **`시작일`·`종료일`을 `YYYY-MM-DD` 로** 채우면 달력에 바로 뜹니다.
> 대표가 승인하면 `승인 여부` 를 `승인 완료` 로 바꿉니다.

---

## 1. 복사하기

1. `[품의서] 제목.md` 를 복사
2. **`2.🌱(Area) 관리 영역 / 🥭 망고AI 추구미 / 근무표 (휴가 및 일정 공유)`** 폴더에 붙여넣기
3. 파일명을 신청 내용으로 변경 — 예: `부산 출장`, `휴가 신청`, `병가신청`
4. 속성 `이름` 에도 같은 이름 적기

> [!warning] `notion_db: 휴가` 는 지우지 마세요
> 이 값이 있어야 근무표 보드·달력에 올라옵니다. 양식에 미리 채워뒀습니다.

## 2. 속성 채우기

| 속성 | 쓰는 법 | 어디에 쓰이나 |
| --- | --- | --- |
| 이름 | 신청 내용. 파일명과 동일하게 | 카드·표 제목 |
| **근무 상태** | `휴가` `출장` `병가` `반차` | 표·카드 분류 |
| 기간 | 사람이 읽는 표기. 예: `2025년 11월 7일 → 2025년 11월 10일` | 표에 표시 |
| **시작일** | **`2025-11-07` 형식** | **🗓️ 달력** |
| **종료일** | 하루짜리면 **비워두기** | **🗓️ 달력** (여러 날이면 막대) |
| 승인 여부 | 비움 = 대기 / `승인 완료` / `반려` | ✅ 승인 여부별 |
| 직원 ID | 신청자 이름 | 👤 사람별 |
| 상위 자료 | `[[근무표 (휴가 및 일정 공유)]]` — 그대로 | 상위 노트로 이동 |
| notion_db | `휴가` — **고정** | 보드 필터 |

> [!danger] `기간` 만 적으면 달력에 안 뜹니다
> `기간` 은 사람이 읽는 글자일 뿐입니다. 달력은 **`시작일`·`종료일`** 만 읽습니다.
> 노션에서 넘어온 자료도 이래서 ISO 날짜를 따로 뽑아 넣었습니다.
>
> - 하루 : `시작일` 만 채우고 `종료일` 은 비움
> - 여러 날 : 둘 다 채우면 달력에 막대로 표시

## 3. 본문 쓰기

| 구역 | 무엇을 |
| --- | --- |
| `> [!abstract]` 신청 개요 | 종류·기간·일수·신청자 한눈에 |
| `## 📝 사유` | 왜 필요한지 |
| `## 🔁 인수인계` | 체크박스로 담당 업무·대행자 |
| `> [!question]-` 참고 사항 | 연락 가능 시간 등. 없으면 지워도 됨 |
| `> [!success]-` 대표 확인란 | 승인자가 확인일·의견 기록 |

## 4. 어디에 반영되나

`🏖️ 휴가.base` 에 저장 즉시 올라오고, **`근무표 (휴가 및 일정 공유)` 노트 안에도 그대로 보입니다.**

| 탭 | 보이는 것 |
| --- | --- |
| 🗓️ 달력 | 월간 달력. 드래그로 일정 이동 가능 |
| 🗓️ 일정순 | 시작일 빠른 순 |
| 👤 사람별 | 직원 ID 로 묶기 |
| ✅ 승인 여부별 | 대기 / 승인 완료 |
| 📋 전체 표 | 속성 전부 |

> [!info] 이 양식 파일은 보드에 안 뜹니다
> 파일명이 `[품의서] 제목` 이고 Template 폴더에 있어서 제외됩니다.
> 복사한 뒤 파일명을 바꾸는 순간부터 올라옵니다.
