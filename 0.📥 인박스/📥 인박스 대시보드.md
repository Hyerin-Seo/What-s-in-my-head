/** Link 객체·문자열·목록 무엇이 와도 링크 경로 문자열로 (여기가 전에 깨진 지점) */
function linkPath(v) {
  if (v == null) return "";
  if (Array.isArray(v)) return v.length ? linkPath(v[0]) : "";
  if (typeof v === "object") {
    if (v.path) return String(v.path);                       // Dataview Link
    if (typeof v.toString === "function") {
      const s = v.toString();
      return s.replace(/^!?\[\[/, "").replace(/\]\]$/, "").split("|")[0].trim();
    }
    return "";
  }
  return String(v).replace(/^!?\[\[/, "").replace(/\]\]$/, "").split("|")[0].trim();
}

/** 목록 속성을 사람이 읽는 문자열 배열로 */
function textList(v) {
  if (v == null) return [];
  const arr = Array.isArray(v) ? v : (v.values ? Array.from(v) : [v]);
  return arr.map((x) => {
    if (x == null) return "";
    if (typeof x === "object") {
      if (x.display) return String(x.display);
      if (x.path) return String(x.path).split("/").pop().replace(/\.md$/, "");
      return String(x).replace(/^!?\[\[/, "").replace(/\]\]$/, "").split("|")[0];
    }
    return String(x).replace(/^!?\[\[/, "").replace(/\]\]$/, "").split("|")[0];
  }).map((s) => s.trim()).filter(Boolean);
}

function plain(v) {
  if (v == null) return "";
  if (typeof v === "object") {
    if (v.display) return String(v.display);
    if (v.path) return String(v.path);
    return String(v);
  }
  return String(v);
}

function ymd(v) {
  if (!v) return "";
  const s = plain(v);
  const m = s.match(/(\d{4})-(\d{2})-(\d{2})/);
  return m ? m[0] : s.slice(0, 10);
}

const attCache = new Map();
function attachmentOf(p) {
  const key = p.file.path;
  if (attCache.has(key)) return attCache.get(key);
  const cache = app.metadataCache.getCache(key) || {};
  let found = null;
  // 임베드 먼저, 그 다음 링크 (xls·zip·hwp 는 `📎 [[링크]]` 로 걸려 있다)
  for (const group of [cache.embeds || [], cache.links || []]) {
    for (const ref of group) {
      const dest = app.metadataCache.getFirstLinkpathDest(
        String(ref.link).split("#")[0], key);
      if (dest && dest.extension && dest.extension.toLowerCase() !== "md") {
        found = dest;
        break;
      }
    }
    if (found) break;
  }
  // 본문에 링크가 없으면 `커버` 를 본다
  if (!found) {
    const c = linkPath(p.커버);
    if (c) {
      const dest = app.metadataCache.getFirstLinkpathDest(c.split("#")[0], key);
      if (dest && dest.extension.toLowerCase() !== "md") found = dest;
    }
  }
  attCache.set(key, found);
  return found;
}

function sizeText(n) {
  if (!(n > 0)) return "";
  if (n >= 1048576) return (n / 1048576).toFixed(1) + " MB";
  if (n >= 1024) return Math.round(n / 1024) + " KB";
  return n + " B";
}

function kindOf(p) {
  const att = attachmentOf(p);
  const ext = att ? att.extension.toLowerCase()
                  : (p.file.name.endsWith(".canvas") ? "canvas" : "");
  if (IMG.includes(ext) || MEDIA.includes(ext)) return "media";
  if (ext && ext !== "canvas") return "doc";
  return "memo";
}

  mk.createEl("span", { text: "✏️ 새 인박스" });

    const plugin = claudePlugin();
    if (!plugin || !plugin.openNewNoteModal) {
      notice("Claude 플러그인이 꺼져 있습니다.\n설정 → 커뮤니티 플러그인에서 켜세요.");
      return;
    }
    const folder = active.startsWith("f:") ? INBOX + "/" + active.slice(2) : null;
    plugin.openNewNoteModal(folder);
  };
}

/** Notice 가 dataviewjs 범위에 있다는 보장이 없습니다 */
function notice(msg, ms) {
  const N = (typeof Notice !== "undefined" && Notice)
    || (typeof obsidian !== "undefined" && obsidian.Notice)
    || (window.obsidian && window.obsidian.Notice);
  if (N) new N(msg, ms || 6000);
  else console.log("[인박스] " + msg);
}

/* ── 인박스에서 내보내기 ───────────────────────────────────
   카드에서 구역만 고르면 `Claude` 플러그인의 **PARA 구역 정리** 가 보내기 창을 띄웁니다.
   그 창이 나머지(유형·상태·분류·마감)를 묻고, 속성을 쓰고, 파일을 옮깁니다. 구역 표도
   그 플러그인 것을 그대로 씁니다 — 같은 표를 두 군데 적으면 반드시 어긋납니다. */

/** 이 볼트의 살림 플러그인.
    예전에는 para-mover · inbox-auto · cover-auto · canvas-open-right 넷이었습니다. */
function claudePlugin() {
  return app.plugins.plugins["gaeddong-claude"] || null;
}

let openMenu = null, awayHandler = null, keyHandler = null;
function closeMenu() {
  if (awayHandler) { document.removeEventListener("click", awayHandler, true); awayHandler = null; }
  if (keyHandler) { document.removeEventListener("keydown", keyHandler, true); keyHandler = null; }
  if (openMenu) { openMenu.remove(); openMenu = null; }
}

function sendMenu(btn, onPick) {
  const pm = claudePlugin();
  if (!pm || !pm.openSendModal) {
    notice("Claude 플러그인이 꺼져 있습니다.\n설정 → 커뮤니티 플러그인에서 켜세요.");
    return;
  }
  closeMenu();
  const menu = document.body.createEl("div", { cls: "ib-menu" });
  menu.createEl("div", { cls: "ib-menu-head", text: "어디로 보낼까요" });
  for (const z of (pm.zones || [])) {
    if (z.key === "0.inbox") continue;
    const it = menu.createEl("div", { cls: "ib-menu-item" });
    it.createEl("span", { cls: "ic", text: z.icon || "📁" });
    const tx = it.createEl("div");
    tx.createEl("div", { cls: "t", text: z.label });
    tx.createEl("div", { cls: "d", text: z.hint || "" });
    it.onclick = (e) => { e.stopPropagation(); closeMenu(); onPick(z.key); };
  }

  // 자리 잡기 — 버튼 오른쪽에 맞추고, 아래로 넘치면 위로 띄웁니다
  const r = btn.getBoundingClientRect();
  const h = menu.offsetHeight, w = menu.offsetWidth;
  const down = r.bottom + 6 + h < window.innerHeight;
  menu.style.top = Math.max(8, down ? r.bottom + 6 : r.top - 6 - h) + "px";
  menu.style.left = Math.max(8, Math.min(r.right - w, window.innerWidth - w - 8)) + "px";
  openMenu = menu;

  // 이 클릭이 끝난 다음부터 바깥 클릭을 듣습니다 (안 그러면 열자마자 닫힙니다)
  setTimeout(() => {
    awayHandler = (e) => { if (!menu.contains(e.target)) closeMenu(); };
    keyHandler = (e) => { if (e.key === "Escape") closeMenu(); };
    document.addEventListener("click", awayHandler, true);
    document.addEventListener("keydown", keyHandler, true);
  }, 0);
}

/* ── 일괄 보내기 ─────────────────────────────────────────────
   `☑ 일괄 보내기` 를 누르면 고르기 모드 — 카드를 누르면 열리는 대신 체크됩니다.
   위 줄의 `📤 PARA로 보내기 ▾` 로 구역을 고르면 Claude 플러그인의 **일괄 보내기 창**이
   구역·분류·마감은 한 번에, 유형은 각자 그대로(구역에 없는 유형만 고름) 묻고 차례로 보냅니다.
   (2026-09-17 개발 요청 — `[개발 요청] Inbox - 일괄 PARA 보내기 기능`) */
function drawSelBar(list) {
  selBar.empty();
  selBar.style.display = selecting ? "" : "none";
  if (!selecting) return;
  selBar.createEl("span", { cls: "cnt", text: picked.size ? picked.size + "개 고름" : "카드를 눌러 고르세요" });

  const ps = (list || []).map((p) => p.file.path);
  const every = ps.length > 0 && ps.every((x) => picked.has(x));
  const all = selBar.createEl("div", { cls: "ib-btn", text: every ? "이 칸 선택 풀기" : "이 칸 전체 선택" });
  all.onclick = () => {
    for (const x of ps) { if (every) picked.delete(x); else picked.add(x); }
    drawGrid();
  };

  const go = selBar.createEl("div", { cls: "ib-btn" + (picked.size ? "" : " is-off"), text: "📤 PARA로 보내기 ▾" });
  go.onclick = (e) => {
    e.stopPropagation();
    if (!picked.size) return;
    sendMenu(go, (zoneKey) => {
      const pm = claudePlugin();
      if (!pm.openBatchSendModal) {
        notice("Claude 플러그인이 옛 코드입니다. 옵시디언을 다시 켜세요.");
        return;
      }
      const files = [...picked].map((x) => app.vault.getAbstractFileByPath(x)).filter(Boolean);
      const modal = pm.openBatchSendModal(files, zoneKey);
      if (!modal) return;
      // 한 장이면 원래 보내기 창이 열리고 onSent(파일) 로, 여러 장이면 onSent(보낸 목록) 으로 옵니다
      modal.onSent = (sent) => {
        const done = new Set((Array.isArray(sent) ? sent : [sent]).filter(Boolean).map((f) => f.path));
        pages = pages.filter((x) => !done.has(x.file.path));
        picked.clear();
        selecting = false;
        drawTabs();
        drawGrid();
      };
    });
  };

  const cancel = selBar.createEl("div", { cls: "ib-btn", text: "취소" });
  cancel.onclick = () => { selecting = false; picked.clear(); drawTabs(); drawGrid(); };
}

async function drawGrid() {
  grid.empty();
  const tab = tabs.find((t) => t.id === active) || tabs[0];
  const list = pages.filter(tab.test)
    .sort((a, b) => {
      const av = ymd(a.작성일) || "", bv = ymd(b.작성일) || "";
      if (av !== bv) return av < bv ? 1 : -1;
      return b.file.ctime - a.file.ctime;
    });
  drawSelBar(list);

  if (!list.length) {
    grid.createEl("div", { cls: "ib-empty", text: "이 칸에는 아무것도 없습니다." });
    return;
  }

  for (const p of list) {
    const card = grid.createEl("div", { cls: "ib-card" });
    let check = null;
    if (selecting) {
      card.addClass("is-picking");
      if (picked.has(p.file.path)) card.addClass("is-picked");
      check = card.createEl("div", { cls: "ib-check", text: picked.has(p.file.path) ? "✓" : "" });
    }
    const att = attachmentOf(p);
    const ext = att ? att.extension.toLowerCase()
                    : (p.file.name.endsWith(".canvas") ? "canvas" : "");

    card.onclick = () => {
      if (!selecting) return app.workspace.openLinkText(p.file.path, "");
      // 고르는 중엔 열지 않고 체크만 — 판 전체를 다시 그리면 그림이 깜빡여서 이 카드만 바꿉니다
      const on = !picked.has(p.file.path);
      if (on) picked.add(p.file.path); else picked.delete(p.file.path);
      card.toggleClass("is-picked", on);
      if (check) check.setText(on ? "✓" : "");
      drawSelBar(list);
    };
    card.addEventListener("contextmenu", (e) => {
      const tf = app.vault.getAbstractFileByPath(p.file.path);
      // dataviewjs 범위에 `obsidian` 모듈이 있다는 보장이 없다. 없으면 우클릭 메뉴만
      // 포기하고 카드 클릭은 그대로 동작하게 둔다.
      const MenuClass = (typeof obsidian !== "undefined" && obsidian.Menu)
        || (window.obsidian && window.obsidian.Menu);
      if (!tf || !MenuClass) return;
      e.preventDefault();
      const menu = new MenuClass();
      menu.addItem((i) => i.setTitle("↗ 오른쪽에 열기").setIcon("separator-vertical")
        .onClick(() => app.workspace.getLeaf("split", "vertical").openFile(tf)));
      menu.addItem((i) => i.setTitle("🪟 새 창에서 열기").setIcon("popout")
        .onClick(() => app.workspace.openPopoutLeaf().openFile(tf)));
      if (att) {
        menu.addItem((i) => i.setTitle("📎 첨부 파일 열기").setIcon("paperclip")
          .onClick(() => app.workspace.openLinkText(att.path, "")));
      }
      menu.addSeparator();
      app.workspace.trigger("file-menu", menu, tf, "file-explorer");
      menu.showAtMouseEvent(e);
    });

    /* 커버 */
    const cover = card.createEl("div", { cls: "ib-cover" });
    if (att && IMG.includes(ext)) {
      cover.createEl("img", { attr: { src: app.vault.getResourcePath(att), alt: p.file.name } });
    } else if (ext === "canvas") {
      const box = cover.createEl("div", { cls: "ib-canvas" });
      box.createEl("div", { cls: "h", text: "🎨 CANVAS" });
      const cf = att || app.vault.getAbstractFileByPath(
        p.file.folder + "/" + p.file.name + ".canvas");
      let drawn = false;
      if (cf) {
        try {
          const nodes = (JSON.parse(await app.vault.read(cf)).nodes || [])
            .filter((n) => n.text || n.file).slice(0, 3);
          for (const n of nodes) {
            box.createEl("div", { cls: "ib-node",
              text: n.text ? String(n.text).slice(0, 44) : "📎 " + n.file });
            drawn = true;
          }
        } catch (e) { /* 캔버스를 못 읽으면 아래 안내로 */ }
      }
      if (!drawn) box.createEl("div", { cls: "ib-node", text: "빈 캔버스" });
    } else if (att && MEDIA.includes(ext)) {
      banner(cover, "ib-b-media", "🎬", ext.toUpperCase(), att);
    } else if (att && BANNER[ext]) {
      banner(cover, BANNER[ext][0], BANNER[ext][1], BANNER[ext][2], att);
    } else if (att) {
      banner(cover, "ib-b-etc", "📎", ext.toUpperCase(), att);
    } else {
      // 첨부가 없는 순수 메모 — 본문을 미리 보여준다
      const memo = cover.createEl("div", { cls: "ib-memo", text: "…" });
      const nf = app.vault.getAbstractFileByPath(p.file.path);
      if (nf) {
        const raw = await app.vault.read(nf);
        const body = raw.replace(/^---[\s\S]*?\n---\s*/, "")
                        .replace(/^#+ .*$/gm, "")
                        .replace(/^>.*$/gm, "")
                        .trim();
        memo.setText(body ? body.slice(0, 320) : "(본문이 비어 있습니다)");
      }
    }

    /* 본문 */
    const body = card.createEl("div", { cls: "ib-body" });
    const top = body.createEl("div", { cls: "ib-top" });
    top.createEl("div", { cls: "ib-title", text: p.file.name });

    const sum = plain(p.요약).trim();
    if (sum) body.createEl("div", { cls: "ib-sum", text: sum });

    const chips = body.createEl("div", { cls: "ib-chips" });
    // 인박스에 있다는 것 자체가 "아직 안 본 것" 입니다. 그래서 미처리는 빨간 표시로
    // 두고, 그 밖의 상태(진행중 같은 것)는 있는 그대로 보여줍니다.
    const st = plain(p.상태).trim();
    chips.createEl("span", { cls: "ib-chip " + (!st || st === "미처리" ? "st-todo" : ""),
      text: st || "미처리" });
    const kind = plain(p.유형).trim();
    if (kind) chips.createEl("span", { cls: "ib-chip", text: kind });
    for (const c of textList(p.분류)) chips.createEl("span", { cls: "ib-chip", text: c });
    for (const t of textList(p.주제).slice(0, 4))
      chips.createEl("span", { cls: "ib-chip", text: "#" + t });
    for (const w of textList(p.작성자))
      chips.createEl("span", { cls: "ib-chip who", text: "✍ " + w });

    const foot = body.createEl("div", { cls: "ib-foot" });
    const meta = [ymd(p.작성일), att ? sizeText(att.stat && att.stat.size) : ""]
      .filter(Boolean).join("  ·  ");
    foot.createEl("span", { cls: "ib-date", text: meta });

    // 인박스의 유일한 출구. 구역을 고르면 보내기 창이 나머지를 묻고 파일을 옮깁니다.
    const btn = foot.createEl("div", { cls: "ib-btn", text: "📤 PARA로 보내기 ▾" });
    btn.onclick = (e) => {
      e.stopPropagation();
      sendMenu(btn, (zoneKey) => {
        const tf = app.vault.getAbstractFileByPath(p.file.path);
        const modal = claudePlugin().openSendModal(tf, zoneKey);
        if (!modal) return;
        // 보내고 나면 이 카드는 인박스 것이 아닙니다 — 바로 치웁니다.
        // (Dataview 가 다시 훑기를 기다리면 몇 초 동안 유령 카드가 남습니다)
        modal.onSent = () => {
          pages = pages.filter((x) => x.file.path !== p.file.path);
          drawTabs();
          drawGrid();
        };
      });
    };
  }
}

function banner(parent, cls, ico, kind, att) {
  const b = parent.createEl("div", { cls: "ib-banner " + cls });
  b.createEl("div", { cls: "ico", text: ico });
  b.createEl("div", { cls: "kind", text: kind });
  const s = att ? sizeText(att.stat && att.stat.size) : "";
  if (s) b.createEl("div", { cls: "size", text: s });
}
