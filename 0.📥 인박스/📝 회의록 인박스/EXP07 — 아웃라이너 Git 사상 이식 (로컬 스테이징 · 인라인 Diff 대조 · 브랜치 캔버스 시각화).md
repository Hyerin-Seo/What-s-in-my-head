### EXP07 — 아웃라이너 Git 사상 이식 (로컬 스테이징 · 인라인 Diff 대조 · 브랜치 캔버스 시각화)

**아웃라이너로 문서 목차와 구조를 설계할 때**, 갈아엎고 되돌아가는 작업의 불안감을 없애기 위해 **노드 단위 로컬 스테이징, 초록/빨강 인라인 Diff 대조, 2차원 캔버스 브랜칭**을 결합하여 안심하고 구조를 파괴·실험·복구할 수 있도록 지원하는 핵심 인터랙션 기능

> [!check] 3초 요약 (What)
> - **노드 단위 로컬 스테이징**: 전체 문서를 무겁게 롤백할 필요 없이, 작업자가 집중하는 특정 노드/섹션 단위로 수정 전 상태를 임시 커밋/스테이징하여 안전망 확보
> - **초록/빨강 인라인 Diff 가시화**: 무엇이 추가되고 빠졌는지 눈으로 즉시 대조(`+` 녹색 추가 / `-` 붉은색 삭제), 전후 비교 인지 비용 제로화
> - **캔버스 브랜치 시각화 & 비파괴 복귀**: 대안 목차 및 갈래를 2차원 캔버스 브랜치로 펼쳐 조망하고, 마음에 드는 버전을 메인 트리에 안전하게 병합·체크아웃

### EXP08 — 노드 픽스(인용 잠금) 및 영역 지정 다중 버전 생성

**확정된 기준 노드가 AI 재생성으로 흔들리는 것을 방지할 때**, 노드에 **핀/픽스(인용 블록화)를 걸어 변경 불가 앵커로 잠그고**, 미확정 구간만 **영역 지정하여 3개 대안(v1, v2, v3)을 인라인으로 병렬 생성·대조**하는 부분 발산 인터랙션 기능

> [!check] 3초 요약 (What)
> - **노드 픽스(Pin) & 인용 스타일 잠금**: 확정된 노드를 인용문 블록 스타일로 잠그고 AI 변경 대상에서 원천 제외 (`Ctrl + L`)
> - **범위 영역 지정 (Range Selection)**: 확정 노드 사이의 미완성 구간만 드래그/선택하여 3개 대안 병렬 생성 트리거
> - **인라인 멀티 버전 탭 & 즉시 픽스**: `[v1][v2][v3]` 탭 단축키로 비교 후 원클릭으로 정식 채택 및 다음 기준점으로 픽스

### EXP11 — 코드 편집기 스타일 아웃라인 인라인 Diff 대조 및 부분 승인

**AI가 수정한 아웃라인의 변경점을 대조하고 채택할 때**, 전체를 다시 읽는 독해 피로를 없애기 위해 **초록/빨강 인라인 Diff로 가시화**하고 노드별 **`[✓ Accept]` / `[✗ Reject]`로 원하는 부분만 선별 승인**하는 인터랙션 기능

> [!check] 3초 요약 (What)
> - **노드 인라인 Diff 오버레이**: 삭제 문구(붉은 취소선)와 추가 문구(녹색 하이라이트)를 원본 노드에 겹쳐 표시하여 대조 비용 제로화
> - **노드 단위 부분 승인 (Cherry-pick)**: `Tab`(승인) / `Esc`(거절) 또는 인라인 액션 버튼으로 원하는 노드만 골라 채택
> - **미니 히스토리 서랍 롤백**: 수락 후에도 우측 미니 서랍에서 이전 스냅샷을 열어 언제든 단일 노드 롤백 가능
