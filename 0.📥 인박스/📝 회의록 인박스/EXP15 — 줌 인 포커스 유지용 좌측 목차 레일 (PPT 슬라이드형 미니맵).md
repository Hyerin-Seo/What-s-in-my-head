### EXP15 — 줌 인 포커스 유지용 좌측 목차 레일 (PPT 슬라이드형 미니맵)

**아웃라이너로 복잡한 문서를 작성할 때**, 특정 노드로 깊이 줌 인하더라도 전체 문서의 위치 감각(컨텍스트)을 잃지 않도록 **좌측 사이드 패널에 PPT 슬라이드 목록처럼 1·2·3·4 상위 목차 트리를 상시 노출**하고, 원클릭으로 다른 섹션으로 다이렉트 점프(Hop)하는 내비게이션 인터랙션 기능

> [!check] 3초 요약 (What)
> - **좌측 초경량 아웃라인 레일**: 화면 좌측에 180~220px 폭의 얇은 접이식 사이드바(`Ctrl + \`)로 1·2레벨 상위 헤딩 노드만 상시 조망
> - **원클릭 무지연 줌 점프 (Instant Zoom Hop)**: 줌 아웃 ➔ 스크롤 ➔ 줌 인의 번거로운 3단계 왕복 없이, 레일의 목차 클릭 한 번으로 메인 뷰가 해당 노드의 줌 인 화면으로 즉각 전환 (속기: "줌을 했어도 옆에 PPT처럼 1, 2, 3, 4 바로 갈 수 있게" 구현)
> - **작성 진행 상태 미니 뱃지**: 각 목차 아이템 우측에 하위 노드 수, 체크 완료 여부, 핀 픽스(`📌`) 상태를 시각화하여 전체 문서의 진척도를 한눈에 파악
