### EXP01 — 아웃라이너 문서 뼈대 설계용 '줌 안 버전 탭' (무지연 전후 대조)

**아웃라이너로 복잡한 문서의 목차/골격을 짤 때**, 특정 섹션 노드로 줌 인하여 **하위 목차 대안들(1안·2안)을 탭으로 생성·전환·비교**한 뒤 최적의 구조를 전체 문서에 확정 반영하는 초경량 인터랙션 기능

> [!check] 3초 요약 (What)
> - **[+] 목차 대안 분기**: **문서의 특정 섹션(노드)을 기획할 때**, 현재 뼈대를 `v1`으로 얼려두고 새 판(`v2`)을 따서 과감하게 하위 목차를 갈아엎음
> - **단축키 무지연 스위칭**: 화면을 반반 쪼개 비교하는 노가다 없이, `Alt + 1, 2`로 같은 자리에서 **'목차 1안 vs 2안'의 구조 차이를 눈 깜빡이듯 대조**
> - **최적 목차 1개 채택**: 비교 후 가장 잘 짜인 대안만 **전체 문서 트리에 공식 목차로 반영**하고 줌 아웃 (버려진 대안은 해당 노드 안에 보관)
