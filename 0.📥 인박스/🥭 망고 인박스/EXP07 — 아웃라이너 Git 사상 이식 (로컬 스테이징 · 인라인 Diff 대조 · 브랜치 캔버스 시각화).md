### EXP07 — 아웃라이너 Git 사상 이식 (로컬 스테이징 · 인라인 Diff 대조 · 브랜치 캔버스 시각화)

**아웃라이너로 문서 목차와 구조를 설계할 때**, 갈아엎고 되돌아가는 작업의 불안감을 없애기 위해 **노드 단위 로컬 스테이징, 초록/빨강 인라인 Diff 대조, 2차원 캔버스 브랜칭**을 결합하여 안심하고 구조를 파괴·실험·복구할 수 있도록 지원하는 핵심 인터랙션 기능

> [!check] 3초 요약 (What)
> - **노드 단위 로컬 스테이징**: 전체 문서를 무겁게 롤백할 필요 없이, 작업자가 집중하는 특정 노드/섹션 단위로 수정 전 상태를 임시 커밋/스테이징하여 안전망 확보
> - **초록/빨강 인라인 Diff 가시화**: 무엇이 추가되고 빠졌는지 눈으로 즉시 대조(`+` 녹색 추가 / `-` 붉은색 삭제), 전후 비교 인지 비용 제로화
> - **캔버스 브랜치 시각화 & 비파괴 복귀**: 대안 목차 및 갈래를 2차원 캔버스 브랜치로 펼쳐 조망하고, 마음에 드는 버전을 메인 트리에 안전하게 병합·체크아웃
