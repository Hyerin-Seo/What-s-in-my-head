# .outline 아웃라인 파일 규격 및 생성 규칙

이 볼트의 커스텀 플러그인 `gaeddong-outliner`는 `.outline` JSON 파일을 읽을 때 엄격한 Zod 스키마 검증을 거칩니다.

## 1. 최상위(Root) 필수 타임스탬프 (누락 시 "아웃라인 파일 규격이 아니라서 열 수 없습니다" 에러 발생)
루트 JSON 객체에 반드시 다음 필드가 포함되어야 합니다:
```json
{
  "version": "1.0.0",
  "id": "12자리_문자열",
  "title": "제목",
  "rootNodes": [],
  "defaultView": "bullets",
  "createdAt": 1792390589158,
  "updatedAt": 1792390589158
}
```
- `createdAt` (밀리초 정수): 필수!
- `updatedAt` (밀리초 정수): 필수!
- `version`: 반드시 `"1.0.0"` 고정.

## 2. 노드 객체 규격
각 노드는 다음 구조를 지켜야 합니다:
```json
{
  "id": "12자리_문자열",
  "text": "노드 본문",
  "children": [],
  "isFolded": false,
  "nodeType": "bullet",
  "createdAt": 1792390589158,
  "updatedAt": 1792390589158
}
```
- 허용되는 `nodeType`: `"bullet"`, `"h1"`, `"h2"`, `"h3"`, `"todo"`, `"code"`, `"quote"`, `"paragraph"`, `"divider"`
- `children`: 하위 자식이 없어도 반드시 `[]` 빈 배열로 존재해야 함.

## 4. 파일명 및 노트 제목에 대괄호 `[]` 사용 절대 금지 ⭐⭐
- 옵시디언의 위키링크는 `[[파일명]]` 형식을 씁니다. 파일명에 대괄호(`[...]`)가 들어가면 `[[[파일명]]]` 형태로 3중 중첩되어 링크 파서가 깨집니다.
- 특히 `gaeddong-outliner`의 링크 감지 정규식(`/\[\[[^[\]\n]+\]\]/`)이 `[`와 `]`를 제외하므로, 링크 감지에 실패하여 **마크다운 렌더링이 중단되고 보라색 칩 및 바로가기 링크가 일체 뜨지 않습니다**.
- **철칙: 파일명이나 아웃라인 제목의 말머리·묶음 표기는 무조건 소괄호 `()`를 사용합니다.** (예: `(PM 보고서) ...`, `(통합 원심분리기) ...`)
