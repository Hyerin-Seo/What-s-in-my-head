# 1.1 "문서 작업의 Cursor" — Cursor 에서 무엇을 가져오나

> **속기 원문** (속기 47–54 · 80–96 · 163–171 · 176–178 · 285–306)
> - Rin (13:36) *커서에 어떤 기능을 우리한테 넣고 싶다면 왜 커서요?*
> - Rin (13:56) *이미 이런 거는 많이 있잖아. 많이 있고 그게 또 커서의 장점을 가져온 건 아닌 거 같고.*
> - Rin (20:22) *지금 커서의 핵심 기능이나 그런 핵심 아이디어들은 어디서 어떻게 가져왔는지 모르겠어서 물어보는 거예요.*
> - 민규 서 (21:53) *이 구조를 알 아는 상태의 에이전트한테 질문을 한다는 것과 이 구조를 모르는 에이전트한테 질문하는 거는 진짜 천재적인*
> - 민규 서 (38:21) *에이전트랑 같이 일을 하는 작업 방식에 대해서 커서가 제일 처음 제시를 했기 때문에 그냥 커서로 그냥 얘기를 하는 겁니다.*
> - 민규 서 (39:41) *이 VIBE 코딩 안에서만 느껴졌던 이 에이전트의 카타르시스를 맞아. 문서 작업에서도 느껴봐라.*
> - 민규 서 (01:02:21) *안티그래피 다 커서 같은 경우에는 라이트를 하거든요. 그게 중요하거든.*
> - Rin (01:03:09) *아 이거 뭐 에이전트 써서 좋은데 읽을 게 더 많아져서*
> - 민규 서 (01:03:59) *이게 내가 하려고 했던 핵심 컨셉이었어. 너처럼 이익 나와 있는 이 말 솔직히 읽을 필요가 없어.*

## 📌 기존엔 왜 이렇게 관리했을까? (현행 사양의 이유)

* **1. 이름 하나로 전달하는 지름길**
  * 에이전트와 같이 일하는 방식을 처음 보여 준 도구라, "Cursor 처럼" 한마디로 방향을 전할 수 있었습니다 (속기 38:21).
* **2. v2 의 해법이 Cursor 기능에 1:1 로 맞춰져 있음**
  * `@Docs` → @Reference 딥리딩, Composer → Document Composer, 컴파일러 에러 → 1:1 앵커 ([[망고독 Outcome 01·린 캔버스 — 이해한 것과 민규 서에게 물어볼 것|회의 준비 노트]] 1-2).
* **3. 민규 서 가 직접 겪은 경험에서 나옴**
  * Antigravity 로 목업을 이틀 만에 만들고, 구조를 아는 에이전트의 힘을 직접 느꼈습니다 (속기 21:53 · 56:13).

## 📌 핵심 분석

* **같은 이름, 다른 Cursor:**
  * Rin 은 Tab 자동완성(다음 코드를 미리 보여 줌)을 떠올렸고, 민규 서 는 구조 파악 + 직접 쓰기 + 에이전트와 같이 일하는 경험을 말했습니다 (속기 20:03 · 21:53 · 38:21). 회의 내내 서로 다른 것을 가리켰습니다.
* **"이미 많이 있다" 에 대한 답이 아직 한 줄이 아님:**
  * 코드는 `package.json` 처럼 세계 공통 규칙이 있어 구조를 읽기 쉽지만 문서는 사람마다 다르다는 반론(속기 22:17 · 22:49)에, 민규 서 는 "레퍼런스 + 기준 문서 두 개면 공통 규칙을 뽑을 수 있다" 로 답했습니다 (23:12). 이 답이 차별점이 될지는 합의 전입니다.
  * 발췌 + 출처는 Hebbia · Elicit 에서 이미 표준 기능입니다 ([[망고독 Outcome 01·린 캔버스 — 이해한 것과 민규 서에게 물어볼 것|회의 준비 노트]] 1-6).

## 🌐 참조 자료 및 모범 사례 (다른 곳은 어떻게 하는가?)

* **1. Cursor 가 걸어온 길 — 자동완성 → 코드베이스 인덱싱 → 에이전트**
  * Tab 자동완성으로 시작해, 코드베이스 전체를 인덱싱하고, 에이전트가 여러 파일을 고치면 사람은 바뀐 곳(diff)을 받아들일지 버릴지만 정합니다. 두 사람이 말한 Cursor 가 이 길의 서로 다른 칸입니다.
* **2. NotebookLM — 자료 기반 답과 인용, 쓰기는 사람**
  * 민규 서 가 속기 01:02:09 에서 가른 "리드만 한다" 쪽입니다. 올린 자료에서 답과 출처를 주지만 최종 문서는 사람이 씁니다.
* **3. Hebbia Matrix · Elicit — 발췌와 출처는 이미 표준**
  * 둘 다 문장 단위 출처를 내세웁니다. "출처를 단다" 만으로는 차별점이 못 되고, 차별은 다른 곳에서 찾아야 합니다 ([[망고독 Outcome 01·린 캔버스 — 이해한 것과 민규 서에게 물어볼 것|회의 준비 노트]] 1-6).
