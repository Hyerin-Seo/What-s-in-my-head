## 💬 왜

- 와꾸가 잡힌 사람은 "이대로 써 줘" 지시만 하면 되니 Claude · GPT 가 편하다 (01:59–03:16)
- Skywork · Genspark · Claude · GPT 가 주는 문서 작업의 가치는 "대신 타이핑해 줄게" 다 (11:46)
- 버전을 여러 개 두고 이 버전의 이 부분 · 저 버전의 저 부분을 섞는 **작업 공간 관리 UI · 프로세스**는 그 도구들이 지원하지 않는다고 봄 (20:38–21:29)
- Claude 로도 할 수 있지만, 레퍼런스로 빈칸 와이어프레임을 띄워 놓고 바로바로 바꿔 나가는 게 10배는 편하다 (24:57–25:32)
- Claude + 옵시디언 + VS Code 로 직접 판을 까는 건 에이전트를 아주 잘 아는 사람만 한다 (29:28–30:31)

## 🚧 어디까지

- **한다:** "뭘 해야 되지? 무슨 내용 써야 되지?" 부터 시작하는 문서 작업 (07:08–07:23) — 기준 문서 안에서 일부 항목의 와꾸가 안 나오는 것도 포함 (32:02–32:50)
- **안 한다:** 와꾸가 이미 잡혀 지시만 하면 되는 작업 — "이 도구를 안 써도 되는 사람" (01:42–02:25)
