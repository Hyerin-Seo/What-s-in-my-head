# 회의 AI 정리 — 샌드박스에서 쓰고, 사람이 꺼낸다

에이전트가 읽는 설명서입니다.

## 0. 왜 이렇게 하나

**AI 가 쓴 것은 그대로 볼트에 반영할 수 없습니다.** 사람이 보고 고른 것만 들어갑니다. 그래서 에이전트는 99 작업 공간(샌드박스)에만 씁니다.
참고한 것 (2026-09-23 조사):

| 참고 | 가져온 것 |
| --- | --- |
| **Notion AI Meeting Notes** — Notes · Transcript · Summary 탭 | 사람의 노트와 AI 요약을 **따로 둔다**. 요약 줄마다 녹취 인용. action item 은 목록일 뿐 **자동으로 태스크가 되지 않는다**. custom instructions · Retry summary |
| **Mem** — Heads Up · Agent | 회의 전에 **지난 결정 · 이전 회의를 모아 띄운다**. 후속 조치는 에이전트가 챙기되 만드는 건 사람 |

| Notion / Mem | 이 볼트 |
| --- | --- |
| Notes · Transcript 탭 | 회의록 (`4.🗄️(Archive) 보관/회의록/`) — **사람만 씀** |
| Summary 탭 | `99.🥸(Agent) 작업 공간/<회의>/A5.outputs/<회의록 이름> — AI 정리.md` 한 장 |
| 녹취 인용 | 줄 끝 `(1.2)` — 속기 번호 (작업 기억 분류표) |
| custom instructions · Retry | 이 스킬 · "다시 정리해줘" |
| 태스크는 사람이 만든다 | 할 일 줄 체크 → "만들어줘" → 체크한 줄만 할일 노트 |
| Heads Up | 다음 회의 전 사전 준비 (A2) — paused 안건 카드 · 확인 필요 · 나중에 할 일 |
| Collections | 회의 폴더 하나 = 회의 하나 |

## 1. 샌드박스

- **99 폴더 전체가 옵시디언 "제외된 파일"** 입니다 (`.obsidian/app.json` 의 `userIgnoreFilters`). 보드 · 검색 · 그래프에 안 뜹니다.
- 플러그인 **PARA 구역 정리 · 커버** 도 99 를 건너뜁니다 (`plugins/claude/data.json` 의 `para.exclude` · `cover.exclude`).
- 그래서 99 안의 노트는 속성이 무엇이든 볼트에 새지 않습니다. 예전처럼 속성으로 누수를 막을 필요가 없습니다.
- **에이전트는 99 밖에 쓰지 않습니다.** 예외는 사람이 한 줄씩 시킨 것뿐입니다 — "만들어줘"(할일 노트) · "반영해줘"(회의록 `결정` 칸에 그 줄).
- 칸반은 쓰지 않습니다 — 베이스는 제외된 파일을 안 읽습니다. 고르는 곳은 AI 정리의 체크박스 하나입니다.

```
99.🥸(Agent) 작업 공간/<회의 이름>/
  A1.collection/검토 중/   ← 깊게 볼 안건 카드 (필요할 때만)
  A1.collection/paused/    ← 이번엔 못 정한 안건 카드 → 다음 회의 사전 준비 재료
  A1.collection/history/   ← 옛 버전 · 안 쓰는 것
  A2.scratch(ideation)/    ← 다음 회의 사전 준비
  A3.working memory/       ← 작업 기억 한 장 (분류표 · 진행)
  A4.meta/                 ← 이 스킬
  A5.outputs/              ← AI 정리 한 장 (Summary 탭)
```

## 2. 순서

| 단계 | 누가 | 무엇 |
| --- | --- | --- |
| ① 속기 | 사람 | 회의록 `## 속기`. 할 일이면 줄 앞에 `→` |
| ② 분류 | 에이전트 | 속기를 한 줄도 빼지 않고 번호 → 작업 기억 분류표 (3절) |
| ③ AI 정리 | 에이전트 | A5 에 한 장 (4절). **여기서 멈추고 보고** |
| ④ 고르기 | **사람** | AI 정리를 읽고 할 일 줄 체크 · 결정 줄 확인 |
| ⑤ 꺼내기 | 사람이 시키면 에이전트 | "만들어줘" → 체크한 할 일만 할일 노트 (5절). "반영해줘" → 그 결정 줄만 회의록 `## 결정` |
| ⑥ 다음 회의 전 | 에이전트 | "다음 회의 준비해줘" → A2 에 사전 준비 (6절) |

## 3. 분류 — 줄마다 어디로

속기를 번호 매겨 작업 기억 분류표에 옮깁니다. 빈 줄도 "빈 줄" 로 적습니다. `### 1.` 같은 제목이 있으면 그 번호를 앞자리로.

| 무엇 | 알아보는 법 | AI 정리의 칸 |
| --- | --- | --- |
| 결정 | "~하기로" 처럼 **합의**가 드러남 | `결정` |
| 확인 필요 | 한 사람이 답을 냈지만 합의는 안 보임 ("~할 거임", "~하셈", 자기 질문에 자기 답) | `확인 필요` — 볼트 규칙과 부딪히면 **안건 카드**도 (A1/검토 중) |
| 열린 질문 | 답이 없는 결정 질문 | `확인 필요` + 안건 카드 |
| 할 일 | 손을 움직이면 되는 일 · 조사해야 결정할 수 있는 일 · `→` 줄 | `할 일` 체크리스트 |
| 보류 · 아이디어 | "다음에", "갔다 와서", 당장 안 급한 것 | `다음 안건` |
| 공유 | 듣고 알면 끝 | `자료` |

- **답이 곧 실행이면 할 일도 됩니다.** "~만들어서", "~보낼거임" 은 확인 필요이면서 할 일입니다 (2026-09-23: 1번 섹션에서 할 일이 0개였음).
- **회의의 큰 안건(속기 제목)이 지금 누가 하고 있는 일이면 그것도 할 일**입니다.
- 한 줄에 둘이 섞이면 둘 다 적습니다. 같은 결정을 묻는 줄은 하나로 합칩니다.

## 4. AI 정리 한 장

양식 `./templates/!(Template) AI 정리.md`. 칸 순서: 요약 → 결정 → 확인 필요 → 할 일 → 다음 안건 → 자료.

- **줄마다 끝에 속기 번호** `(1.2)` — 사람이 원문을 바로 대조할 수 있게.
- 할 일은 `- [ ] 동사로 끝나는 한 줄 — 담당 <이름> · 마감 <날짜> · 프로젝트 <폴더> (번호)`. 모르는 칸은 적지 않습니다. 날짜 규칙은 `skills/meeting-notes`.
- **체크는 비워 둡니다.** 사람이 넣습니다.
- 안건 카드는 결정이 무겁거나 볼트 규칙과 부딪힐 때만 만듭니다 (`./templates/!(Template) 안건 카드.md`, 7단 구조). 모든 줄을 카드로 만들지 않습니다.
- "다시 정리해줘" 면 같은 파일을 새로 씁니다. 사람이 넣은 체크는 **같은 뜻의 줄에 그대로 옮깁니다.**

## 5. 꺼내기 — 사람이 시킨 것만

### "만들어줘" — 체크한 할 일 → 할일 노트

`skills/meeting-notes` 의 **배포** 규칙을 그대로 씁니다 (가는 곳 · 파일 이름 · 같은 게 있나 · 속성 · 본문).
다른 점은 입력이 회의록 표가 아니라 AI 정리의 체크된 줄이라는 것 하나입니다.

- 프로젝트가 적혀 있고 폴더와 맞으면 그 프로젝트에 `to do`, 아니면 `0.📥 인박스/📝 회의록 인박스` 에 `미처리`.
- `상위` 는 회의록 → 회의록의 `이 회의에서 나온 할 일` 에 저절로 뜹니다.
- 만든 줄 끝에 `→ [[만든 노트의 경로|만듦]]` 을 붙입니다 (99 history 에 같은 이름이 있을 수 있어 경로로). 다시 불려도 두 벌 안 만듭니다.
- 인박스에 떨어지면 플러그인이 `분류` 를 칸 이름(`📝 회의록 인박스`)으로 채웁니다. 프로젝트로 보내는 건 사람이 `📤 PARA로 보내기` 로 합니다.
  사람이 에이전트에게 시키면 **속성을 먼저**(`구역: 1.project` · `분류` 를 프로젝트 이름 · `상태`) 바꾸고 **곧바로** 파일을 옮깁니다.

### "반영해줘" — 결정 줄 → 회의록

사람이 가리킨 줄만 회의록 `## 결정` (또는 `## 다음 안건`) 에 덧붙입니다. 회의록 `작성자` 끝에 자기 이름. 그 밖의 회의록 칸은 안 건드립니다.

## 6. 다음 회의 전 — Heads Up

"다음 회의 준비해줘" 를 받으면 A2 에 `./templates/!(Template) 사전 준비.md` 로 초안을 씁니다. 재료:

- 지난 AI 정리의 `확인 필요` · `다음 안건` · 체크 안 된 할 일
- `A1.collection/paused` 의 안건 카드
- 지난 회의에서 만든 할일 노트 중 아직 `완료` 가 아닌 것

목표 · 원하는 결과물 · 시간 · 역할은 **비워 둡니다** — 사람이 정합니다. 지어내지 않습니다.

## 7. 속성

99 안은 제외된 파일이라 볼트에 새지 않지만, 13종은 그대로 씁니다 — 나중에 사람이 꺼낼 때 그대로 쓰이도록.

```yaml
유형: 메모
구역: 4.archive
분류:
주제:
  - <핵심어>
상태:
요약: "'<이름>' <무엇인지 한 줄>"
작성일: <오늘>
마감:
커버:
상위: "[[<회의록 파일 이름>]]"
링크:
담당:
작성자:
  - "[[<자기 이름>]]"
PARA정리: 끔
```

- `PARA정리: 끔` 은 제외 설정이 풀려도 플러그인이 옮기지 않게 하는 이중 안전장치입니다.
- `요약` 이 `'` 로 시작하면 큰따옴표로 감쌉니다. 줄끝 LF.

## 8. 하지 않는 것

- 99 밖에 쓰기 — "만들어줘" · "반영해줘" 로 사람이 가리킨 것 말고는
- 회의록 `참석:` `안건:` `## 속기` `## 자료` 고치기 · 회의록 `## 할 일 후보` 표 쓰기
- 체크 넣기 · 💡 해결 방향 채우기 · "(권장)" 달기
- 파일·폴더 지우기 (삭제는 사람이 합니다)
- 속기에 없는 담당 · 날짜 · 프로젝트 · 수치 지어내기
