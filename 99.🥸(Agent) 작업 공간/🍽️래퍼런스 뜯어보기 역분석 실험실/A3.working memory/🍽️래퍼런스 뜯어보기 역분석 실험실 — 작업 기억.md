# 🧠 🍽️래퍼런스 뜯어보기 역분석 실험실 — 작업 기억

- 출발점: [[1.🎯(Project) 프로젝트/🍽️래퍼런스 뜯어보기/비슷한 작업을 이전에 했었지. 그땐 그랬지|비슷한 작업을 이전에 했었지. 그땐 그랬지]]
- 하려는 것: 그 노트에서 말하는 **역분석** — 레퍼런스를 원심분리해 `.outline` 결핍을 푸는 카드만 핀셋으로 뽑고 C라인(C1~C5)에 꽂아 보기
- 이 폴더는 `99.🥸(Agent) 작업 공간/` 안이라 옵시디언 "제외된 파일"입니다 — 보드 · 검색에 안 뜹니다

## 실험실 원칙 (Rin, 2026-10-19)

1. **플러그인 코드는 손대지 않는다.** 커뮤니티 플러그인 · 우리가 만든 커스텀(`plugins/gaeddong-claude` 등) · 민규 서가 만든 것 모두.
2. **`skills/` · `docs/` 를 고치지 않는다.** 실험이 끝나고 본 프로젝트로 들어갈 때 필요한 수정을 한다.
   그때 고칠 것은 미리 `A4.meta/` 에 적어 둔다.
3. **고칠 때마다 버전으로 쌓는다** — 회의 작업 공간처럼 `A1.collection/검토 중/` 에. 아래 **버전 규칙**.

## 버전 규칙

- 결과물은 `A1.collection/검토 중/` 에 이름 끝 ` (v<번호>)` 로 냅니다. 예: `C3 Git 안전망 카드 (v1).md`
- **고칠 때는 덮어쓰지 않습니다.** 새 번호로 새 파일을 내고, 바뀐 것을 아래 **버전 기록** 에 한 줄 적습니다.
- 새 버전이 나오면 그 전 버전은 `A1.collection/history/` 로 옮깁니다 (회의 작업 공간과 같음). 지우지 않습니다.
- 사람이 고른 것은 사람이 `A5.outputs/` 로 옮깁니다. 보류는 `paused/`. 에이전트는 A5 에 만들지도 옮기지도 않습니다.

## 폴더

```
A1.collection/검토 중/   ← 🤖 버전 붙은 결과물 후보
             paused/    ← 🧑 보류
             history/   ← 🤖 밀려난 옛 버전
A2.scratch(ideation)/   ← 🤖 생각 정리 · 메모 (버전 안 붙임)
A3.working memory/      ← 🤖 이 노트
A4.meta/                ← 🤖 본 프로젝트로 갈 때 고칠 것 (skills · docs · 플러그인 — 지금은 적기만)
A5.outputs/             ← 🧑 사람이 고른 것
```
