# 사실 확인 — 답이 원본과 맞는가

검토 대상의 답을 하나씩 원본에 비춰 봅니다. 보고서의 "원본과 다른 답" · "출처가 없는 답" · "확인 못 한 답" 절을 채웁니다.

## 1. 출처가 붙었나

- 질문 틀은 답마다 `(출처: …)` 를 붙이게 합니다. 출처 없는 답은 **"출처가 없는 답"** 에 적습니다.
- `(출처: 직접 사용, 날짜)` 는 원본으로 확인할 수 없습니다. 맞는지 따지지 않고 그대로 둡니다. 다만 공식 문서와 어긋나면 "원본과 다른 답" 에 둘 다 인용해 적습니다.
- "모름" · "해당 없음 — 왜" 는 출처가 없어도 됩니다.

## 2. 원본에 그렇게 되어 있나

답마다 넷 중 하나로 봅니다.

| 본 결과 | 어디에 적나 |
| --- | --- |
| 원본과 맞음 | 적지 않음 (보고서 맨 위 개수에만 셈) |
| **이름은 원본에 있는데 동작 · 뜻이 다름** | 원본과 다른 답 |
| 원본에 없음 | 원본과 다른 답 ("원본에서 찾지 못함" 이라고) |
| 원본을 못 읽음 | 확인 못 한 답 |

- 두 번째 경우를 특히 봅니다. 기능 이름은 맞는데 "막는다" 를 "경고한다" 로, "멈춘다" 를 "표시만 하고 진행한다" 로 바꿔 적는 일이 가장 흔합니다.
- 답에 나온 **고유한 이름**(기능 · 파일 · 명령 · 화면 이름)과 **숫자**(시간 · 횟수 · 비율 · 단계 수)는 빠짐없이 확인합니다.

## 3. 원문 인용 칸

- 1장(스스로 하는 말)은 **원문 그대로** 적는 칸입니다. 원본 문장과 다르면 "원본과 다른 답" 에 적습니다.
- 번역했으면 번역이라고 밝혔는지 봅니다. 안 밝혔으면 같은 절에 "번역인데 원문 인용처럼 적음" 으로 적습니다.

## 4. 숫자

- 숫자에 **센 방법이나 출처**가 있는지 봅니다. 예: "첫 결과물까지 3단계" 면 그 3단계가 위 칸에 차례로 적혀 있어야 합니다.
- 잰 적 없는 숫자가 잰 것처럼 적혀 있으면 "원본과 다른 답" 에 "원본에서 찾지 못함 — 잰 방법도 없음" 으로 적습니다.
