## 속성 14종

| 속성 | 뜻 |
| --- | --- |
| `제목` | 노트 이름. 파일명과 같다 |
| `유형` | 노트의 종류. **가장 먼저 거는 조건** |
| `구역` | PARA 위치. `0.inbox` `1.project` `2.area` `3.resource` `4.archive` |
| `분류` | 구역 안의 묶음 (목록) |
| `주제` | 태그성 키워드 (목록) |
| `상태` | 진행 상태. 유형마다 값이 다름 |
| `요약` | 한 줄 설명 |
| `작성일` | 만든 날 |
| `마감` | 끝내야 하는 날 / 끝난 날 |
| `커버` | 대표 이미지 (위키링크). **본문 첫 이미지로 자동 채워집니다** |
| `상위` | 상위 노트 (위키링크) |
| `링크` | 외부 원본 주소 |
| `담당` | 이 일을 **책임지는** 사람. 위키링크로 넣어야 색 칩이 된다. 기본값은 비움(미할당) |
| `작성자` | 이 노트를 **쓴** 주체. 사람이면 민규 서·Rin, AI가 썼으면 Claude·Gemini·ChatGPT 로 반드시 밝힌다 |

> [!tip]- 그 아래 '이외 속성' 은 뭔가요
> 유형마다 고유한 값들입니다. 책의 `출판사`, 아이디어의 `망고's 점수`, 레퍼런스의 `참고 포인트` 처럼요.
> 통일하면 오히려 정보가 사라지는 것들이라 원래 이름 그대로 남겼습니다.
