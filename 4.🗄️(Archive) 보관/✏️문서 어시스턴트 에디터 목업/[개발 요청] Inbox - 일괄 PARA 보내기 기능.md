## 만든 것 (2026-09-17, Claude)

1. 핀보드에서 `☑ 일괄 보내기` → 카드를 누르면 체크됩니다 (열리지 않음)
2. 위에 뜨는 줄에서 `📤 PARA로 보내기 ▾` → 구역 고르기
3. 창 하나에서 한 번에
   - `구역`·`분류`·`마감` 은 모두에. 분류·마감을 비우면 각자 지금 값 그대로
   - `유형` 은 **각자 그대로.** 고른 구역에 없는 유형인 노트만 한 번에 고릅니다 (예: 메모를 프로젝트로 → 할일)
   - 창 아래에 노트마다 `지금 유형 → 갈 유형 · 상태` 가 한 줄씩 보입니다
4. 보낸 카드는 판에서 바로 빠지고, 끝나면 알림 한 번

파일 탐색기에서 Ctrl·Shift 로 여러 개 고르고 우클릭해도 같은 창이 열립니다 — 인박스 밖 노트도 됩니다.
