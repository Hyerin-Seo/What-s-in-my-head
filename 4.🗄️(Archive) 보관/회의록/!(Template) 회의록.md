## ⏮ 지난 회의에서 넘어온 것

```base
filters:
  and:
    - note["유형"] == "할일"
    - note["주제"].contains("회의 할 일")
    - not:
        - file.hasLink(this.file)
views:
  - type: table
    name: ⏳ 아직 안 된 것
    filters:
      and:
        - note["상태"] != "완료"
        - note["상태"] != "히스토리"
    order:
      - file
      - 담당
      - 마감
      - 상태
      - 상위
  - type: table
    name: ✅ 요 7일 사이 끝난 것
    filters:
      and:
        - note["상태"] == "완료"
        - file.mtime >= today() - "7d"
    order:
      - file
      - 담당
      - 상태
      - 상위
```

■ 한 바퀴 — 사람이 하는 건 세 가지뿐
  1. 회의 전: 맨 위 `⏮ 지난 회의에서 넘어온 것` 을 봅니다. 지난 회의 할 일이 됐나 안 됐나가 저절로 뜹니다
  2. 회의 중: `속기` 만 씁니다. 정리하지 말고 들리는 대로
  3. 회의 뒤: 에이전트에게 "이 회의록 정리해줘" → `🤖 AI 정리` 에 체크리스트가 뜹니다
     고를 줄에 체크하고 "반영해줘" → 할 일은 할일 노트로, 정한 것 · 다음 회의로 는 아래 칸으로

■ 자료
  이미지   붙여넣기 (이 폴더 `이미지/` 로 들어갑니다)
  사이트   주소 그대로
  폴더     `폴더::볼트 안 경로` 처럼 코드로 적으면 눌러서 열립니다

■ `🤖 AI 정리` 는 에이전트가 쓴 초안입니다
  실제 파일은 `99.🥸(Agent) 작업 공간/<이 회의록 이름>/A5.outputs/` 에 있고 (샌드박스 — 보드·검색에 안 뜸),
  여기에는 끼워 보여 주기만 합니다. 후보를 거르지 않고 전부 냅니다 — 고르는 건 사람입니다.
  안 고른 줄은 기록되어 다음 정리가 더 정확해집니다.

■ `✅ 정한 것` · `⏭ 다음 회의로` 는 "반영해줘" 때 체크한 줄만 들어옵니다
  직접 써도 됩니다. `⏭ 다음 회의로` 는 다음 회의의 사전 준비 재료입니다.

■ `이 회의에서 나온 할 일` 은 저절로 모입니다
  할 일 노트는 인박스를 거쳐 각자 프로젝트 폴더에 살고, `상위` 로 이 회의록을 가리킵니다.
  에이전트 규칙은 볼트 맨 위 `skills/meeting-notes/SKILL.md` 에 있습니다.
