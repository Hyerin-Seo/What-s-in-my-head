# 🤖 06. 최종검토 Agent

> **상위 대시보드**: [[00_Dashboard]]

---

## 📌 역할 및 목표
- 5가지 중간 산출물(조건, 숙소, 일정, 예산, 준비물)을 종합 점검하고, 리스크(날씨 대안, 휴무일, 과밀 동선)를 최종 검증한 뒤 **[사람 직접 승인 게이트]**에 승인을 요청합니다.

## 📥 입력 데이터
- 중간 산출물 ① ~ ⑤ 전체

## 🔍 최종 종합 검증 기준 (Audit Matrix)
- [x] **일정 과밀도**: 일자별 이동시간이 3시간 이하인가?
- [x] **이동 시간**: 주요 관광지 간 거리가 연령대 체력에 적합한가?
- [x] **예산 초과**: 총 비용이 목표 예산 범위 안인가?
- [x] **빠진 준비물**: 필수 비상약 및 서류가 포함되었는가?
- [x] **휴무일 체크**: 방문 장소의 정기 휴무일과 일정이 겹치지 않는가?

## 👤 사람 직접 승인 게이트 (Human-in-the-Loop)
> [!CAUTION]
> **권한 통제 규정**: 숙소 예약, 교통편 결제, 개인정보 입력 등 비용 발생 및 외부 연동 액션은 에이전트가 자동 처리하지 않고 **사람이 직접 승인**합니다.
