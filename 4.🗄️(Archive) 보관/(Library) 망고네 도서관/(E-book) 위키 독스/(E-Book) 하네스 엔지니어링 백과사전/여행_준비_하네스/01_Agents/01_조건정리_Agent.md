# 🤖 01. 조건정리 Agent

> **상위 대시보드**: [[00_Dashboard]]

---

## 📌 역할 및 목표
- [[family-trip-brief]]로부터 여행지, 기간, 동행자 특성, 총 예산, 선호 여행 스타일, 주의사항, 참고 링크 등의 컨텍스트를 수집하고 정제합니다.

## 📥 입력 컨텍스트
- [[family-trip-brief]] (여행지, 기간, 동행자, 예산, 스타일, 주의사항, 참고 링크)

## 📤 중간 산출물 ① (Output)
- **정제된 조건 요약서**:
  - 여행 그룹 특성 분석 (예: 아동 동행 시 휴식 필요, 어르신 동행 시 경사도 고려 등)
  - 1일 권장 예산 한도
  - 필수 포함/제외 키워드 정제

## 🔍 검증 기준 (Validation Criteria)
- [ ] 필수 컨텍스트 6가지(여행지/기간/동행자/예산/스타일/주의사항)가 모두 파악되었는가?
- [ ] 참고 링크가 있을 경우 해당 데이터가 추출되었는가?
- [ ] 동행자의 연령대 특성이 추출되어 주의사항으로 매핑되었는가?
