# EXP10 아웃라인 다중 노드 동시 선택 및 일괄 AI 디렉션 프로토타입

## 🧐 1. 왜 이런 UI·사양이 필요하다고 느꼈는가? (현행 작업의 고통과 문제의식)

* **비연속 다중 영역 짚기(Multi-selection)의 불가능:**
  * 글을 쓰다 보면 "1번 섹션의 두 번째 줄과, 3번 섹션의 첫 번째 불릿"처럼 서로 떨어져 있는 여러 노드를 동시에 골라 *"이것들을 유기적으로 연결해서 수정해줘"*라고 지시하고 싶습니다.
  * 그러나 현재 UI에서는 단일 노드나 연속된 블록만 긁을 수 있어, 여러 곳을 묶어서 AI에 넘기는 조작 자체가 원천 차단되어 있습니다.
* **노드별 반복 지시로 인한 문맥 오염:**
  * 한 군데씩 따로 채팅에 복사해 넣고 지시하다 보면 AI의 이전 답변 문맥이 뒤섞이고 지시 피로도가 극에 달합니다.
* **개발자 도구(Antigravity/Cursor) 수준의 정밀한 셀렉션 UI 갈망:**
  * 코드 편집기에서는 여러 함수나 라인을 `Ctrl`+클릭으로 골라 한 번에 Composer나 채팅에 묶어 프롬프트를 날리는 경험이 일상화되어 있습니다.
  * 이 정밀한 선택 조작을 아웃라이너 노드 위계에도 그대로 적용해야 합니다.

## 🔬 2. 실험 가설 (Hypothesis)
* **가설:** "아웃라인 트리에서 `Ctrl`+클릭(또는 체크박스 토글)으로 **비연속 복수 노드를 다중 선택(Multi-selection)**하고, 플로팅 액션 바를 통해 **'선택된 노드 일괄 프롬프트 입력창'을 띄워 지시**하게 하면, 부분 수정 지시의 정확도가 올라가고 대화 턴 수가 절반 이하로 줄어들 것이다."

## 🛠️ 4. 프로토타입 구현 명세 (UI/UX Prototype Spec)
1. **아웃라인 다중 노드 선택 인터랙션:**
   - `Ctrl` (Mac: `Cmd`) + 노드 클릭 시 복수 노드 하이라이트 선택 상태 활성화.
   - 불릿 좌측에 일괄 선택용 체크박스 UI 옵션 노출.
2. **플로팅 컨텍스트 바 (Selection Context Bar):**
   - 2개 이상의 노드가 선택되는 즉시 화면 하단에 `[ 선택된 3개 노드 대상 지시하기 💬 ]` 플로팅 바 노출.
   - 클릭 시 선택된 노드들의 텍스트와 트리 경로(Breadcrumb)가 프롬프트 입력창에 컨텍스트 블록으로 자동 첨부.
3. **선택 노드 타겟 일괄 재생성:**
   - 지시 프롬프트 입력 후 실행 시, 선택된 각 노드의 위치에 AI 응답이 개별 치환 반영.
