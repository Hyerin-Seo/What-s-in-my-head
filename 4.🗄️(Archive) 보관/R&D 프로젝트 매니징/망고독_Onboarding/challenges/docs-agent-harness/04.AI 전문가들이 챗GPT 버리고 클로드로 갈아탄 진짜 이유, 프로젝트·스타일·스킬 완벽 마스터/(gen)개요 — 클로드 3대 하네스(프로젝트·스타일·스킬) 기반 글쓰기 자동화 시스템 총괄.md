# (gen)개요 — 클로드 3대 하네스(프로젝트·스타일·스킬) 기반 글쓰기 자동화 시스템 총괄

> **레퍼런스 원천**: 유튜브 [세인튜 Seintoo] — *["The Real Reason AI Experts Abandoned ChatGPT and Switched to Claude (Mastering Projects, Styles, Skills)"](https://www.youtube.com/watch?v=9SLS0Xqe9KM)*  
> **하네스 본질**: *"매번 챗창에 '이런 말투로 써줘', '이 자료 참고해줘'라고 복붙하는 사람은 영원히 AI의 노예로 남는다. **프로젝트(지식 베이스) + 스타일(문체 DNA) + 스킬(작업 절차)**이라는 클로드의 3대 하네스를 시스템으로 구축해 둘 때, 비로소 인간은 버튼 하나로 나만의 글을 양산하는 디렉터가 된다."*

## 1. 왜 AI 전문가들은 ChatGPT를 버리고 Claude로 갈아탔는가?

일반적인 챗GPT 작업 방식은 **'휘발성 대화(Ephemeral Chat)'**입니다:
* 대화창을 새로 열 때마다 사내 배경 지식을 다시 설명해야 합니다.
* 내 말투와 취향을 기억하지 못해 매번 뻔한 번역투로 돌아갑니다.
* 프롬프트 복붙과 핑퐁에 지쳐 결국 *"내가 직접 쓰는 게 낫겠다"*며 포기하게 됩니다.

클로드(Claude)가 제시하는 해법은 대화가 아닌 **'시스템(System)'**입니다:
1. **프로젝트 (Projects)**: 사내 문서와 가이드라인을 영구 기억하는 **지식 베이스캠프**.
2. **스타일 (Styles)**: 내 과거 글에서 추출하여 박아둔 **나만의 문체 DNA**.
3. **스킬 (Skills)**: 기획부터 윤문까지 반복되는 절차를 하나의 명령어로 압축한 **자동화 파이프라인**.

## 2. 클로드 3대 하네스 결합 글쓰기 자동화 4단계 총람

```text
┌────────────────────────────────────────────────────────┐
│  [Step 01] 프로젝트(Projects) 구축 (Knowledge Grounding)│
│  → 사내 룰북, 참고 자료를 프로젝트 지식에 사전 영구 주입 │
├────────────────────────────────────────────────────────┤
│  [Step 02] 문체 DNA 추출 및 스타일(Styles) 고정       │
│  → 과거 잘 쓴 글 3편을 분석하여 '나만의 고유 톤'으로 동기화│
├────────────────────────────────────────────────────────┤
│  [Step 03] 반복 절차 모듈화 및 스킬(Skills) 세팅       │
│  → [기획 ➔ 초안 ➔ 윤문] 3단계 워크플로우를 명령어로 압축│
├────────────────────────────────────────────────────────┤
│  [Step 04] 3대 하네스 결합 및 양산 피드백 루프         │
│  → 복붙 없이 키워드 1개 입력으로 고품질 콘텐츠 직조     │
└────────────────────────────────────────────────────────┘
```

| 하네스 축 | 클로드 기능 | 통제 메커니즘 (Harness) | 산출물 및 효과 |
| :--- | :--- | :--- | :--- |
| **[[Step 01]]** | Projects | 사내 룰북, 배경 지식 사전 업로드 | 매 대화마다 자료를 복붙할 필요 100% 제거 |
| **[[Step 02]]** | Styles | 과거 글에서 추출한 문체·문장길이·불릿 규칙 고정 | 번역투/AI 냄새가 완전히 제거된 '내 진짜 말투' 복제 |
| **[[Step 03]]** | Skills | [아웃라인 ➔ 본문 ➔ 검증] 반복 워크플로우 템플릿화 | 3단계 복잡한 작업 동선을 단 1회 명령으로 자동화 |
| **[[Step 04]]** | Synthesis | 지식 + 문체 + 절차 3중 결합 가동 | 1/10 시간 안에 100% 개인화된 전문 문서 완성 |

---

## 3. 온보딩 2단계 실행 요령 (Rin을 위한 가이드)

1. 작업자(Rin)는 **Step 01부터 Step 04까지의 카드를 확인**하며, 클로드의 [프로젝트 + 스타일 + 스킬]이 어떻게 프롬프트 노가다를 제거하는지 학습합니다.
2. 1단계 Candidate 과제(예: 옵시디언 가이드, 나무위키 엔트리, 상세설명서 등)를 클로드의 Project 환경에 올리고, **'나만의 커스텀 스타일'을 장착**해 봅니다.
3. 매번 복붙하던 고통에서 벗어나 **"프로젝트에 올려두고 스타일만 켜두니, AI가 내 마음을 읽은 것처럼 척척 써내는 해방감"**을 실측합니다.
