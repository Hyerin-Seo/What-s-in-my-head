# Prototype Test Guide

> Stage 1에서 반복되는 실제 Job이 확인되기 전에는 이 테스트를 시작하지 않는다.

## 준비

- [[(chatgpt)소스 범위·필수 서비스·수집 기준]]의 공개 문서 과업 팩 또는 참가자가 허가한 비식별 자료를 사용한다. 형식/레퍼런스 1건, 근거 자료 3건 이상, 사전 정의한 성공 조건이 없는 과업은 테스트하지 않는다.
- 비교 후보는 `현재 흐름`, `에디터 내 기능`, `분할 화면`, `2D Workspace`이며, 2D를 기본값으로 취급하지 않는다.
- 참가자마다 후보 순서를 바꾸고, 과업 수행 전에 기능 설명을 최소화한다.
- 진행자와 기록자를 분리할 수 있으면 분리한다.

## 과업과 기록

참가자는 “주어진 근거에서 필요한 내용을 찾아 형식에 맞는 한 섹션을 완성하고, 근거를 다시 확인할 수 있게 하라”는 한 가지 핵심 과업을 수행한다.

| 기록 항목 | 정의 |
| --- | --- |
| 완료/중단 | 도움 없이 완료, 도움 후 완료, 중단으로 구분 |
| 시간 | 시작부터 제출 가능하다고 선언할 때까지 |
| 형식 오류 | 사전에 정한 필수 항목·형식의 누락 수 |
| 근거 확인 | 근거를 찾는 시간과 찾지 못한 주장 수 |
| 도움 요청·되돌리기 | 참여자가 진행자에게 도움을 요구하거나 이전 상태로 되돌린 횟수 |
| 다음 실제 업무 선택 | 다음 유사 업무에 어떤 후보를 쓸지와 포기 이유 |

## 진행 원칙

- 사용자가 막혀도 바로 가르치지 않는다. 무엇을 찾는지 먼저 묻고 기록한다.
- “좋아 보인다”는 평가는 보조 메모이며, 완료·중단·선택보다 약한 증거다.
- 테스트 후에는 각 후보의 장점뿐 아니라 “이 방식이 실제 업무에 맞지 않는 이유”를 반드시 묻는다.
