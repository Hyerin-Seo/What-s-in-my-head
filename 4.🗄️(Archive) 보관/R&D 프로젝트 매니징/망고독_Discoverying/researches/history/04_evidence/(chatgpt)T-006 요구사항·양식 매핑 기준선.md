# T-006 요구사항·양식 매핑 기준선

## 과업 정의와 앵커 규칙

- 입력: `01_공고문.pdf` 13쪽, `02_RFP.hwpx`, `03_연구개발계획서_양식.hwpx`.
- 산출: 실제 연구개발계획서가 아닌 `원문 앵커 → 요구 → 본문/첨부 위치 → 검수` 구조화 표.
- HWPX 앵커는 페이지 수가 아니라 문서 안의 제목·표·작성요령 문구를 쓴다.
- 본문 양식의 비행기·이온풍·MIT·YYYY·ABCDE는 **작성 예시**다. Space-K BIG의 실제 과제 사실이나 목표로 옮기면 오류다.
- `사업화 전략 및 계획`은 양식상 `해당 시` 선택 항목이다. RFP가 필수로 요구하지 않은 경우 누락으로 채점하지 않는다.
