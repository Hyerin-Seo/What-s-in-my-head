# (gen)개요 — 노트북LM RAG 기반 실무 보고서 100% 종결 하네스 총괄

> **레퍼런스 원천**: 유튜브 [퇴사한아빠] — *["노트북LM 보고서 이렇게만 세팅하세요! 실무에 바로 쓰는 100개 프롬프트 다 드립니다"](https://www.youtube.com/watch?v=Ug8H3Vn8uCM)*  
> **하네스 본질**: *"구글 노트북LM(NotebookLM)을 단순한 PDF 3줄 요약기로 쓰는 것은 1%만 활용하는 것이다. 업로드한 원천 소스(Source)라는 철벽의 기준선(Ground Truth) 위에서, **[구조·톤앤매너·분량·서술방식·타겟독자]의 '스타일 빌더 5대 파라미터'**를 하네스로 세팅할 때 경영진 보고용 실무 문서가 100% 완벽하게 직조된다."*

## 1. 왜 이 영상이 'RAG 팩트 앵커링 하네스'의 최고봉인가?

앞선 01번(장표 시각 셰이프)과 02번(다중 AI 도구 분업)에 이어,  
이번 03번 영상은 **"내가 업로드한 원천 데이터만을 절대적 근거로 삼아, 환각(Hallucination) 0% 상태에서 고밀도 비즈니스 보고서를 뽑아내는 구글 노트북LM RAG 하네스"**의 정수를 보여줍니다.

* **환각의 원천적 억제 (RAG Grounding)**: 외부 인터넷의 불확실한 지식을 배제하고, 오직 내가 지정한 소스(PDF, 웹페이지, 회의록, 기획서) 안에서만 답변하도록 강제.
* **스타일 빌더(Style Builder) 하네스**: 뻔한 AI 말투가 나오지 않도록 **5가지 통제 다이얼(구조/톤/분량/서술/독자)**을 돌려 사내 보고서 규격으로 즉시 동기화.

## 2. 노트북LM 실무 보고서 4단계 프로세스 총람

```text
┌────────────────────────────────────────────────────────┐
│  [Step 01] 원천 소스 바인딩 (Source Grounding)         │
│  → PDF, 구글 문서, URL 등 백데이터를 소스로 묶어 앵커링   │
├────────────────────────────────────────────────────────┤
│  [Step 02] 스타일 빌더 5대 세팅 (Style Builder Setup)   │
│  → [구조 + 톤앤매너 + 분량 + 서술방식 + 타겟독자] 다이얼 고정 │
├────────────────────────────────────────────────────────┤
│  [Step 03] 상황별 3대 템플릿 가동 (Template Execution) │
│  → 임원용 1p 요약 / 팀장용 3p 표준 / 실무용 딥다이브    │
├────────────────────────────────────────────────────────┤
│  [Step 04] 교차 출처 앵커링 및 액션 도출 (Synthesis)   │
│  → 단순 요약을 넘어, 소스 간 교차 분석 및 Next Action 수렴│
└────────────────────────────────────────────────────────┘
```

| 단계 | 핵심 과업 | 통제 하네스 (Harness Mechanism) | 산출물 및 효과 |
| :--- | :--- | :--- | :--- |
| **[[Step 01]]** | 소스 데이터 바인딩 | 외부 지식 차단, 오직 업로드된 파일만 참조 | 환각 0%, 100% 원문 인용 번호 보장 |
| **[[Step 02]]** | 스타일 빌더 5대 옵션 | 구조·톤·분량·서술·독자 파라미터 조합 (12만 가지) | 회사 직급 및 보고 목적에 맞춘 문체 완벽 복제 |
| **[[Step 03]]** | 상황별 3대 템플릿 | 1p Executive / 3p Standard / Deepdive 선택 가동 | 불필요한 프롬프트 핑퐁 없이 단 1회 프롬프트로 완결 |
| **[[Step 04]]** | 교차 인사이트 큐레이션 | 복수 소스 간의 차이점, 리스크, 액션 아이템 합성 | 단순 텍스트 나열을 뛰어넘는 전략적 제언 완성 |

## 3. 온보딩 2단계 실행 요령 (Rin을 위한 가이드)

1. 작업자(Rin)는 **Step 01부터 Step 04까지의 카드를 확인**하며, 노트북LM의 '스타일 빌더'가 어떻게 AI를 통제하는지 이해합니다.
2. 1단계 Candidate 과제(예: 옵시디언 가이드, 나무위키 엔트리, 상세설명서 등)의 원천 백데이터를 노트북LM에 소스로 업로드합니다.
3. 영상에서 제시하는 **스타일 빌더 5대 프롬프트 옵션을 적용**하여 1회 지시만으로 "환각 없이 정확한 출처 번호가 박힌 비즈니스 보고서"가 출력되는 쾌감을 경험합니다.
