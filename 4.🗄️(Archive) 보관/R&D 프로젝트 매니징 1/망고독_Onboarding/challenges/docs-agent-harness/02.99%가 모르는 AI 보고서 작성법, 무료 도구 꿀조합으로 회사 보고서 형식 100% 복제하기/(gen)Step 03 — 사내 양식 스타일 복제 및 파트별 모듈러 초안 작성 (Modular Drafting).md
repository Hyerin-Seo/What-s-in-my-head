# (gen)Step 03 — 사내 양식 스타일 복제 및 파트별 모듈러 초안 작성 (Modular Drafting)

> **Step 03 헌법**:  
> *"AI에게 보고서 전체를 한 번에 다 쓰게 하지 마라.  
> **과거 사내 모범 보고서 1장을 샘플(In-context)로 던져주어 서식을 100% 복제하게 만들고, 목차의 파트(Part)별로 쪼개어 한 챕터씩 직조**하라."*

---

## 1. 왜 '스타일 복제'와 '파트별 분절'이 핵심인가?

AI가 작성한 보고서가 상사에게 반려당하는 가장 큰 이유는 내용보다 **"우리 회사 보고서 양식이 아니기 때문"**입니다:
* 각 회사마다 고유한 기호 체계(`□` ➔ `○` ➔ `-` ➔ `※`), 서술 종결 어미(`~함`, `~추진 요망`), 표 테두리 스타일이 존재합니다.
* AI에게 이 '모범 샘플'을 주지 않으면 네이버 블로그 말투나 일반적인 번역투 줄글을 뱉어냅니다.

또한 10페이지 전체를 한 번에 뽑게 하면 AI의 토큰 한계와 집중력 저하로 **후반부로 갈수록 서식이 깨지고 내용이 날림으로 축약**됩니다. 따라서 **파트별(Modular)로 쪼개어 작성**해야 합니다.

---

## 2. 사내 서식 100% 복제 메커니즘 (Style Cloning)

```text
┌────────────────────────────────────────────────────────┐
│ [입력 1] 과거 사내 우수 보고서 텍스트 샘플 (Reference)  │
│   → 기호 체계(□, -, ·), 문장 길이, 여백 스타일 추출     │
├────────────────────────────────────────────────────────┤
│ [입력 2] Step 02에서 수집한 검증된 팩트 데이터         │
│   → 조사된 수치와 URL 앵커                               │
├────────────────────────────────────────────────────────┤
│ [출력 명령] "위 샘플의 서식/문체 그대로 '1장만' 작성하라" │
│   → 파트 A 완료 ➔ 검토 ➔ 파트 B 작성 (모듈러 연속 진행)  │
└────────────────────────────────────────────────────────┘
```

## 3. 실전 하네스 프롬프트 템플릿 (사내 양식 복제 및 모듈 작성)

```text
[Step 03 모듈러 초안 작성 프롬프트]
"아래 제공된 [사내 모범 보고서 샘플]의 서식, 들여쓰기, 불릿 기호 체계, 문장 종결 어미를 100% 복제하여 작성하십시오.

[사내 모범 보고서 샘플]:
(여기에 과거 회사에서 결재 통과된 우수한 보고서 1페이지 텍스트 붙여넣기)

[이번에 작성할 파트]: Step 01 목차 중 '제1장. 도입 배경 및 시장 현황'
[주입할 팩트 데이터]: Step 02에서 Perplexity로 수집한 통계 표

지침:
1. 샘플에 쓰인 기호(예: □ ➔ ○ ➔ - ➔ ※)의 위계를 엄격히 유지할 것.
2. 서술형 문장 대신 '개조식(~함, ~임, ~요망)'으로 끝맺을 것.
3. 다른 장은 쓰지 말고 오직 '제1장'만 완성도 100%로 출력할 것."
```

## 4. 효과 및 망고독(Scaffolding) 연결점

* **효과**: AI가 뽑아낸 글이 **"어제 김 부장이 쓴 보고서"와 구분할 수 없을 정도로 완벽한 사내 공식 톤앤매너로 출력**됨.
* **망고독 연결**: 망고독의 **템플릿 스캐폴딩 엔진**이 바로 이 기호 위계와 표 서식을 미리 잠가두고, 슬롯별로 내용을 채우는 아키텍처의 정수입니다.
