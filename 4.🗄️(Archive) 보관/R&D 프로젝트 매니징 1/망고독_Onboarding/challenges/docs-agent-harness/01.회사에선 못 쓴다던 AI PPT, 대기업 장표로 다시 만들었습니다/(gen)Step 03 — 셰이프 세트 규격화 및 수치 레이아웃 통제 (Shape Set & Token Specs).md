# (gen)Step 03 — 셰이프 세트 규격화 및 수치 레이아웃 통제 (Shape Set & Token Specs)

> **Step 03 헌법**:  
> *"AI가 만든 PPT가 촌스러운 이유는 글씨가 아니라 **'도형의 두께, 화살표 각도, 여백이 페이지마다 제각각'**이기 때문이다.  
> 대기업의 셰이프 세트(Shape Set: 1장의 규격 시트)를 정의하고, AI에게 **'이 셰이프 시트에 있는 도형과 여백 수치만 쓰라'**고 하네스를 채워라."*

---

## 1. 왜 '셰이프 세트(Shape Set)'가 디자인 하네스의 핵심인가?

대기업 IR 장표를 보면 100페이지가 넘어도 단정하고 고급스러워 보입니다. 비결은 단순합니다:
* 쓰는 도형의 종류가 **단 3~4개**로 엄격히 제한되어 있습니다.
* 박스 모서리 둥글기(Radius), 선 두께(1px), 화살표 모양, 폰트 크기 계층이 **단 1픽셀의 오차도 없이 통일**되어 있습니다.

AI에게 자유를 주면 1페이지는 둥근 박스, 2페이지는 네모 박스, 3페이지는 알록달록 그라데이션을 씁니다.  
따라서 **'허용된 도형 규격 시트(Shape Set)'를 먼저 정의하고 AI에게 주입**해야 합니다.

---

## 2. 대기업 표준 셰이프 세트 규격 (The Minimal Shape Set)

실무 장표에서 실제로 사용하는 핵심 4대 셰이프 컴포넌트:

```text
┌────────────────────────────────────────────────────────┐
│ [Shape 1] 헤드라인 박스: 높이 48px, 투명 배경, 좌측 정렬│
├────────────────────────────────────────────────────────┤
│ [Shape 2] 컨테이너 카드: 1px 실선(#E2E8F0), R=8px, 패딩 16px│
├────────────────────────────────────────────────────────┤
│ [Shape 3] 프로세스 화살표: 두께 2px, 쉐브론 단일 규격  │
├────────────────────────────────────────────────────────┤
│ [Shape 4] 데이터 매트릭스 표: 헤더 다크 그레이, 행높이 36px│
└────────────────────────────────────────────────────────┘
```

| 토큰 요소 | 대기업 표준 규격 (Standard Spec) | 금지 사항 (Do Not Use) |
| :--- | :--- | :--- |
| **컬러 팔레트** | Primary 1색(Navy/Blue) + Gray 2종(#333, #777) | 무지개색, 채도 높은 형광색 |
| **선 및 외곽선** | 1px Solid(#E2E8F0) 단일화 | 2px 이상 굵은 테두리, 그림자 효과 |
| **폰트 위계** | H1(20pt Bold) ➔ H2(14pt SemiBold) ➔ Body(11pt) | 4개 이상의 다양한 폰트 크기 혼용 |
| **박스 여백** | 블록 간 간격 16px, 내부 패딩 12px 고정 | 요소 간 불규칙한 여백 |

---

## 3. 실전 하네스 프롬프트 템플릿 (수치 레이아웃 강제)

AI에게 디자인을 지시할 때, 수치 토큰을 못 박아 하네스로 전달합니다.

```text
[Step 03 하네스 지시문]
"디자인 레이아웃은 사전에 정의된 [표준 셰이프 세트]만을 사용하십시오:

1. 컬러 토큰:
   - 배경: #FFFFFF
   - 카드 테두리: 1px solid #E2E8F0
   - 텍스트 주색상: #0F172A (다크 슬레이트)
   - 포인트 강조색: #2563EB (로열 블루 단 1가지만 허용)
2. 컴포넌트 규격:
   - 모든 정보 카드는 'Radius: 8px, Padding: 16px'로 통일할 것.
   - 화살표는 단순 선형 화살표(→)만 사용하며 3D 도형 절대 금지.
   - 표(Table)는 헤더 배경 #F8FAFC, 본문 셀 높이 36px로 고정할 것."
```

## 4. 효과 및 망고독(Scaffolding) 연결점

* **효과**: AI가 디자인을 망치는 원흉인 '시각적 불일치'가 완벽히 차단되고, **대기업 전용 디자인 템플릿을 입힌 것처럼 장표의 격이 수직 상승함**.
* **망고독 연결**: 망고독의 **디자인 시스템 토큰(Tailwind CSS v4 + 고정 UI 컴포넌트)**이 바로 이 역할을 엔진 레벨에서 영구 보장하는 장치입니다.
