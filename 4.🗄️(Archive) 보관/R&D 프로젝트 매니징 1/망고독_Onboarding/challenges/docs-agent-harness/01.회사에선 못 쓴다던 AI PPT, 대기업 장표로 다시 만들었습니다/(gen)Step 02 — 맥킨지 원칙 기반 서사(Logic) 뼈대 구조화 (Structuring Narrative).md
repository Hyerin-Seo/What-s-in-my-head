# (gen)Step 02 — 맥킨지 원칙 기반 서사(Logic) 뼈대 구조화 (Structuring Narrative)

> **Step 02 헌법**:  
> *"장표의 제목은 '현황 보고' 같은 명사형 단어가 아니라, **'무엇을 해야 하는가'를 명확히 선언하는 두괄식 결론(Lead Message)**이어야 한다.  
> 맥킨지 4단 서사(결론 ➔ 근거 ➔ 실행 ➔ 결정)를 뼈대로 박아둘 때, 비로소 AI의 장황한 횡설수설이 멈춘다."*

---

## 1. 왜 '서사(Logic) 구조화'가 필수적인가?

블록의 위치(Step 01)를 잡아주어도, AI에게 내용을 채우라고 하면 "이것은 매우 중요한 이슈이며 다양한 관점에서 검토가 필요합니다..." 같은 **알맹이 없는 공자왈 맹자왈**을 쏟아냅니다.

대기업 임원 보고용 장표의 생명은 **'두괄식 서사(Logic)'**입니다:
* 바쁜 의사결정권자는 장표를 3초 이상 보지 않습니다.
* 첫 줄에서 **"So What?(그래서 결론이 뭔데?)"**을 선언하고,
* 하위 블록에서 **"Why So?(그 근거 데이터가 뭔데?)"**를 숫자로 입증해야 합니다.

---

## 2. 맥킨지 피라미드 기반 4단 서사 구조

대기업 IR 및 컨설팅 장표의 표준적인 서사 흐름:

```text
┌────────────────────────────────────────────────────────┐
│ [1. 결론 (Conclusion / Lead)]                         │
│   → "상반기 매출 15% 하락, 원인은 공급망 지연 (So What?)"│
├────────────────────────────────────────────────────────┤
│ [2. 근거 데이터 (Evidence / Why So?)]                 │
│   → 블록 A: 원자재 리드타임 3주 증가                   │
│   → 블록 B: 물류비용 40% 급등                          │
├────────────────────────────────────────────────────────┤
│ [3. 실행 방안 (Action / How To)]                      │
│   → 3분기 내 공급선 다변화 2개사 체결 추진             │
├────────────────────────────────────────────────────────┤
│ [4. 최종 결정 요청 (Decision)]                         │
│   → 예산 1.2억 원 긴급 전용 승인 요청                 │
└────────────────────────────────────────────────────────┘
```

## 3. 실전 하네스 프롬프트 템플릿 (두괄식 문장 강제)

AI가 서술형 사족을 쓰지 못하도록, **헤드라인과 불릿 포인트의 문장 종결 규칙**을 엄격히 하네스로 묶습니다.

```text
[Step 02 하네스 지시문]
"모든 블록의 텍스트는 맥킨지 피라미드 원칙을 준수하여 작성하십시오:

1. 헤드라인(Lead Message) 규칙:
   - 명사형 종결(예: 'AI 도입 현황') 금지.
   - 반드시 [현상 + 원인 + 수치]가 포함된 완전한 문장으로 작성 (예: '도입률 30% 정체, 주요 원인은 프롬프트 학습 비용 과다').
2. 하위 근거 블록 규칙:
   - 문장 길이는 1줄을 넘지 말 것 (최대 30자 이내).
   - 반드시 구체적인 수치(%, 시간, 건수)와 팩트만 포함할 것.
   - 감정적이거나 추상적인 형용사(예: '매우 뛰어난', '혁신적인') 사용 시 즉시 실패로 간주."
```

## 4. 효과 및 망고독(Scaffolding) 연결점

* **효과**: AI가 뽑아내는 모든 문장이 **대기업 보고서 수준의 군더더기 없는 명쾌한 비즈니스 언어로 정제**됨.
* **망고독 연결**: 망고독의 **메타데이터 위계(Title ➔ Summary ➔ Key Fact)**가 바로 이 4단 서사를 UI 폼으로 강제하는 장치입니다.
