# (gen)Candidate 04 — '옵시디언 에이전트 시스템' 크라우드 펀딩 소개 페이지 빌딩 챌린지 (와디즈·킥스타터 스토리 & 리워드 스캐폴딩)

> **챌린지 정의**: UI·UX 디자이너(Rin)가 현재 팀에서 구축·운영 중인 **'옵시디언 기반 에이전트 온톨로지 협업 시스템'을 킥스타터(Kickstarter)나 와디즈(Wadiz) 크라우드 펀딩 상품으로 출시한다고 가정**하고, 사내 시스템 규칙과 개발 비하인드 메모를 백데이터로 삼아 **펀딩 상세 스토리, Before/After 비교표, 리워드 패키지 매트릭스**를 조립해보는 네 번째 실무 챌린지.

---

## 1. 챌린지 개요 및 선정 배경 (Why This Project)

1. **"우리가 만든 이 도구를 세상에 펀딩한다면?" (흥미도 극대화)**:
   * 막연한 남의 제품이 아니라, 디자이너와 PM이 직접 쓰고 있는 '개똥이 머릿속 볼트' 시스템을 디지털 템플릿/생산성 패키지 상품으로 기획해보는 매력적인 가상 펀딩 시나리오입니다.
   * 작업자의 주도적인 상상력과 기획적 재미를 자연스럽게 자극합니다.
2. **펀딩 페이지 특유의 엄격한 '시각적 블록' 구조**:
   * 크라우드 펀딩 문서는 단순 줄글이 아니라, **"후킹 헤더 ➔ 고통(Before) vs 구원(After) 대비표 ➔ 핵심 기능 4대 명세 ➔ 리워드 등급표 ➔ 타임라인 로드맵"**이라는 강력한 시각적 공식(Scaffold)을 가집니다.
3. **스토리와 정밀 수치(표)의 결합 난이도 관측**:
   * 감성적인 문제 제기 카피와 엄격한 리워드 가격/구성표를 하나의 흐름으로 엮어야 하므로, 기존 채팅창에 "와디즈 스타일로 써줘"라고 했을 때 어떤 혼선과 서식 깨짐이 일어나는지 관측하기에 이상적입니다.

## 2. 산출물 목표: 크라우드 펀딩 소개 페이지 레이아웃 (Visual Scaffold)

문서의 80%가 **카드, 비교 매트릭스, 리워드 표, 로드맵 그리드**로 규격화됩니다.

```text
┌────────────────────────────────────────────────────────┐
│ [헤더 프로젝트 카드] 슬로건, 펀딩 목표, 타깃 페르소나 배지 │
├────────────────────────────────────────────────────────┤
│ [1. Before vs After 비교 매트릭스] (격자 대비 표)       │
│   → 혼자 쓰는 고립된 메모 vs 에이전트와 공존하는 지식베이스│
├────────────────────────────────────────────────────────┤
│ [2. 시스템 4대 핵심 기능 스펙] (기능 제원 표)           │
│   → PARA 구역, 13종 속성, 자동 요약 인박스, 문법 린터    │
├────────────────────────────────────────────────────────┤
│ [3. 리워드 패키지 매트릭스 (Reward Matrix)] (선택 표)   │
│   → 슈퍼얼리버드, 얼리버드, 올인원 패키지 구성 및 가격    │
├────────────────────────────────────────────────────────┤
│ [4. 메이커 스토리 & 펀딩 타임라인 로드맵] (일정 그리드)   │
└────────────────────────────────────────────────────────┘
```

## 3. 작업자에게 지급되는 실제 백데이터 세트 (Raw Data Package)

볼트의 실제 시스템 헌법과 개발 기획 메모:

1. **`CLAUDE.md` & `AGENTS.md` (사내 온톨로지 시스템 정본)**:
   * PARA 4대 구역의 역할, Frontmatter 13종 속성 규격, 에이전트 협업 수칙 원문.
2. **`raw_dev_retrospective.md` (시스템 도입 비하인드 메모)**:
   * "기존 옵시디언은 메모가 쌓여도 다시 안 보게 됨", "AI한테 그냥 정리하라고 하면 파일 다 망가뜨림", "이 시스템 도입 후 문서 정리가 1/5로 줄어듦" 등 생생한 개발자 회고 텍스트.
3. **`ref_successful_funding_samples.md` (생산성 펀딩 성공 사례 카피 모음)**:
   * 와디즈/텀블벅 억대 펀딩을 달성한 노션 템플릿 및 생산성 도구의 대표적인 후킹 카피와 리워드 명세 패턴 모음.

## 4. 작업 진행 및 정지 가이드 (Stop-on-Fatigue Protocol)

작업자는 기존 ChatGPT/Claude 웹 채팅창에 백데이터를 넣고, **"이 자료들을 바탕으로 와디즈 펀딩 상세페이지(Before/After 표, 4대 기능 명세, 리워드 구성표)를 만들어줘"**라고 요청해 봅니다.

결과물을 완벽히 뽑으려고 애쓸 필요가 전혀 없습니다.

> **🛑 즉시 정지 기준 (Stop Threshold)**:  
> 감성적인 스토리와 딱딱한 리워드 표를 엮는 과정에서 **"작업이 너무 복잡해서 피로하다"**, 혹은 **"원하는 대로 표나 리워드 구성이 정렬되지 않아 너무 불편하다"**고 느껴지는 순간이 오면, **그 즉시 작업을 멈추십시오.**

* 10분을 시도했든, 3분을 시도했든 아무 상관 없습니다.
* 펀딩 페이지의 핵심인 '표와 카드의 정교한 서식'을 챗창에서 유지하려다 지치는 순간, 그 피로감과 손이 멈춘 이유를 솔직하게 공유하면 그것으로 온보딩은 온전히 달성됩니다.
