## 1. 개요: 왜 대중적 AI 서비스들은 사업계획서 작성에서 무너지는가?

2026년 현재 수많은 사용자들이 "검색과 문서 작성을 대신해 준다"는 버티컬 AI 도구들을 사용하고 있다. 그러나 **"10장~50장짜리 전문 사업계획서, 투자 제안서, 전략 보고서"**를 작성하려 할 때, 이 도구들은 일제히 구조적 한계를 드러낸다.

본 조사는 대표적인 4대 버티컬 서비스(**Genspark, NotebookLM, Perplexity, Manus**)를 10장짜리 사업계획서 작성 시나리오에 직접 투입하여 도출된 실측 한계를 분석한다.

## 3. 서비스별 상세 분석

### 🔍 1. 젠스파크 (Genspark)의 Sparkpage 한계: '그럴듯한 요약'과 '엉망인 슬롯'
* **현장 실태**:
  - 젠스파크는 복수의 소스를 교차 검증하는 MoA(Mixture of Agents)를 표방하지만, 10장 이상의 긴 문서를 요구할 경우 **앞서 정의한 고유 가치 제안(UVP)을 뒤쪽 시장 분석에서 잊어버리는 치명적인 현상**이 발생함.
  - 특히 스타트업 투자 제안서의 핵심인 시장 규모(TAM/SAM/SOM)나 경쟁사 비교 표를 작성할 때, **존재하지 않는 2차 출처 데이터를 짜깁기하여 그럴듯하게 포장하는 환각(Plausible-sounding hallucination)**이 빈번함.
* **사용자 행동**:
  - 결국 사용자는 젠스파크가 생성한 Sparkpage를 그대로 발표할 수 없어, 본문의 모든 수치를 구글링으로 재검증하는 **"이중 노가다"**를 겪음.

### 🔍 2. 구글 노트북LM (NotebookLM)의 한계: '소스 요약기'이지 '문서 작성기'가 아니다
* **현장 실태**:
  - 업로드된 문서(최대 50~600개)에 대해서는 환각이 적고 출처를 정확히 가리키는 강력한 장점이 있음.
  - 그러나 노트북LM은 어디까지나 **'질의응답 및 요약기(Q&A & Summarizer)'**일 뿐, **'문서 스캐폴딩 엔진(Scaffolding Engine)'**이 아님.
  - 창업자가 *"과거에 통과된 사업계획서 족보 양식(H1~H3, 슬롯 규칙, 톤앤매너)을 그대로 복제하고, 업로드된 5개 시장 리포트에서 데이터만 뽑아서 각 슬롯에 채워 넣어라"*라는 지시를 내릴 수 없음.
  - 결과물은 항상 챗봇의 단답형 요약문이거나 개괄적인 가이드 노트 수준에 머묾.
* **공간적 결함**:
  - 2D 캔버스처럼 참고 자료를 좌측에 펼쳐놓고, 중앙에 뼈대를 세우며, 우측에 에디터를 두는 **"비선형 작업 공간(Non-linear Workspace)"**이 전무하여 인지 부하를 해소하지 못함.

### 🔍 3. 퍼플렉시티 프로 (Perplexity Pages): 1차원 나열의 덫
* **현장 실태**:
  - 웹 검색 기반의 리포트 생성은 빠르나, 생성된 문서는 전형적인 1차원 블로그 글 형태에 불과함.
  - 사업계획서처럼 **"문제 정의 ➔ 솔루션 ➔ 비즈니스 모델 ➔ 재무 계획"**으로 이어지는 끈끈한 인과 관계를 유지하지 못하고, 각 챕터가 독립적인 백과사전 항목처럼 겉돌게 됨.

### 🔍 4. 마누스 (Manus): 통제 불가능한 자율성의 공포
* **현장 실태**:
  - 에이전트가 백그라운드에서 브라우저를 띄우고 문서를 작성하지만, 사용자가 작성 중간에 실시간으로 개입하거나 피드백을 줄 수 없음.
  - 10분 동안 기다려 받은 사업계획서가 사용자의 의도와 다른 방향으로 전개되어 있을 경우, **수정 프롬프트를 넣는 것보다 사용자가 문서를 직접 타이핑하는 것이 훨씬 빠름.**

## 4. 실태 조사 결론: 기존 대안들의 '치명적 공백 (The Unserved Void)'

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                             기존 대안들의 포지셔닝                          │
│                                                                             │
│      [높은 자율성, 통제 불능]  ◀─── Manus / Genspark                        │
│                                                                             │
│      [강력한 소스 그라운딩, 양식 스캐폴딩 불가] ◀─── NotebookLM             │
│                                                                             │
│      [단순 1차원 검색 요약, 인과 논리 부재] ◀─── Perplexity Pages           │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                    ★ 시장에 존재하지 않는 공백 영역 (우리 제품)              │
│                                                                             │
│  "레퍼런스 문서(족보)의 슬롯을 역공학하여 뼈대를 완벽히 고정하고(Anchor),     │
│   자료를 아무리 추가해도 사업 컨셉이 1도 흔들리지 않으며(Zero-Drift),        │
│   2D 캔버스에서 물리적 원본 좌표로 100% 실측 검증하는 전용 Workspace"       │
└─────────────────────────────────────────────────────────────────────────────┘
```

이로써 기존 버티컬 서비스들이 사업계획서 작성이라는 초고난도 지식 노동을 해결하지 못하고 있음이 명백히 실증되었다.
