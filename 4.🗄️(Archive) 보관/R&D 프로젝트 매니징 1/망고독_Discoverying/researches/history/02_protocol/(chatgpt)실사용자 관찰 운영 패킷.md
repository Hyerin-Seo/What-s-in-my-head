# 실사용자 관찰 운영 패킷

> 상태: **준비됨, 미실행.** 이 문서는 참여자 섭외를 승인받은 뒤에만 사용한다. 현재 P01~P12는 빈 자리이며, 발화·화면·문서를 만들어 내거나 외부에 연락하지 않는다.

## 1. 모집 쿼터와 포함 기준

| 코호트 | 목표 | 반드시 서로 달라야 할 조건 | 포함 기준 | 제외 기준 |
| --- | ---: | --- | --- | --- |
| 외부 심사·승인 문서 작성자 | 4명 | 최소 2개 조직/업종, AI 사용·비사용 모두 포함 | 최근 60일 내 제안/지원/입찰/규제 문서를 실제 작성 또는 최종 검토 | 제품 의견만 있고 최근 사례·비식별 설명이 없음 |
| 조직 내 전략·리서치 문서 작성자 | 4명 | 최소 2개 조직, 자료 형식 2종 이상 | 여러 출처를 결합해 의사결정/보고 문서를 만든 최근 사례 | 단순 회의록·개인 메모만 있음 |
| AI 워크플로우 파워 유저 | 4명 | 최소 3개 서로 다른 도구 조합 | AI/자동화를 사용해 여러 참고자료 기반 문서를 만든 최근 사례 | 데모·프롬프트 의견만 있고 실제 산출 흐름 없음 |

- 같은 회사·지인·커뮤니티에서 2명 이상이 오면 `편향`으로 표기하고 다른 채널을 먼저 보충한다.
- 목표 수는 통계적 유의성을 뜻하지 않는다. 같은 문제의 반복과 **현재 도구로 충분한 반례**를 찾기 위한 목적 표집이다.
- 모집 채널·보상·개인정보 처리 주체는 외부 연락 승인 시 확정한다. 임의의 보상이나 개인정보 수집을 제안하지 않는다.

## 2. 참여 전 안내 및 동의 문안

아래 문안은 실제 연락/세션에서만 사용한다.

> 이 대화는 최근 실제 문서 작업이 어떻게 진행됐는지 이해하기 위한 내부 제품 조사입니다. 제품을 판매하거나 업무 능력을 평가하지 않습니다. 비밀·개인·고객 정보가 보이는 화면이나 원문은 공유하지 않아도 되며, 필요하면 이름·금액·기관명 등을 가린 예시 또는 말로 설명하는 방식으로 진행할 수 있습니다. 녹음·화면 녹화는 별도 선택 동의가 있을 때만 합니다. 참여자는 질문을 건너뛰거나 언제든 중단할 수 있습니다. 연구 노트에는 P01 같은 익명 ID와 비식별 관찰만 남깁니다.

세션 시작 전에 아래를 각각 확인한다.

| 확인 항목 | 허용 / 거절 / 해당 없음 | 기록 위치 |
| --- | --- | --- |
| 최근 실제 작업을 비식별 방식으로 설명할 수 있음 |  | `03_raw/Pxx/consent.md`의 상태만 기록 |
| 화면 공유를 허용함 |  | 범위·시간을 기록, 캡처는 기본 금지 |
| 음성 녹음을 허용함 |  | 별도 선택; 거절하면 상세 메모만 |
| 비식별 스크린샷/발췌 보관을 허용함 |  | 파일명·삭제 요청 경로를 기록 |
| 후속 과업/파일럿 연락을 허용함 |  | 조사와 분리하여 별도 선택 |

`실명·전화번호·이메일·회사명·고객명·계정명·원문 파일`은 이 볼트에 적지 않는다. 동의 거절은 이유를 캐묻지 않고 `거절`만 기록한다.

## 3. 세션 운영과 증거 체인

| 단계 | 조사자 행동 | 남기는 자료 | 금지 |
| --- | --- | --- | --- |
| 시작 5분 | 동의 범위, 중단권, 비식별 방식을 재확인 | `consent.md`의 상태 | 제품 화면·가격·Canvas 선제시 |
| 문제 회고 20분 | 최근 사례의 시작→제출 시간선을 질문 | `timeline.md`: 시각/행동/도구/문서 수/실패 | 의견을 사실처럼 요약 |
| 화면·문서 관찰 15분 | 허용 범위에서만 자료·도구 전환·수정 행동 확인 | `observation.md`: 관찰/참가자 발화/제한 | 무단 녹화·캡처·파일 저장 |
| 대안·비용 10분 | 이미 쓴 도구와 우회, 시간·위험·협업 비용 질문 | `alternatives.md` | “우리 제품이면 해결” 유도 |
| 종료 5분 | 빠진 사실·동의 철회·후속 가능 여부 확인 | `closeout.md` | WTP/가격을 먼저 묻기 |

Evidence Matrix에는 다음 연결이 없는 참가자 문장을 넣지 않는다.

`Evidence ID → Pxx → 원자료 위치/시각 → 관찰 사실 → 해석 → 반대 사례 → 신뢰도 → 결정 영향`

## 5. 중단·삭제·에스컬레이션 규칙

- 화면에 비식별 전환이 어려운 민감 정보가 보이면 즉시 공유를 멈추고 말로 설명하는 방식으로 바꾼다.
- 참가자가 녹화/보관 범위를 바꾸거나 철회를 요청하면, 해당 원자료의 접근을 중단하고 Evidence Matrix 상태를 `확인 불가`로 바꾼다.
- 동의 없이 남은 정보, 비식별 실패, 이해관계 충돌이 생기면 PM/조사 책임자에게 넘기고 해당 세션을 결론 근거에서 제외한다.
- 같은 코호트에서 현재 도구로 충분하다는 사례가 2건 이상이면, 제품 필요성을 약화시키는 반대 증거로 먼저 종합한다.

## 6. 외부 접촉 승인 전 체크

- [ ] 개인정보를 받을 주체·보관 장소·삭제 절차가 정해짐
- [ ] 보상/일정/담당자가 확정됨
- [ ] 제품 설명 없는 첫 연락 문안이 검토됨
- [ ] P01~P12 빈 자리에 실제 수락/거절만 기록할 준비가 됨
