# 02. Workflowy MCP 도구 명세 및 기능 가이드

Workflowy 데스크톱 앱은 공식적으로 **MCP(Model Context Protocol)** 서버를 내장하고 있습니다. 별도의 외부 프록시나 복잡한 클라우드 인증 없이, 로컬 데스크톱 프로세스가 직접 JSON-RPC 2.0 및 SSE 기반 엔드포인트를 열어 AI Agent와 양방향 통신을 지원합니다.

---

## 1. 아키텍처 및 연결 규격

* **연결 방식**: 데스크톱 앱 내장 SSE / HTTP POST (JSON-RPC 2.0)
* **엔드포인트 포맷**: `http://127.0.0.1:<포트>/mcp/<시크릿토큰>`
* **응답 특성**:
  * 트리 탐색(`tree_seek`) 결과는 `result.structuredContent.results` 배열에 포맷팅된 문자열로 반환됩니다.
  * 오류 발생 시 JSON-RPC 표준 error 객체(`code`, `message`, `data`)를 반환합니다.
* **노드 식별자**: 각 노드는 12자리의 고유 16진수 해시 문자열(예: `113247151ada`, `369293435670`)을 가집니다.

---

## 2. 제공 도구(Tool) 13종 상세 명세

Workflowy MCP 서버는 트리의 탐색, 편집, 동시성 잠금(Lease), 사용자 UI 피드백, 첨부파일, 자동 업데이트 등 총 13종의 도구를 제공합니다.

### A. 트리 탐색 및 시점 제어 (2종)

#### 1. `tree_seek` (트리 탐색 및 검색)
* **역할**: 트리의 특정 지점부터 상향 또는 하향으로 노드를 재귀적으로 탐색하고 검색합니다.
* **주요 파라미터**:
  * `start_from`: 탐색 시작 노드 (`root`, `inbox`, `zoomed`, `calendar`, `last_active` 또는 12자리 노드 ID)
  * `direction`: 탐색 방향 (`downward-deep`: 하향 깊이 우선 탐색, `upward`: 조상 방향 탐색)
  * `limit`: 최대 조회 노드 개수 (기본 100)
  * `truncate_text_at`: 노드 텍스트 생략 길이 (기본 50자)
  * `filter`: 세부 필터링 조건
    * `text_contains_any`: 특정 문자열 포함 여부
    * `text_matches_any`: 자바스크립트 정규식 매칭
    * `block_format_is_any`: 포맷 필터 (`todo`, `bullets`, `p`, `code-block`, `quote-block`)
    * `child_count_gte` / `child_count_lte`: 자식 노드 개수 조건
    * `completed_after` / `completed_before`: 완료 처리 시각 조건
* **결과 포맷**:
  ```text
  [<handle>]<·*depth><block_format> <text>
                     <child_count>:<deep_count>:<matches_inside>
  ```

#### 2. `tree_zoom` (클라이언트 화면 시점 이동)
* **역할**: 사용자 화면의 Workflowy 클라이언트를 특정 노드로 줌인(Zoom-in) 이동시킵니다.
* **주요 파라미터**:
  * `tree_item_target`: 이동할 대상 (`root`, `inbox`, `zoomed`, `calendar`, `last_active` 또는 노드 ID)

---

### B. 트리 편집 및 변동 (1종)

#### 3. `tree_patch` (원자적 트리 수정 및 생성)
* **역할**: 트리에 노드를 추가, 수정, 이동, 완료, 삭제하는 핵심 뮤테이션 도구입니다. 복수 작업을 트랜잭션 단위로 한 번에 처리합니다.
* **지원 연산(Requests)**:
  * `insert_after` / `insert_before`: 특정 노드의 앞/뒤에 새 노드 생성
  * `inside`: 특정 노드의 자식으로 삽입할지 여부 (`true` / `false`)
  * `replace`: 특정 노드의 텍스트 내용 교체
  * `complete` / `uncomplete`: 체크리스트 완료 및 완료 해제
  * `comment_on`: 특정 노드에 주석/메모 추가
  * `move` & `under`: 특정 노드들을 지정한 부모 노드 아래로 이동
  * `delete`: 노드 삭제 (`recursively` 옵션 지원)
* **텍스트 서식 지원**:
  * 인라인 HTML: `<b>`, `<i>`, `<u>`, `<s>`, `<code>`, `<a href="...">`
  * 날짜 태그: `<time startYear="2026" startMonth="10" startDay="7">`
  * 컬러 태그: `<span class="colored c-COLOR">`
  * 해시태그(`#tag`) 및 멘션(`@mention`)

---

### C. 동시성 제어 및 락 (Leases) (4종)

AI Agent와 사용자가 동시에 동일한 노드를 편집하다가 내용이 유실되는 충돌(Race Condition)을 방지하기 위한 임대(Lease) 시스템입니다.

#### 4. `lease_acquire` (임대 락 획득)
* 대상 노드 ID들에 대해 지정된 유효시간(TTL, 30초~3600초) 동안 독점 작업 토큰(UUID)을 획득합니다.

#### 5. `lease_touch` (임대 갱신)
* 장시간 작업 시 보유한 임대 토큰의 만료 시간을 연장합니다.

#### 6. `lease_release` (임대 반환)
* 작업이 끝난 후 임대 락을 즉시 해제합니다.

#### 7. `lease_inspect` (임대 상태 점검)
* 특정 노드가 현재 다른 작업자에 의해 임대 중인지와 남은 수명을 확인합니다.

---

### D. 사용자 UI 피드백 (1종)

#### 8. `message_success` (완료 토스트 알림)
* **역할**: 사용자 데스크톱 앱 화면 하단에 성공 토스트(Toast) 팝업을 띄웁니다.
* **용도**: 에이전트가 긴 작업이나 트리 정리를 마쳤을 때 사용자에게 작업 완료를 시각적으로 전달합니다.

---

### E. 첨부파일 제어 (2종)

#### 9. `attachments_pull` (첨부파일 다운로드)
* 노드에 포함된 이미지/파일을 로컬 캐시 디렉터리로 다운로드하고 로컬 절대 경로를 반환합니다.

#### 10. `attachments_attach` (파일 첨부)
* 로컬 파일을 특정 노드에 첨부물로 업로드하여 연결합니다.

---

### F. 데스크톱 자동 업데이트 제어 (3종)

#### 11. `auto_update_status`
* 현재 설치된 WorkFlowy 데스크톱 버전 및 업데이트 다운로드 진행 상태를 조회합니다.

#### 12. `auto_update_check`
* 공식 업데이트 서버를 즉시 확인하고 사용 가능한 업데이트를 다운로드합니다.

#### 13. `auto_update_install`
* 다운로드된 최신 업데이트를 설치 적용합니다.

---

## 3. AI Agent 권장 작업 프로토콜

1. **상태 파악 (Read)**:
   * `tree_seek`로 대상 영역(`zoomed` 또는 특정 프로젝트 노드 ID)의 자식 노드들을 탐색하여 구조 파악.
2. **동시성 확보 (Lock - 선택 사항)**:
   * 대규모 변경 시 `lease_acquire`로 해당 노드 ID 락 획득.
3. **원자적 변경 (Write)**:
   * `tree_patch`로 하위 브랜치 생성, 본문 수정, 순서 재배치를 한 번의 요청으로 실행.
4. **시각적 보고 (Feedback)**:
   * `message_success`를 호출하여 사용자 화면에 "작업 완료" 토스트를 띄우고, 채팅창에 최종 요약 보고.
