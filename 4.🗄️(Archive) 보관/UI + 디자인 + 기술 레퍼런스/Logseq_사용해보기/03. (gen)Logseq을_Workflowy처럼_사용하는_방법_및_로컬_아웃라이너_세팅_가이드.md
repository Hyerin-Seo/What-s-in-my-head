# 03. Logseq을 Workflowy처럼 사용하는 방법 — 온톨로지를 걷어낸 로컬 아웃라이너 가이드

Logseq의 양방향 지식 그래프, Datalog 쿼리, RDF 온톨로지 구조는 강력하지만 **개인 사용자가 매일 관리하기에는 데이터 구조화 비용(인지 부하)이 지나치게 큽니다.**

본 문서는 이러한 복잡한 기능을 일체 배제하고, Logseq을 **“클라우드 종속이 없는 내 컴퓨터 로컬 마크다운(`.md`) 기반의 순수 Workflowy”**로 활용하는 구체적인 세팅과 운영 가이드를 정리합니다.

---

## 1. 운영의 3대 절대 원칙 (Do's & Don'ts)

| 구분 | ❌ 하지 않는 것 (Don'ts) | ⭕ 하는 것 (Do's) |
| :--- | :--- | :--- |
| **작성 방식** | 매일 저널(일기장)에 파편 메모 던지기 ❌ | **소수의 고정 페이지(Home 등)에서 트리 확장** ⭕ |
| **메타데이터** | 복잡한 태그(`#`), 속성(`key:: value`) 관리 ❌ | **오직 텍스트 불릿과 들여쓰기 위계만 사용** ⭕ |
| **블록 참조** | `((UUID))` 블록 링크 남발 ❌ (파일에 `id::` 메타 생성 방지) | **순수 마크다운 목록(`- `) 형태 보존** ⭕ |
| **분석/조회** | 그래프 뷰, Datalog 쿼리문 작성 ❌ | **불릿 클릭 줌인/줌아웃(Zoom-in / Out)** ⭕ |

---

## 2. Logseq 환경 세팅 (Workflowy 모드 전환)

### ① 시작 화면을 '저널'에서 '단일 트리(Home)'로 변경
Logseq은 기본적으로 오늘 날짜 저널을 첫 화면으로 띄웁니다. 이를 Workflowy의 최상위 홈(Home) 화면처럼 변경합니다.

* **방법**:
  1. `Home`이라는 새 페이지를 하나 생성합니다.
  2. 좌측 사이드바 상단의 즐겨찾기(Favorites)에 `Home`을 등록합니다.
  3. 설정(`Settings` → `General`) 또는 그래프 루트의 `logseq/config.edn` 파일에서 기본 홈 페이지를 지정합니다:
     ```clojure
     ;; config.edn 설정 예시
     :default-home {:page "Home"}
     ```
  4. (선택 사항) 저널이 아예 필요 없다면 설정에서 저널을 비활성화할 수 있습니다:
     ```clojure
     :journals-directory nil
     ```

### ② 불릿 가이드라인 및 줌(Zoom) 인터랙션 확인
* `Settings` → `Editor`에서 **들여쓰기 가이드라인(Indent Guide)**을 활성화하면 상하 계층선이 시각적으로 명확해집니다.
* 불릿 점을 클릭했을 때 즉시 해당 블록이 전체 화면 제목으로 승격되는 **줌인(Zoom-in)** 동작을 기본 네비게이션으로 사용합니다.

### ③ 페이지 하단 '잡음' 접어두기
* Logseq 페이지 하단에 자동으로 뜨는 `Linked References`나 `Unlinked References` 섹션은 헤더 우측의 접기 버튼(`▼`)을 눌러 완전히 숨겨둡니다. 
* 화면에 오직 **내가 작성한 불릿 트리만 순수하게 표시**되도록 만듭니다.

---

## 3. 실전 워크플로우: 단일 무한 트리 구성

최상위 `Home.md` 페이지 안에 내 모든 업무와 생각을 단 4~5개의 루트 불릿으로 시작합니다.

```text
• [Home]
	• 🎯 활성 프로젝트
		• Scaffold Engine 설계
			• 1단계 앵글 정의
			• 2단계 뼈대 생성 파이프라인
		• 인프라 최적화
	• 📥 인박스 (생각나는 것 아무거나 적기)
		• redis 캐시 벤치마크 확인 필요
		• 다음 주 미팅 안건 메모
	• 📚 자료 및 리소스
		• 토스닥터 빌더 분석
		• 아웃라이너 패턴 정리
	• 🗄️ 아카이브 (완료된 프로젝트)
```

### 작업 방식:
1. **생각 뼈대 잡기**: `Enter`로 줄을 만들고, `Tab`으로 들여쓰며 아이디어를 하위로 쪼갭니다.
2. **몰입 집중 (Zoom-in)**: `Scaffold Engine 설계` 불릿을 클릭하면 화면 전체가 그 프로젝트로 가득 차며 주변 잡음이 사라집니다.
3. **상위 복귀 (Breadcrumbs)**: 화면 상단 경로(Breadcrumb)의 `Home`을 클릭하면 즉시 최상위 전체 조감도로 복귀합니다.
4. **작업 완료**: `Ctrl + Enter`를 누르면 `TODO` ↔ `DONE` 체크박스로 토글되거나 줄긋기(취소선) 처리가 됩니다.

## 4. 핵심 단축키 치트시트 (키보드 100% 조작)

마우스 없이 생각의 속도로 트리를 재배치하는 핵심 단축키입니다.

| 기능 | Windows 단축키 | 설명 |
| :--- | :--- | :--- |
| **하위 들여쓰기** | `Tab` | 현재 블록을 상위 블록의 자식으로 한 단계 넣기 |
| **상위 내어쓰기** | `Shift + Tab` | 현재 블록을 부모 계층 밖으로 한 단계 꺼내기 |
| **블록 위/아래 이동** | `Alt + ↑` / `Alt + ↓` | 현재 블록(및 모든 자식)의 순서를 위아래로 이동 |
| **줌인 (Zoom-in)** | `Alt + →` (또는 불릿 클릭) | 선택한 블록의 내부로 집중 진입 |
| **줌아웃 (Zoom-out)** | `Alt + ←` (또는 상단 경로 클릭) | 상위 블록/홈으로 빠져나오기 |
| **블록 접기 / 펴기** | `Ctrl + ↑` / `Ctrl + ↓` | 하위 자식 노드들을 접거나 펼치기 |
| **칸반 뷰 전환** | 블록 우클릭 → `View as Kanban` | 1단계 자식이 컬럼, 2단계 자식이 카드로 즉시 전환 |

---

## 5. 이렇게 썼을 때 얻는 실익

1. **100% 로컬 파일 소유권 & 영속성**:
   * Workflowy처럼 서버 장애나 서비스 종료를 걱정할 필요가 없습니다.
   * 내 컴퓨터 디스크에 평범한 `.md` 파일로 보관되므로 Git으로 버전 관리를 자유롭게 할 수 있습니다.
2. **인지 부하 제로 (Zero Cognitive Overhead)**:
   * 온톨로지, 태그 규칙, Datalog 쿼리 문법을 전혀 공부할 필요가 없습니다.
   * 생각의 뼈대를 엔터/탭으로 1초 만에 위계화하는 순수 '생각의 스케치북'으로만 동작합니다.
3. **완벽한 마크다운 호환성**:
   * 복잡한 블록 참조 메타데이터를 쓰지 않으므로, 파일 내부에는 순수 `- ` 들여쓰기 마크다운만 남습니다.
   * 필요할 때 옵시디언, VS Code, 메모장 등 어떤 에디터로 열어도 서식이 100% 깨끗하게 유지됩니다.
