## 어떤 이유로 중요하다고 생각하시나요?

- 스토리 작업에서 ‘어휘력, 용어’ = ‘실력, 필력’ = ‘표현력’
- ‘어휘집’을 바탕으로 나와의 대화를 LLM이 더 최적화할 수 있음(내 단어 = 내 생각)
- 자료 조사(검색) or AI 작업을 압축, 축약해서 전달 가능 = ‘비용 감소 + 정확한 작업 수행’
