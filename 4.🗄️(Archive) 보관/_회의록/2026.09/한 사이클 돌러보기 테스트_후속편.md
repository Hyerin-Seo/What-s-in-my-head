## ⏮ 지난 회의 점검

![[한 사이클 돌러보기 테스트_후속편 — 지난 회의 점검]]

```base
filters:
  and:
    - note["유형"] == "할일"
    - note["주제"].contains("회의 할 일")
    - not:
        - file.hasLink(this.file)
views:
  - type: table
    name: ⏳ 아직 안 된 회의 할 일
    filters:
      and:
        - note["상태"] != "완료"
        - note["상태"] != "히스토리"
    order:
      - file
      - 상태
      - 담당
      - 마감
      - 상위
    sort:
      - property: 마감
        direction: ASC
  - type: table
    name: 🔴 마감 지남
    filters:
      and:
        - note["상태"] != "완료"
        - note["상태"] != "히스토리"
        - note["마감"] < today()
    order:
      - file
      - 상태
      - 담당
      - 마감
      - 상위
```

■ 한 바퀴 — AI 가 70~80%, 사람이 마무리
  회의 전   에이전트에게 "지난 회의 점검해줘"
            → 맨 위 `⏮ 지난 회의 점검` 에 표가 뜹니다: ✅ 됨 · 🔄 진행 중 · ⏳ 안 됨 · ❓ 끈 없음 · 🔁 몇 번째 밀림
            → 사람은 ❓ 줄만 봅니다. 체크 = 이제 안 따라와도 됨 (됐거나 버림)
            → 🚨 는 3번 넘게 밀린 것 — 버릴지 쪼갤지 이번 회의에서 정합니다
  회의 중   `속기` 만 씁니다. 정리하지 말고 들리는 대로
  회의 뒤   에이전트에게 "이 회의록 정리해줘"
            → 99 작업 공간이 만들어지고, 논의할 안건이 카드로 `A1.collection/검토 중` 에 뜹니다
            → 단순 할 일 · 연락 · 정한 것은 카드 대신 작업 기억의 `카드 아님` 목록에 한 줄씩
            → `🥸 작업 공간` 칸의 작업 기억에서 둘 다 봅니다
  고르기    쓸 만한 카드를 `A5.outputs` 로 끌어 옮깁니다 (pick)
            남은 것이 아쉬우면 "다시 뽑아줘" — 에이전트가 스킬 사본을 고쳐 다시 뽑고, 튜닝 기록을 남깁니다
  올리기    A5 에서 실행할 것만 **사람 말로** 인박스에 씁니다
            `📊 회의 할 일` 보드의 `+ 새 항목` → `📝 회의록 인박스` 에 회의 할 일 양식으로 만들어집니다
            `상위` 에 이 회의록, `링크` 에 A5 카드 — 이 끈이 있어야 다음 회의 점검에 돌아옵니다
