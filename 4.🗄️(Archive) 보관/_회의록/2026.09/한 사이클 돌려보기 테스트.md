## ⏮ 지난 회의 점검

![[한 사이클 돌려보기 테스트 — 지난 회의 점검]]

```base
filters:
  and:
    - note["유형"] == "할일"
    - note["주제"].contains("회의 할 일")
    - not:
        - file.hasLink(this.file)
views:
  - type: table
    name: ⏳ 아직 안 된 회의 할 일
    filters:
      and:
        - note["상태"] != "완료"
        - note["상태"] != "히스토리"
    order:
      - file
      - 상태
      - 담당
      - 마감
      - 상위
    sort:
      - property: 마감
        direction: ASC
  - type: table
    name: 🔴 마감 지남
    filters:
      and:
        - note["상태"] != "완료"
        - note["상태"] != "히스토리"
        - note["마감"] < today()
    order:
      - file
      - 상태
      - 담당
      - 마감
      - 상위
```

## 속기

- 아, 그러면 오늘 회의는 일단 크게 두 가지 안건부터 짚고 넘어갑시다. 첫 번째가 지금 진행 중인 회의록 자동화 시스템 파이프라인 현황이고, 두 번째가 그 옵시디언 기반으로 지식베이스랑 PARA 구조 연동해 둔 거 현재 상태 체크하는 거. 네가 먼저 전반적인 진행 상황 브리핑해 줄래?

오케이. 일단 회의록 자동화 쪽부터 말하면, 지금 음성 녹음 파일 들어오면 위스퍼 모델 거쳐서 텍스트로 뽑아내는 것까지는 로컬에서 테스트 완치했거든? 근데 문제는 그 다음이야. 이걸 그냥 텍스트 덩어리로 두니까 나중에 검색하거나 요약할 때 개판 되더라고. 그래서 엘엘엠 API 붙여서 자동으로 핵심 키워드 뽑고 구조화된 마크다운으로 뱉어주는 파이프라인을 짜야 되는데, 그 프롬프트 엔지니어링 쪽에서 지금 토큰이 자꾸 터지거나 포맷이 깨지는 이슈가 좀 있음.

아, 토큰 제한 걸리는 거? 그거 텍스트 덩어리째로 한 번에 넣어서 그런 거 아니야? 스크립트 길어지면 당연히 오버되지. 그거 청크 단위로 잘라서 요약한 다음에 최종 취합하는 방식으로 스크립트 수정해야 될 것 같은데. 내가 그 파이프라인 구조 도식화해 둔 거 있잖아, 그거 이따 공유해 줄게. 프론트 쪽에서 UI로 실시간 상태 확인하는 건 내가 붙여놓을 테니까, 너는 파이프라인 에러 핸들링이랑 프롬프트 최적화 쪽 좀 더 파줘.

오, 그 청크 분할 방식 좋네. 알겠어. 그 부분은 내가 오늘 내로 정규식 짜서 문단 단위로 끊기게 스크립트 수정해 볼게. 그리고 두 번째 안건인 옵시디언 구축 현황 말인데... 이거 생각보다 정리가 안 된다? 네가 전에 추천해 준 파라 구조(프로젝트, 에어리어스, 리소스, 아카이브)로 폴더링까지는 다 갈아엎었거든? 근데 막상 노트를 쌓으려니까 데일리 노트랑 프로젝트 노트가 자꾸 꼬여. 어디에다 짱박아야 될지 애매한 자료들이 너무 많아.

아, 그건 당연히 처음엔 헷갈리지. 나도 처음엔 그랬으니까. 핵심은 지금 당장 실행 중인 액션이 있냐 없냐야. 액션이 있으면 프로젝트, 그냥 계속 관리해야 되는 영역이면 에어리어스, 단순 참고용 자료면 리소스. 이거 기준으로 분류 안 하고 그냥 귀찮아서 다 리소스에 처박으니까 악순환 생기는 거라고. 내가 만들어 둔 템플릿이랑 링크 연결 규칙 문서 가이드라인 공유해 줬잖아, 안 봤지?

봤지, 봤는데 막상 현업에 적용하려니까 손이 안 갔지... 근데 네가 말한 대로 프로젝트 단위로 데일리 노트랑 백링크 걸어두니까, 나중에 연관 검색할 때는 진짜 편하긴 하더라. 특히 회의록 마크다운으로 떨궈서 옵시디언 볼트로 바로 싱크시키는 거, 이거 루틴화만 되면 진짜 일 개 빨라질 것 같아.

그지? 그게 핵심이야. 우리가 지금 회의록 자동화 시스템 만드는 이유도 결국 그 노가다 줄이려고 하는 거니까. 옵시디언이랑 연동되는 자동화 스크립트 뼈대는 내가 어느 정도 잡아놨으니까, 거기 네가 쓰는 태그 시스템이랑 메타데이터 포맷만 맞추면 돼.

오케이, 그럼 업무 분장 이렇게 깔끔하게 나누자. 나는 오늘 남은 시간 동안 1번 안건인 회의록 자동화 엘엘엠 파이프라인 프롬프트 안정화랑 청크 분할 스크립트 수정 끝내고, 2번 옵시디언 쪽은 네가 준 가이드라인 참고해서 우리 팀 공용 볼트 메타데이터 포맷 통일하는 걸로 할게.

좋아. 그리고 너 그 마크다운 포맷 맞출 때 프론트엔드에서 렌더링 깨지는 거 없는지도 같이 체크해 줘야 된다? 나중에 UI에서 글자 깨지면 또 수정해야 되니까.

알았어, 그건 당연하지. 그럼 일단 각자 파트 작업 들어가고, 막히는 거 있으면 슬랙으로 바로 콜하자. 이따 점심 먹고 오후 2시에 다시 중간 싱크 한 번 더 해.

오케이, 고고.
