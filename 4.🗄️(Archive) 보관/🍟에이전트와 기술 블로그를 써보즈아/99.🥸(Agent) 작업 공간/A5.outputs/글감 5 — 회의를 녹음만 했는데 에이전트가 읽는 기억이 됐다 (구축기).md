# 글감 5 — 회의를 녹음만 했는데 에이전트가 읽는 기억이 됐다 (구축기)

| | |
| --- | --- |
| **독자** | 옵시디언이나 노션에 회의록을 쌓고 있고, 에이전트에게 읽히고 싶은 사람 |
| **가져갈 것** | 녹음 → 전사 → 카드 → 날짜 폴더까지의 순서와, 사람이 손대는 곳이 어디인지 |
| **한 줄 주장** | 회의록을 세컨드 브레인으로 만드는 일의 대부분은 에이전트가 하고, 사람은 고르기만 한다 |

## "어쩌라고?" 에 대한 답

같은 것을 만들고 싶다면 무엇을 어떤 순서로 두면 되는지. 그리고 만들어 두면 어떤 순간이 오는지(캡처 2).

## 가제

- 회의록 자동 구축해서 세컨드 브레인으로 쓰기 — 녹음만 하면 에이전트가 읽는 기억이 된다
- 15분 회의가 에이전트의 기억이 되기까지

## 목차

```
결과부터         에이전트가 회의 발화를 시각과 함께 꺼내 와 방향을 잡았다 (캡처 1 · 2)
이게 되려면       회의가 이런 모양으로 쌓여 있어야 한다 — 폴더 그림 한 장
① 녹음과 전사      사람은 녹음만. 전사는 발화자 번호와 시각으로
② 카드로 쪼개기    안 정한 것은 안건 카드, 정한 것은 결정 카드 — 스킬이 뽑는다
③ 사람이 고른다    에이전트가 깔고 사람이 고른다 — 09.29 회의: 376발화 → 카드 6 → 고름 3
④ 프로젝트로 간다   고른 것만 프로젝트의 회의 날짜 폴더로
⑤ 다음 회의가 묻는다 지난번에 하기로 한 것이 됐나 — 점검표
두 번 갈아엎은 것   처음 방식과 지금 방식, 왜 바꿨나
아직 불편한 것
마무리
```
