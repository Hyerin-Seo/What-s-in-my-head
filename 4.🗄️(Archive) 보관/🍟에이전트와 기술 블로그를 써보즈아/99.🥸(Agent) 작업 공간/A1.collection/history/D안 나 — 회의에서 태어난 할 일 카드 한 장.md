## 1편의 제목과 뼈대

**회의 376발화가 할 일 카드 한 장이 되기까지 — 노트 한 장의 일생 1편**

```
개요          회의가 끝나면 정리가 밀렸다 → 속기만 쓰면 할 일이 되게 할 수 없을까 · 숫자 한 줄 (376발화 → 카드 6 → 고름 3)
지도          이 카드의 일생 (위 표를 그림으로)
스킬          회의 한 바퀴 — Pre → Live → Post → Action → Learn
Before / After   속기만 남던 회의록 ↔ 안건 카드 한 장 (실제 카드)
맡긴 것과 안 맡긴 것  뽑는 것은 에이전트 / 고르고 사람 말로 다시 쓰는 것은 사람
한계          고른 셋은 전부 할 일 후보가 있는 카드였다 · 깨진 링크 하나
언제 스킬로 만들면 좋은가
마무리          다음 편 — 이 카드에 이름표가 붙는다
```

## 쉽고 재밌나

- **진짜 한 장을 따라갑니다.** 레퍼런스의 "예시 하나를 끝까지" 에 가장 가깝습니다. 날짜와 시각까지 있습니다.
- 사람 → 에이전트 → 사람 → 플러그인이 번갈아 손대는 모습이 한 장에 다 나옵니다. 하네스 주제가 안 흐려집니다.
- 지금 이 프로젝트 폴더에 있는 카드라, 글의 끝이 글 자신으로 이어집니다.

## 약점

- 이 카드는 **인박스도 보관도 거치지 않았습니다.** 일생이 여섯 단계가 아니라 다섯이고, 끝이 없습니다.
- 사고가 3편 하나뿐이라 가 안보다 심심한 편이 생깁니다 (2 · 5편).
- 카드 이름과 내용이 사내 프로젝트 이야기입니다. 이름을 바꿔 써야 할 수 있습니다.
