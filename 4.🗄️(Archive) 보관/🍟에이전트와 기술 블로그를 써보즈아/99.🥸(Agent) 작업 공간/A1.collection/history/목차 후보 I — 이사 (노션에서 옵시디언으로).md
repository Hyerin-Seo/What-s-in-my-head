# 후보 I — 이사 (노션에서 옵시디언으로)

> **한 줄**: 이삿짐 목록. 가져온 것 · 두고 온 것 · 와서 새로 산 것.

## 편 목록

| 편 | 가제 | 내용 | 볼트 근거 |
| --- | --- | --- | --- |
| 1 | 왜 짐을 쌌나 | 노션에서 불편했던 것, 옵시디언을 고른 이유 | **문서에 없음 — 사람이 써야 함** |
| 2 | 가져온 것 — PARA 와 데이터베이스 | 네 구역 · 노션 DB 의 속성 → 프론트매터 13종 · 뷰 → 보드(`.base`) | `docs/properties.md` · `docs/boards.md` |
| 3 | 두고 온 것 | 속성 일곱 가지 · 노션 버튼 · 깨진 첨부 19개 | `docs/properties.md` · `docs/known-gaps.md` |
| 4 | 와서 다시 만든 것 | 노션이 해 주던 것을 플러그인으로 — 속성 붙이기 · 칸반 · 상태 칩 · 달력 | `docs/plugins.md` · `docs/project-board.md` |
| 5 | 와서 새로 생긴 것 — 에이전트가 파일을 직접 읽는다 | `CLAUDE.md` · 스킬 · 작업 공간 · git 동기화 | `CLAUDE.md` · `skills/` |
| 6 | 다시 한다면 | 먼저 할 것 · 안 할 것 | 사람이 써야 함 |

## 한 편 안의 소제목 (3편을 예로)

```
개요        옮기고 보니 속성이 스무 개였고 절반은 비어 있었다
한눈에      노션에 있던 것 ↔ 옵시디언에서 한 일 (가져옴 · 버림 · 못 옮김 표)
버린 것     제목 속성 — 310건 중 56건이 파일명과 달랐다
못 옮긴 것   깨진 첨부 19개 — 지금도 그대로
정한 기준    같은 정보를 두 곳에 두지 않는다
아쉬운 것    노션에서 편했던 것 (사람이 써야 함)
마무리      다음 편 — 와서 다시 만든 것
```

- 개요의 "스무 개 · 절반" 은 자리 표시입니다. 없앤 속성 일곱 가지와 `수정일` 이 절반 비어 있었다는 것만 문서에 있습니다. 쓰기 전에 다시 셉니다.

## 잘 맞는 경우

- 읽는 사람이 **노션을 쓰다 옮길까 고민하는 사람**일 때. 검색으로 가장 많이 들어올 주제입니다.
- "노션 ↔ 옵시디언" 대비가 편마다 저절로 생깁니다.
- 5편에서 에이전트 이야기로 자연스럽게 넘어갑니다.
