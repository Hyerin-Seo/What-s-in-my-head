# 2.1 PARA 분류 기준 — 데일리 노트와 애매한 자료의 자리

> **속기 원문**
> - *네가 전에 추천해 준 파라 구조(프로젝트, 에어리어스, 리소스, 아카이브)로 폴더링까지는 다 갈아엎었거든? 근데 막상 노트를 쌓으려니까 데일리 노트랑 프로젝트 노트가 자꾸 꼬여. 어디에다 짱박아야 될지 애매한 자료들이 너무 많아.*
> - *핵심은 지금 당장 실행 중인 액션이 있냐 없냐야. 액션이 있으면 프로젝트, 그냥 계속 관리해야 되는 영역이면 에어리어스, 단순 참고용 자료면 리소스. 이거 기준으로 분류 안 하고 그냥 귀찮아서 다 리소스에 처박으니까 악순환 생기는 거라고.*
> - *봤지, 봤는데 막상 현업에 적용하려니까 손이 안 갔지... 근데 네가 말한 대로 프로젝트 단위로 데일리 노트랑 백링크 걸어두니까, 나중에 연관 검색할 때는 진짜 편하긴 하더라.*

---

## 🎯 핵심 의사결정 포인트 (Decision Checkpoint)
> **[결정 질문] 데일리 노트는 PARA 밖의 '입구' 로 두고 내용은 프로젝트 노트에 백링크로 붙일 것인가, 데일리 노트도 PARA 폴더 안에 넣을 것인가?**
> - [ ] **[데일리는 입구 · 백링크로 연결 (권장)]**: 화자 B 가 이미 해 보고 "연관 검색할 때는 진짜 편하긴 하더라" 라고 함. 날마다 어느 구역인지 고민하지 않아도 됨.
> - [ ] **[데일리도 PARA 폴더 안에]**: 한곳에 다 모이지만, 매일 어느 칸인지 또 정해야 함 — 지금 꼬이는 원인이 그대로 남음.

---

## 📌 기존엔 왜 이렇게 관리했을까? (현행 사양의 이유)

* **1. 폴더부터 바꾸면 구조가 눈에 보임 (전환의 첫걸음)**
  * PARA 네 칸을 먼저 만들어 두면 어디에 넣을지가 보임. 새 체계로 옮길 때 가장 자연스러운 시작.
* **2. 애매하면 리소스 (자료 유실 방지)**
  * 분류를 미뤄도 버리지 않고 남겨 둘 수 있는 가장 쉬운 자리.
* **3. 데일리 노트는 원래 쓰던 습관 (기록 흐름 유지)**
  * 날짜별로 적는 흐름은 PARA 이전부터 있던 것이라, 바꾸지 않고 그대로 씀.

---

## 📌 핵심 분석

* **기준은 합의됐는데 적용이 안 됨:**
  * 화자 A 의 기준(지금 실행 중인 액션이 있나)에 화자 B 가 반대하지 않음. 막힌 곳은 "현업에 적용하려니까 손이 안 갔지".
* **기준에 데일리 칸이 없음:**
  * P · A · R 은 '내용' 을 나누는 기준인데, 데일리 노트는 '날짜' 로 쓰는 노트라 어느 칸에도 딱 맞지 않음 → 프로젝트 노트와 꼬임.
* **리소스 쏠림:**
  * 애매한 것을 리소스로 보내는 게 반복되면 리소스가 사실상 '미분류' 칸이 됨 — 화자 A 가 말한 악순환.

---

## 🌐 참조 자료 및 모범 사례 (다른 곳은 어떻게 하는가?)

* **1. PARA 의 실행 가능성 기준 (티아고 포르테)**
  * 주제가 아니라 '얼마나 실행에 가까운가' 로 나눔 — 화자 A 의 기준과 같음. 애매하면 더 실행에 가까운 칸으로 보내는 것이 원래 권장.
* **2. GTD 의 인박스 (데이비드 앨런)**
  * 담는 것과 분류하는 것을 나눔. 일단 인박스에 넣고 정해진 때에 한꺼번에 처리 → 애매한 자료가 리소스로 새지 않음.
* **3. 이 볼트의 방식 (`CLAUDE.md` · `docs/inbox.md`)**
  * 네 질문("마감이 있고 지금 집중하는 일인가? → project …")으로 구역을 정하고, 모르면 인박스 → `📤 PARA로 보내기`. 같은 고민을 먼저 풀어 둔 예.

---

## ⚖️ 핵심 쟁점 (회의에서 답을 내려야 할 질문)

* **1. 데일리 노트의 자리 (장소)**
  * **[PARA 밖 입구]:** 날짜로 쓰고, 내용은 백링크로 프로젝트에 붙임.
  * **[PARA 안]:** 데일리도 구역 폴더에 넣음.
* **2. 애매한 자료는 어디로 (처리)**
  * **[일단 인박스 → 주기적으로 분류]:** 분류할 때가 따로 있어 리소스 쏠림을 막음.
  * **[바로 리소스, 나중에 정리]:** 지금처럼 빠르지만 쏠림이 계속됨.
* **3. 가이드라인을 어떻게 손에 붙일까 (적용)**
  * **[양식에 기준 질문을 넣음]:** 노트를 만들 때마다 기준이 눈에 보임.
  * **[문서로 두고 각자 참고]:** 지금 방식 — "손이 안 갔지" 가 반복될 수 있음.
