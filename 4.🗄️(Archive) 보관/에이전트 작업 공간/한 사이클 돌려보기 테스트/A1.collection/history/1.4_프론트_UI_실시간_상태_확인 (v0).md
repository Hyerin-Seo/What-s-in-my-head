# 1.4 프론트 UI 에서 파이프라인 실시간 상태 확인

> **속기 원문** (속기 3)
> - *프론트 쪽에서 UI로 실시간 상태 확인하는 건 내가 붙여놓을 테니까*
>
> **할 일 후보** — 프론트 UI 실시간 상태 확인 붙이기 — 담당 화자 A · 마감 없음

---

## 🎯 핵심 의사결정 포인트 (Decision Checkpoint)
> **[결정 질문] "실시간 상태" 에 무엇을 보여 줄까?**
> - [ ] **[단계만 (전사 · 청크 · 요약 · 취합 · 실패) (권장)]**: 파이프라인 모양과 같아서 만들기 쉬움
> - [ ] **[로그까지]**: 디버깅엔 좋지만 화면이 무거워짐

---
