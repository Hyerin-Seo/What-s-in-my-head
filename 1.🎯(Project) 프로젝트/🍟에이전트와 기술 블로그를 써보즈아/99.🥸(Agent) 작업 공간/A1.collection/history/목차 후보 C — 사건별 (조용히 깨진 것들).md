## 한 편 안의 소제목 (1편을 예로)

```
개요        속성을 고쳤는데 아무 일도 없었다. 오류도 없었다 → 왜 조용했을까
장면        그날 무엇을 했고 무엇이 안 됐나 (실제 파일 · 명령)
원인        프론트매터를 찾는 코드가 줄끝을 어떻게 보나
Before/After  깨진 파일 ↔ 고친 파일 · 깨지는 코드 ↔ 견디는 코드
남긴 규칙    CLAUDE.md 의 한 줄과 docs 의 한 절
언제 조심하나  윈도우 · 파이썬으로 노트를 쓸 때
마무리      다음 사건 예고
```

## 잘 맞는 경우

- 레퍼런스의 **"불편한 장면 → Before/After"** 장치와 가장 잘 맞습니다. 편마다 장면이 이미 있습니다.
- 한 편이 짧고 혼자서도 읽힙니다. 순서를 바꿔 내도 됩니다.
- 사고가 날 때마다 다음 편이 생깁니다.
