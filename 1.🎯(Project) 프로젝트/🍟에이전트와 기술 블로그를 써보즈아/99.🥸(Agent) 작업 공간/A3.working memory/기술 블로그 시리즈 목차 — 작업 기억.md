## 섞을 수 있는 곳

고른 A · D 에 2차 후보를 얹는 길:

- **A + G**: 편은 조각별(A)로 자르고, 편마다 "이 조각에서 버린 것 하나" 를 G 의 틀(처음엔 왜 → 깨진 곳 → 바꾼 것 → 잃은 것)로 한 단원 넣습니다.
- **A + F**: A 의 조각 앞에 방법론 편(PARA · GTD)을 두어 "왜 이 조각이 이렇게 생겼나" 를 먼저 깝니다.
- **D + F**: 노트의 일생(D) 단계마다 그 단계가 어느 방법론에서 왔고 무엇을 버렸는지 표 하나 — 던진다 = GTD, 자리를 찾는다 = PARA.
- **D + H**: 단계마다 "기대했던 것 ↔ 실제로 된 것" 을 개요 장면으로.

2차 후보끼리:

- **F + G**: 방법론별로 자르되 편마다 버린 것 하나를 G 의 틀로.
- **I → G → H**: 이사(1부) · 버린 것들(2부) · 기대치(끝) 순으로 한 시리즈.
- **G + J**: 버린 것마다 세 목소리를 한 단락씩.

### 코드로 보이는 예시 (같은 날, 한 번 더)

사람의 말: 레퍼런스는 한 환경에서 Rules 와 Skills 각각의 정확한 상황과 코드 예시까지 썼다 — Before/After 가 확실한 코드, 또는 docs · skills 에 더한 줄로 보여 주면 좋겠다.

이번엔 안 뽑았지만 다른 편에 맞는 것: 지워도 되살아나는 캔버스(6편 협업) · 칸반 `+` 가 남긴 빈 폴더 두 겹(5편 플러그인) · 책 44권의 담당이 저자(3편 속성) · 스킬 예시 노트가 가짜 할 일로 뜬 일(4편 스킬).
