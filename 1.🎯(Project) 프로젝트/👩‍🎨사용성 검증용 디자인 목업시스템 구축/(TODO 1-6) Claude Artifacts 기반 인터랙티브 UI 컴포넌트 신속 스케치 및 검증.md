## 뭘 해야 하나

### 1. 배경 및 목적 (Why)
- 로컬 개발 환경(Storybook 세팅 등)이나 피그마 유료 제약에 얽매이지 않고, **브라우저 상에서 30초 만에 버튼을 누르고 화면이 전이되는 실제 React 인터랙티브 컴포넌트를 즉각 스케치**하기 위함.
- Claude의 Artifacts 기능은 단일 프롬프트만으로 실제 동작하는 완성형 프론트엔드 UI를 우측 패널에 실시간 렌더링해주므로, 아이데이션 직후 사용성 손맛을 확인하는 데 가장 진입장벽이 낮음.

### 2. 세부 작업 명세 (What & How)
1. **단일 컴포넌트 완결형 UI 프롬프트 설계**:
   - `React + Tailwind + Lucide Icons` 기반으로 외부 종속성 없이 아티팩트 안에서 100% 자가 구동되는 목업 컴포넌트 지시문 작성.
   - 화면 구성: 좌측 나이브 메모 입력창, 우측 AI 3대 폼 추천 카드(표/조항/카드), 하단 뼈대 슬롯 캔버스 뷰.
2. **동적 상태 전이 (Interactive State Machine) 탑재**:
   - 아티팩트 내부 `useState`를 통해 실전 흐름을 그대로 구현:
     * `State 1`: 메모 타이핑
     * `State 2`: [3대 폼 추천받기] 클릭 시 팝업 렌더링
     * `State 3`: 1번 폼 클릭 시 하단 슬롯으로 데이터가 쏙 꽂히는 애니메이션
     * `State 4`: Diff 대조(초록/빨강) 및 자물쇠(Lock) 버튼 클릭 토글
3. **프로덕션 코드 직행 파이프라인**:
   - 아티팩트에서 눈과 손으로 검증된 React 코드를 복사하여, `apps/web`의 컴포넌트 및 Storybook 스토리로 1:1 이식.
