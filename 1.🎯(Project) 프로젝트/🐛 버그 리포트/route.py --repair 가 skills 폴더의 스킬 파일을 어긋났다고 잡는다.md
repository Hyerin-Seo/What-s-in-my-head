## 무슨 일이 났나

- `python .obsidian/scripts/route.py --repair` 가 `skills/` 안의 `SKILL.md` 두 개와 스킬 예시 파일 두 개를 "구역이 안 맞는 노트" 로 잡았습니다 (4개).
- 이대로 `--repair --write` 를 돌리면 `SKILL.md` 에 볼트 속성 13종이 박혀 스킬 프론트매터가 망가집니다 — 2026-09-17 에 플러그인 쪽에서 한 번 난 일과 같습니다.

## 이렇게 하면 다시 난다

1. `skills/` 를 볼트 맨 위로 옮긴 뒤 (2026-09-17)
2. `route.py --repair` 를 돌린다 → 4개가 잡힌다

## 이래야 맞다

- 에이전트 스킬은 노트가 아니므로 검사에서 빠진다. `--repair` 는 0 이어야 정상.

- 플러그인은 `SKILL.md` 가 있는 폴더를 `inAgentSkill` 로 이미 빼고 있었는데, `route.py` 의 `walk_md` 에는 그 기준이 없었습니다.
- `walk_md` 가 `SKILL.md` 가 있는 폴더를 통째로 건너뛰게 고쳤습니다. 고친 뒤 `--repair` 결과 **0개**.
