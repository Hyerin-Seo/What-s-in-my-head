## 무슨 일이 났나

- `📚 망고네 책장` 에서 `+ 추가` 로 책을 만들면 `(Book) 서적/무제.md` **파일 하나**만 생겼다.
  다른 책들은 전부 `<제목>/📖 <제목>.md` + `<제목>/이미지/` 인데, 표지를 넣을 자리가 없었다.
- 새 책에 `주제: 양식 · 책`, `요약: 새 책 등록할 때 복사하는 틀` 이 딸려 왔다.

## 이렇게 하면 다시 난다

1. `📚 망고네 책장` → `+ 추가` → 제목 입력

## 이래야 맞다

- 기존 책과 같은 모양 — `<제목>/📖 <제목>.md` 와 `<제목>/이미지/`.
- 표지는 `이미지/표지.jpg` 로 넣으면 카드와 본문에 붙어야 한다.

## 알아낸 것

- 보드의 `+ 새 항목` 은 `newItemFolder` 에 **파일만** 떨군다. 폴더를 만드는 기능이 없다.
- **고침**: 설정 **폴더째 담는 보드**(기본 `📚 망고네 책장`)의 새 항목 폴더 바로 아래에 노트가
  생기거나 이름이 바뀌면, 제목으로 폴더를 세우고 `📖 <제목>.md` 로 옮기고 `이미지/` 를 만든다.
  `무제` 인 동안은 기다린다. 본문이 비면 양식 본문을 깐다. 같은 책이 있으면 안 옮기고 알린다.
  떨구는 폴더는 **보드에서 읽는다** — 도서관이 또 옮겨져도 따라간다.
- 양식 `📖 (책 제목)` 에서 함께 고친 것
  - `주제`·`요약` 비움 — 병합 때 민규 서 판을 택하며 빠졌던 main 수정
  - 본문 표지가 **`세컨드 브레인` 책의 표지 경로**로 박혀 있었다 → 새 책마다 남의 표지
  - `커버`·본문 표지를 **`./이미지/표지.jpg`** 로. `./` 없이 `이미지/표지.jpg` 면, 자기 폴더에
    표지가 없을 때 옵시디언이 **다른 책의 `…/이미지/표지.jpg` 로 넘어간다** (asar 의
    `_getLinkpathDest` — 같은 이름이면 자기 폴더 쪽을 먼저, 없으면 남의 것). `./` 는 자기 폴더만 본다.
