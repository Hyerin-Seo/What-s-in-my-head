**무엇이 정본인가** — 버그의 절반은 여기서 갈립니다.

| 값 | 정본 | 반대쪽 |
| --- | --- | --- |
| `구역` | **폴더** | 속성 — 플러그인이 양방향으로 맞춤 |
| `분류` | **구역 바로 아래 폴더 이름** | 속성 — 양방향 (인박스 · 보관 제외) |

| 제목 | **파일명** | `제목` 속성 없음 |
| 보드에 뜨는 것 | **속성** (`유형` · `상태` · `담당`) + 폴더(`file.inFolder`) | 보드 파일은 뷰 정의뿐 |
