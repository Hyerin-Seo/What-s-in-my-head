# 📋 (설계) 창분할 지옥을 끝내는 5단계 라이프사이클 워크스페이스와 사냥개형 독해 UI

> [!abstract] 💡 **핵심 설계 요약: "화면 분할(Split)과 작업 모드(Mode)의 엄격한 분리"**
> * **5분할 모기장 화면 퇴출:** 파일트리, 래퍼런스, 에디터, 아웃라인, AI 챗창을 한 화면에 욱여넣는 무책임한 타일링을 영구 배제.
> * **래퍼런스 vs 리소스 분리:** 뼈대·형식·비트(Beat)를 훔치는 '래퍼런스'와 실제 팩트·수치·근거를 담은 '리소스'의 소비 시점을 엄격히 분리.
> * **최대 2-Pane 원칙:** 어떤 순간에도 인간의 눈앞에는 **최대 2개의 집중 창(70:30 또는 50:50)**만 유지.
> * **사냥개형 목적 독해 워크벤치 (Rin's Insight):**
>   * 수동적 정독이 아닌, **"목적(가설/반박 대상)을 품고 허점을 찾는 수색 및 취조(Adversarial Interrogation)"**.
>   * **타깃 앵커 HUD (좌측 25%):** 읽다가 뇌 단기기억이 넘쳐 뭘 찾는지 잊어버리는 **인지적 표류(Cognitive Drift)**를 시각적 닻으로 방어.
>   * **사냥개 AI:** 재판관 노릇(거짓말/환각)을 금지하고, 타깃과 모순되는 **의심 구간의 좌표(Coordinate)**만 물어오게 제한.
>   * **1초 육안 확인:** 좌표 클릭 시 원문의 해당 줄로 즉시 점프(형광펜)하여 인간 전문가 본인이 직접 확인하고 채택.
