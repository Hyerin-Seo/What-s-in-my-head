## 무슨 일이 났나

- [[레퍼런스 훑어보고 뜯어 볼 도구 하나 고르기]] 의 "우리가 모아 둔 것" 표 링크 6개가 `UI + 디자인 + 기술 레퍼런스` 폴더를 가리키는데, 주소의 `+` 를 `%2B` 로 인코딩해 두었습니다.

## 이렇게 하면 다시 난다

1. 이름에 `+` `&` `,` 가 든 노트로 마크다운 링크 `[글자](주소)` 를 만들면서 주소를 통째로 인코딩한다
2. 링크를 누르면 노트를 못 찾는다

## 이래야 맞다

- 누르면 그 레퍼런스 노트가 열린다.

## 알아낸 것

- 옵시디언은 마크다운 링크 주소를 `decodeURI` 로 풉니다 (obsidian.asar 확인). `decodeURI` 는 `%2B`(+) `%26`(&) `%2C`(,) `%3B` `%3D` `%24` `%40` 을 **안 풉니다.** 이 글자들은 인코딩하지 말고 그대로 둬야 합니다.
- 카드의 링크를 고쳤습니다. vault-sync 의 동기화 기록도 같은 규칙으로 링크를 만듭니다 (`encPath`).
- **확인할 것**: 카드의 My.mind · Are.na 링크를 눌러 열리면 `완료` 로 옮겨 주세요.
