## 알아낸 것

- **대댓글 문제가 아니었습니다.** 답글이 `@민규서` — 민규 서가 **자기 자신을** 불렀고, 그때 코드는 자기 언급을 알림에서 조용히 뺐습니다.
  다른 사람을 부른 답글은 원래 갑니다 (첫 시험 때 민규 서 → `@Rin` 답글이 슬랙에 간 것 확인).
- **고침** (2026-09-22, Claude · `plugins/claude` 💬 코멘트)
  - 자기 자신을 불러도 보냅니다 — 슬랙 첫 줄이 `📌 이름 의 나중에 볼 것` (Rin 요청: 나중에 확인하려고 슬랙에 남겨 두기). 옵시디언 `🔔` 에도 남습니다
  - 아무도 안 부른 코멘트는 "부른 사람 없음" 알림을 띄웁니다 — 조용히 넘어가서 고장처럼 보이던 것
  - 가독성: 메시지를 `💬 누가 → 누구` / 한 말 / 코멘트 단 자리 앞뒤 글 / `📄 노트 · 폴더  옵시디언에서 열기 →` 로 다시 짰습니다.
    `둘 다 동기화` 문구는 뺐습니다
- **같이 고친 것**: `옵시디언에서 열기 →` 링크가 안 붙던 것. 첫 버전이 링크 주소 틀을 빈 값으로 `data.json` 에 적어 둬서,
  나중에 넣은 기본 중계 주소를 덮었습니다. 이제 비어 있으면 기본 주소를 씁니다 (`끔` 이면 링크 없음).
