## 무슨 일이 났나

- `🔀 동기화` 버튼이 리본에도 상태 표시줄에도 없고, 플러그인 목록에도 `동기화 — 충돌 한 번에` 가 안 보인다 (2026-10-07 Rin)
- 플러그인 목록에는 대신 `VaultSync` (Justin Bird, 1.0.1) 라는 처음 보는 것이 켜져 있다

## 이렇게 하면 다시 난다

1. 설정 → 커뮤니티 플러그인 → `업데이트 확인` → `모두 업데이트` 를 누른다 (2026-10-06 19:18 에 한 번 났다)
2. 옵시디언을 다시 켠다 → 동기화 버튼이 없다

## 이래야 맞다

- 우리가 만든 플러그인은 커뮤니티 업데이트가 건드리지 않는다
- 손으로 고쳐 둔 커뮤니티 플러그인(칸반)은 업데이트해도 고친 줄이 남거나, 날아가면 바로 안다

## 알아낸 것

- **왜 사라졌나** — 우리 플러그인의 id 가 `vault-sync` 인데, 커뮤니티 목록에 **같은 id** 의 남의 플러그인(`VaultSync` — 클라우드 저장소 동기화, Justin Bird)이 있습니다. 옵시디언은 id 만 보고 "0.6.0 → 1.0.1 업데이트가 있다" 고 판단해 `main.js` · `manifest.json` · `styles.css` 세 개를 그쪽 것으로 덮어썼습니다. 폴더와 `community-plugins.json` 은 그대로라 켜져 있는 것처럼 보였습니다.
- **근거** — `git diff` 로 보면 `manifest.json` 의 이름이 `동기화 — 충돌 한 번에` → `VaultSync`, 작성자가 `개똥이 머릿속` → `Justin Bird` 로 바뀌어 있었습니다. 세 파일의 고친 시각이 전부 10-06 19:18 이고, 같은 시각에 `feel-the-notion` 0.6.1→0.7.0 · `kanban-bases-view` 0.10.3→0.10.6 · `excalidraw-extras` 0.1.0→0.1.1 도 올라갔습니다 (엑스칼리드로우는 그날 12:03 에 2.27.3→2.28.1).
- **잃은 것은 없습니다** — 마지막 동기화(10-06 16:43, v0.6.0)가 git 에 있어서 그대로 꺼냈습니다. 남의 플러그인은 `data.json` 을 만든 적이 없어 설정된 적도 없습니다. 버튼이 없어서 덮어쓴 판이 민규 서에게 올라가지도 않았습니다.
- **고친 것 ①** `vault-sync` 세 파일을 git 의 0.6.0 으로 되돌림. `node test.js` 15개 통과.
- **고친 것 ②** 같은 업데이트로 칸반의 한 줄 수정(`createFileForView(baseFileName, …)` — 칸반 `+` 가 빈 폴더 두 겹을 흘리던 것)이 날아가 있어서 0.10.6 에 다시 넣음. 위쪽 판도 여전히 전체 경로를 넘깁니다.
- **고친 것 ③ — 다시 안 나게** 플러그인 id 를 `vault-sync` → `gaeddong-sync` 로 바꿨습니다 (0.6.1, 2026-10-07). 폴더 이름 · `manifest.json` · `community-plugins.json` · `claude` 플러그인이 이름표를 물어 오는 줄(`plugins["gaeddong-sync"]`) · `docs/plugins.md`. 커뮤니티 목록 8,497개에 `gaeddong` 으로 시작하는 id 는 하나도 없습니다. `claude` · `meeting-board` 도 지금은 목록에 없습니다.
- **민규 서 쪽** — 동기화로 폴더째 넘어갑니다. 받은 뒤 **옵시디언을 한 번 다시 켜야** 새 이름으로 읽힙니다. 다시 켰는데 버튼이 없으면 설정 → 커뮤니티 플러그인에서 `동기화 — 충돌 한 번에` 를 켭니다. 민규 서도 `모두 업데이트` 를 눌렀었다면 받기 전에 버튼이 없을 테니 `git pull` 로 받습니다.
- **사람이 볼 것** — 옵시디언을 다시 켠 뒤 `🔀 동기화` 버튼이 리본과 상태 표시줄에 돌아왔는지, 플러그인 목록에 `VaultSync` 가 없는지, 칸반 `+` 로 카드를 만들었을 때 빈 폴더가 안 생기는지.
