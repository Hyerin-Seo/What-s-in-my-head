## 📌 MCP 도구별 커버 애로사항 및 기대효과 매핑 (1depth ➔ 2depth)

### 🔍 1. `tree_seek` (트리 탐색 & 필터링 쿼리 엔진)
* **1️⃣ grep/정규식 검색 무력화 해결** : `text_matches_any` / `text_contains_any` 내장 필터로 JSON 특수문자나 이스케이프에 구애받지 않고 정밀 질의
* **2️⃣ 부모-자식 트리 맥락 증발 해결** : `direction: "upward"` 조상 역방향 탐색 지원으로 일치 노드의 상위 대분류와 족보 계층을 즉각 복원
* **3️⃣ 800줄 페이징 열람 시 구조 붕괴 해결** : `start_from: "node_id"`와 `limit` 기반으로 원하는 서브트리만 분할 스트리밍하여 괄호 절단 원천 방지
* **4️⃣ 기계용 메타데이터 토큰 낭비(90%) 해결** : JSON 괄호·시간값·잡음 데이터를 걷어내고 `[handle] ··· text` 형태의 초경량 들여쓰기 텍스트만 전달
* **5️⃣ 인간/에이전트 판독성 바닥 해결** : 전용 에디터 없이도 들여쓰기 위계가 완벽히 시각화된 평탄화 텍스트로 전체 지형도 조망
* **6️⃣ 윈도우 CLI 경로/인코딩 인터럽트 해결** : 파일 시스템에 직접 접근하지 않고 표준 로컬 HTTP/SSE 프로토콜로 질의하여 쉘 인터럽트 제로화

---

### 🛠️ 2. `tree_patch` (원자적 트리 뮤테이션 & 트랜잭션 엔진)
* **7️⃣ 마지막 쉼표(Trailing Comma) 참사 해결** : 텍스트 치환이 아닌 `replace`, `insert` 등 선언적 RPC 요청을 던지므로 JSON 문법 오류 원천 불가
* **8️⃣ 12자리 고유 ID(id) 채번 누락 및 중복 충돌 해결** : `insert_after`, `inside` 호출 시 호스트 백엔드가 고유 난수 ID를 자동 발급·보장
* **9️⃣ 문자열 이스케이프(Escape) 붕괴 해결** : 에이전트는 날것의 텍스트만 전달하고 직렬화/이스케이프는 호스트가 전담하여 화면 깨짐 방어
* **🔟 부모 포인터 부재로 인한 상향 탐색 불가 해결** : `under: "parent_id"` 선언만으로 단방향 트리 상향 역추적 알고리즘을 직접 짤 필요 없이 즉각 배치
* **1️⃣1️⃣ 서브트리 래핑 시 닫는 괄호 카운팅 착시 해결** : `move: ["id1", "id2"], under: "new_parent"` 한 줄로 괄호 중첩 레벨 계산 착시 완전 제거
* **1️⃣2️⃣ 배열 슬라이싱 중 인덱스 시프트(Index Shifting) 버그 해결** : 내부 포인터 스왑 방식으로 처리되므로 `splice`에 따른 인덱스 밀림 및 형제 노드 삭제 방지
* **1️⃣3️⃣ 하위 트리 깊은 복사 누락으로 자식 증발 해결** : 노드 ID 이동 시 하위 서브트리 전체가 원자적으로 함께 리로케이션되어 자식 유실 제로화
* **1️⃣4️⃣ 원자적 트랜잭션 부재로 인한 반쪽짜리 파일 파손 해결** : 단일 요청에 묶인 복수 연산 중 하나라도 실패 시 전체 롤백(Rollback)되어 파일 오염 차단
* **1️⃣5️⃣ 부분 패치 불가로 인한 파일 전수 재작성(Full Re-write) 해결** : 파일 전체를 다시 쓰지 않고 수정된 특정 노드만 메모리상에서 즉각 패치
* **1️⃣6️⃣ 미디어 객체(file.target) 스키마 유실 해결** : 텍스트 편집과 첨부파일 연산이 분리되어 텍스트 조작 중 미디어 객체 실수 삭제 원천 방어

---

### 🔒 3. `lease_acquire` / `lease_*` (동시성 락 수명주기 완결 도구군)
* **1️⃣7️⃣ lease_acquire (작업 락 획득)** : 에이전트 편집 중 사용자의 타이핑으로 인한 실시간 편집본 덮어쓰기 유실(Race Condition) 원천 차단
* **1️⃣8️⃣ lease_release (즉시 락 반환)** : 에이전트 수정 완료 즉시 락을 반환하여 사용자의 편집 대기 시간(TTL 블로킹 지연) 제로화
* **1️⃣9️⃣ lease_touch (락 유효시간 연장)** : 100개 노드 이상 대규모 스캐폴딩 등 장시간 작업 시 락 만료로 인한 중간 충돌 방지
* **2️⃣0️⃣ lease_inspect (사전 충돌 검사)** : 작업 착수 전 사용자가 현재 해당 노드를 편집 중인지 먼저 확인하여 대기/우회 판단 가능

---

### 📎 4. `attachments_attach` / `attachments_pull` (첨부파일 & 멀티모달 에셋 파이프라인)
* **2️⃣1️⃣ attachments_attach (미디어 원클릭 주입)** : 생성한 다이어그램·이미지를 볼트 물리 경로 계산 없이 지정 노드에 즉시 복사 및 링크 바인딩
* **2️⃣2️⃣ attachments_pull (시각 데이터 추출)** : 노드에 첨부된 이미지·도면·PDF를 로컬 캐시로 즉시 추출하여 Vision LLM 기반 시각 분석 가능

---

### 🖥️ 5. `tree_zoom` & `message_success` (UI 시점 동기화 & 피드백)
* **2️⃣3️⃣ tree_zoom (포커스 이동)** : 대규모 구조 재배치 직후 사용자 에디터 화면을 작업 노드로 즉시 줌인시켜 탐색 혼란 방지
* **2️⃣4️⃣ message_success (완료 토스트)** : 긴 스캐폴딩 완료 시 사용자 화면에 시각적 완료 토스트를 띄워 인터랙션 안도감 제공
