## 뭘 해야 하나

기존에 수집된 레퍼런스(Puck, Figma, Scrivener, Heptabase 등 16종)와 중복되지 않으면서, **스캐폴드 매니저(슬롯 분리, 팩트 배선, 후보군 체리피킹 합성, 인간-에이전트 협업)**에 직결되는 4대 영역 12대 벤치마킹 대상을 직접 확인하고 실전 설계에 반영하기.

---

### 1. 에이전트 / 에이전트용 파츠 특화 벤치마킹
> **핵심 과제**: 통짜 생성을 배제하고, 화면의 특정 슬롯(State Key/Component)을 타겟팅하여 채우고 인간 개입(Human-in-the-loop)을 제어하는 방식 검토

1. **CopilotKit (AG-UI & In-app Agent Frame)**
   - **확인 대상**: React 컴포넌트 단위 에이전트 바인딩(`useCopilotReadable`, `useCopilotAction`) 및 Interactive Generative UI 프로토콜.
   - **적용점**: `IdeFieldSocket`과 에이전트 간의 양방향 슬롯 조작(Pause & Resume) 인터페이스 표준화.
2. **LangGraph Studio (Human-in-the-Loop State Inspector)**
   - **확인 대상**: `interrupt()`를 통한 슬롯 확정 직전 동적 중단, `graph.update_state()`를 통한 인간의 슬롯 값 패치, Time-travel 디버깅.
   - **적용점**: 에이전트 런타임 중 인간의 슬롯 검토/승인 게이트웨이 및 과거 시안 롤백/분기 메커니즘.
3. **DSPy (Stanford NLP — Signature & Assertion Framework)**
   - **확인 대상**: `Signature` 기반 슬롯 입출력 스키마 강제, `Assert`/`Suggest`를 통한 저작 규격(Recipe) 위반 시 자동 백트래킹/재시도.
   - **적용점**: 프롬프트 엔지니어링 대신 규격 기반 자가 치유(Self-refinement) 백엔드 파이프라인.

---

### 2. 문서 스캐폴드(뼈대·슬롯·규격) 관리 서비스 벤치마킹
> **핵심 과제**: 내용이 바뀌거나 외부 데이터가 주입되어도 문서 와꾸(레이아웃)가 깨지지 않고, 가변 슬롯과 고정 뼈대를 엄격히 분리하는 방식 검토

1. **PandaDoc (엔터프라이즈 스마트 문서 스캐폴드)**
   - **확인 대상**: Boilerplate(고정 서식)와 Token(가변 슬롯)의 물리적 분리, 외부 데이터 소스 슬롯 매핑, 필수 슬롯 무결성 검증(Field Gating).
   - **적용점**: 백데이터 리소스와 와이어프레임 슬롯 간의 토큰 바인딩 및 빈 슬롯 누락 방지 가드레일.
2. **Overleaf (LaTeX 실시간 조판 & 듀얼 뷰포트 시스템)**
   - **확인 대상**: 내용과 레이아웃의 극단적 분리, A4 정밀 조판, SyncTeX 양방향 핀포인트 점프(PDF 클릭 시 소스 라인 이동).
   - **적용점**: 좌측 바인더/슬롯 트리 ↔ 중앙 실측 A4 캔버스 간의 1:1 양방향 뷰포트 스크롤 및 포커스 동기화.
3. **Coda (문서와 정형 데이터 슬롯의 하이브리드 결합)**
   - **확인 대상**: 텍스트 본문 내 인라인 Formula/데이터베이스 슬롯 삽입, 백데이터 변경 시 본문 텍스트 실시간 자동 갱신.
   - **적용점**: 자연어 문서 흐름 속에 살아있는 가변 데이터 소켓을 이질감 없이 녹여내는 인라인 UI.

---

### 3. 작업 관리 / 복잡 공정 통제 / 합성 벤치마킹
> **핵심 과제**: 키보드 중심의 초고속 슬롯 트리아지, 시안 간 실시간 A/B 비교 및 체리피킹 합성 파이프라인 검토

1. **Linear (초고속 키보드 퍼스트 작업 오케스트레이션)**
   - **확인 대상**: `Cmd+K` 및 단축키 중심의 초고속 일괄 처리(Batch Triage), Optimistic UI(0ms 체감 속도).
   - **적용점**: 수십 개의 슬롯 후보군을 마우스 클릭 없이 키보드로 [다음 슬롯 이동 → 1번 후보 수락(Enter) / 기각(Esc)] 처리하는 극강의 작업 속도감.
2. **DaVinci Resolve / Nuke (비주얼 컴포지팅 & A/B 스플릿 비교)**
   - **확인 대상**: A/B Wipe Split 뷰어를 통한 실시간 차이점(Diff) 대조, 다중 소스 합성(Synthesis) 파이프라인.
   - **적용점**: 시안 A와 B의 슬롯을 나란히 놓고 슬라이더/와이프로 실시간 비교 평가(Punch-Testing)하여 최종본으로 믹스하는 인터랙션.
3. **Autodesk ShotGrid (다단계 에셋 공정 및 주석 리뷰)**
   - **확인 대상**: 서브 태스크(슬롯) 단위 버전 관리, 화면 위 시각적 주석(Visual Annotation) 피드백, 단계별 승인 게이트.
   - **적용점**: 캔버스 화면 위에서 슬롯 단위로 에이전트에게 시각적 피드백을 전달하고 레시피 통과를 승인하는 거버넌스.

---

### 4. 반응형 웹 / 인터랙티브 프로토타이핑 & 비주얼 빌더 벤치마킹
> **핵심 과제**: 정적인 캔버스를 넘어 반응형 레이아웃, 코드 직결 컴포넌트, 고차원 인터랙션 상태를 시뮬레이션하고 즉시 웹으로 배포/검증하는 구조 검토

1. **Framer (컴포넌트 기반 반응형 웹 & 모션 프로토타이핑)**
   - **확인 대상**: React 컴포넌트와 1:1 매핑되는 비주얼 캔버스, 스마트 애니메이트 및 스크롤 인터랙션, 코드 컴포넌트 확장성.
   - **적용점**: 스캐폴드 프리뷰 화면에서 반응형 레이아웃 및 마이크로 인터랙션을 부드럽게 시각화하는 캔버스 엔진.
2. **Webflow (DOM/CSS 박스 모델 기반 구조적 스캐폴딩)**
   - **확인 대상**: HTML/CSS 시맨틱 구조(Flexbox/Grid)의 직관적 시각화, 재사용 가능한 클래스 및 스타일 시스템.
   - **적용점**: 가변 슬롯과 컨테이너 간의 반응형 제약 조건(Flex/Grid)을 코드 수준의 무결성으로 유지하는 레이아웃 스키마.
3. **ProtoPie (상태·조건문·센서 기반 정밀 로직 프로토타이핑)**
   - **확인 대상**: 코딩 없는 조건문(`if`), 변수 연동, 실시간 입력 상태 시뮬레이션, 복합 트리거-리스폰스 구조.
   - **적용점**: 단순 뷰어 수준을 넘어 사용자의 입력 데이터와 에이전트의 생성 결과가 실시간으로 상호작용하는 복합 상태 머신 설계.
