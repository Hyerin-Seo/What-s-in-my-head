## 뭘 해야 하나

> [!note] 2026-10-03 보류 (퍼즈)
> 조사된 5종 전반이 CLI, YAML 코드, 텍스트 매니페스트 기반이거나 기존 출판 서식 틀에 갇혀 있어, 현대적인 인터랙티브 UI/UX 관점에서 지나치게 경직되고 불친절함. 직관적인 캔버스 슬롯 조작 경험에 부합하지 않아 우선순위 보류(퍼즈) 처리.

스크리브너(바인더 집필)와 인디자인(정밀 조판)의 한계를 넘어, **도서(Book)·출판·단행본·기술 문서의 논리적 뼈대(Scaffold)를 잡고 챕터 슬롯을 모듈식으로 조립·컴파일**하는 전문 북 스캐폴더 5종의 구조적 메커니즘을 분석하고 실전 컴포넌트 설계에 반영하기.

---

### 1. Atticus (현대 북 퍼블리싱 올인원 표준)
> **핵심 가치**: Scrivener의 바인더 구조 + Vellum의 원클릭 조판 엔진 + 클라우드 협업

- **확인 대상**: 3단 뷰포트(좌: Front/Body/Back Matter 구조 트리 ↔ 중: 리치 텍스트 슬롯 에디터 ↔ 우: 실시간 실측 인쇄/디바이스 프리뷰어).
- **적용점**: 챕터 순서 드래그 앤 드롭 시 우측 캔버스에서 러닝 헤드와 페이지 번호가 0ms로 즉각 리컴퓨팅(Recomputing)되는 실시간 렌더링 파이프라인.

---

### 2. Vellum (인체공학적 북 레이아웃 & 챕터 스타일 스캐폴더)
> **핵심 가치**: 출판사 수준의 챕터 와이어프레임 프리셋을 원클릭으로 입히는 추상화 엔진

- **확인 대상**: 텍스트 내용과 시맨틱 엘리먼트(챕터 타이틀, 드롭캡 두문자, 장식 구분자, 인용구, 각주)의 완전 분리 및 판권지·헌사 등 필수 메타 슬롯 강제(Field Gating).
- **적용점**: 본문 데이터 수정 없이 클릭 한 번으로 문서 전체의 시각적 레시피(Font, Header, DropCap, Margin 테마)를 일괄 스위칭하는 테마 컴포넌트 아키텍처.

---

### 3. Leanpub / Markua (애자일 모듈 조립형 북 빌더)
> **핵심 가치**: 거대한 문서를 개별 텍스트 블록으로 쪼개고, 매니페스트 파일로 직렬화(Compile)

- **확인 대상**: 본문을 수십 개의 독립 파일(`ch01.md`, `slot_02.md`)로 쪼개고 `Book.txt`(인덱스 매니페스트)에서 순서만 정의해 조립하는 파일 기반 오케스트레이션 및 서브셋 컴파일(`Subset.txt`).
- **적용점**: 스캐폴드 매니저의 "슬롯 단위 독립 파일 저장 + 메인 아웃라인 포인터 배선" 구조 표준화.

---

### 4. Quarto / Jupyter Book (데이터·다이어그램 직결형 학술·전문서 스캐폴더)
> **핵심 가치**: 텍스트와 코드, 데이터 테이블, 정밀 다이어그램이 상호 참조로 직결되는 북 엔진

- **확인 대상**: 선언적 `_quarto.yml` 목차 정의 스키마를 통한 뼈대-본문 디커플링, `{#sec-target}`, `{#fig-chart}` 태그를 통한 크로스 레퍼런스(Cross-referencing) 자동 넘버링 및 무결성 검증.
- **적용점**: 스캐폴드 내부에서 다른 슬롯의 데이터/도표를 인용할 때 링크와 번호가 절대 깨지지 않는 상호 참조 가드레일.

---

### 5. Paged.js / Vivliostyle (웹 표준 CSS Paged Media 기반 캔버스 조판기)
> **핵심 가치**: 인디자인 없이 순수 HTML/CSS 표준만으로 브라우저 캔버스에서 책 페이지를 실시간 분할

- **확인 대상**: 웹 브라우저 안에서 연속된 웹 텍스트를 실시간으로 A4/신국판 규격으로 쪼개어 가상 페이지 DOM(양면 펼침면, 제본 마진, 헤더/푸터)을 생성하는 DOM 슬라이싱 알고리즘.
- **적용점**: React/Vite 기반 웹 에디터 캔버스 위에서 인쇄/도서 조판을 외부 도구 없이 0ms로 실시간 시각화하는 핵심 뷰어 엔진.
