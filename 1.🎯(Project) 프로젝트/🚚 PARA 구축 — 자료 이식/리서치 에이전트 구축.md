## 이게 뭐였더라

트렌드 조사와 일상적인 웹 리서치에서 반복되는 검색·비교·정리 작업을 신뢰도 있는 보고서로 자동화한다.

## 다음 행동

- [ ] 비즈니스·AI·대중 트렌드별 수집 소스(X, Hacker News, RSS, 데이터랩, SNS, 뉴스레터)를 우선순위화한다.
- [ ] 검색 API와 크롤러를 이용해 최근 24시간 데이터를 정기 수집하는 파이프라인을 설계한다.
- [ ] 중복 기사 병합, 광고성 콘텐츠 제외, 교차 검증 기준을 정의한다.
- [ ] 비즈니스 기회·패러다임 전환 기준의 트렌드 점수화 프롬프트와 통과 임계값을 정한다.
- [ ] PARA Resources에 맞춘 자동 태그·카테고리 체계를 설계한다.
- [ ] `Headline`, `Context`, `Business_Impact`, `Source_Links` 보고서 JSON 스키마를 만든다.
- [ ] 사용자 질문을 복수의 전문 검색어로 확장하는 Query Expansion 로직을 구현한다.
- [ ] 정보 부족 시 재검색하는 자율 탐색 루프와 종료 조건을 설계한다.
- [ ] 비교·타임라인·학습형 결과에 맞춰 보고서 형식을 선택하는 렌더링 규칙을 만든다.
- [ ] 이미지 중심 카드형 웹 대시보드의 정보 구조와 상세 보기 동작을 정의한다.
