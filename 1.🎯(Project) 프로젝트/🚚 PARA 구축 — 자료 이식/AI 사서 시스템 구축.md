- [ ] 자료를 레퍼런스·할 일·아카이브 등으로 판별하는 시맨틱 라우팅 기준과 예외 처리 규칙을 작성한다.
- [ ] 현재 PARA 폴더 및 노트 속성에 맞춘 저장 대상 매핑을 설계한다.
- [ ] 임베딩 모델·벡터 DB·검색 인터페이스를 선정하고 의미 검색 흐름을 검증한다.
